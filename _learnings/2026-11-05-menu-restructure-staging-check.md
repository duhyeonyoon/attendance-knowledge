- 스테이징(어드민 ap-tx / 사용자 app-tx)에서 근무관리 탭 메뉴·URL·탭 구성을 직접 수집

## 실제 화면과 문서가 다른 곳 (본문 미반영 — 후속 deep-dive 필요)
- **근무 신청 내역 관리**: 실제 10탭 — 근무계획 변경 / 통합 근무내역 변경 / 출퇴근 내역 변경 / 기타근무 / 재택근무 / 연장·야간(사전) / 연장·야간(사후) / 휴일근무(사전) / 휴일근무(사후) / 대체근무. 문서는 4탭 기준
- **개인 근무 스케줄 관리**: `선택적 근로 스케줄` 탭 추가 (근무 스케줄 / 선택적 근로 스케줄)
- **휴가 지급 및 관리** → `연차 관리`(`/attendance/leave/annual_management`), `연차 외 휴가 관리`(`/non_annual_management`), `연차 촉진`(`/encouragement`) 3개 메뉴로 분리
- **연동(#1)**: 근무관리 메뉴에 없음 → `product/admin/etc/sync.md`
- 사용자 근무관리 메뉴: 내 근무 / 내 휴가(예정휴가·사용기록 탭) / 구성원 근무 / 구성원 휴가 / 근무스케줄(내 기준·역할 기준) / 위치정보 제공 조회 / 연차촉진
- 사용자 신청서 중 사후 신청(연장·야간/휴일근무), 출퇴근 내역 변경, 통합 근무내역 변경은 KB에 아직 페이지 없음
