> **메뉴** 근무관리 › 휴가 (메뉴그룹 공통)
> **사용자** 어드민(휴가 담당자) · 구성원(사용자 화면 [내 휴가](../../user/attendance/my-leave.md))

## 1. 개요
휴가 메뉴그룹의 모든 화면에 공통으로 적용되는 개념과 규칙을 정리합니다. 휴가는 **제도 정의 → 휴가 그룹 → 지급·관리 → 사용자 신청·사용**의 4단계로 이어지며, 앞 단계의 설정이 뒤 단계에 그대로 상속됩니다.

| 단계 | 화면 | 하는 일 |
|---|---|---|
| ① 제도 정의 | [휴가 설정](./base-setting.md) | 연차 제도 · 연차 정산 기준 · 연차 외 휴가 제도 정의 |
| ② 정책 단위 | [휴가 그룹 설정](./group-setting.md) | 제도/정산 기준을 묶은 휴가 그룹 생성, 구성원 배정 |
| ③ 운영 | [연차 관리](./annual-management.md) · [연차 외 휴가 관리](./non-annual-management.md) · [연차 촉진](./encouragement.md) | 연차 생성·조정·정산, 연차 외 휴가 지급·정산, 수동 등록, 연차 촉진 |
| ④ 사용 | [내 휴가](../../user/attendance/my-leave.md) | 잔여/예정/사용 기록 조회, 휴가 신청(결재 → 승인) |

## 2. 화면 구성
해당 없음 (메뉴그룹 공통 정책 페이지)

### 2.1 휴가 종류와 설정 단위
| 구분 | 설명 |
|---|---|
| 연차 제도 | 연차 부여 기준(회계연도 기준 / 입사일 기준 / 부여 안함), 근속연수별 부여 일수, 1년 미만 연차, 연차 사용 시간대 |
| 연차 정산 기준 | 귀속연도 종료 시 잔여 연차를 어떻게 처리할지(의무 사용, 이월, 보상) |
| 연차 외 휴가 제도 | 경조사·병가 등 연차 이외의 휴가. 사용자용/어드민용 명칭, 부여 방식, 휴일·휴무일 포함 여부 |
| 휴가 그룹 | 위 제도·정산 기준을 묶어 구성원에게 적용하는 정책 단위 |

### 2.2 주요 용어
| 용어 | 의미 |
|---|---|
| 1년 미만 연차 (월차) | 입사 1년 미만 구성원에게 월별로 발생하는 연차. 부여 방식은 **선부여(1건, 같은 사용기간 일괄 부여)** 또는 **다건 분할(건별 사용기간/개수, 상세 모달로 확인)** |
| 연차기산일 | 연차 산정의 시작일 |
| 귀속연도 | 연차·정산이 속하는 연도. 정산은 귀속연도 단위로 처리 |
| 관리자 등록 휴가 | 어드민이 수동 등록한 휴가. 신청서 결재 없이 등록되며, 사용자 화면에서는 신청서가 아닌 별도 확인 모달로 표시 |
| 수동 휴가 지급 | 어드민이 연차 외 휴가를 직접 입력/엑셀로 지급 (시간 단위만) |
| 수동 휴가 등록 | 어드민이 휴가 사용 기록을 직접 입력/엑셀로 등록 |

## 3. 기능 상세

### 3.1 관리 화면 공통 조회·액션
연차 관리 · 연차 외 휴가 관리의 각 탭(보유현황 / 사용 현황)에 공통으로 적용됩니다. 두 메뉴는 예전 "휴가 지급 및 관리" 한 화면에서 분리된 것으로, 예전 메뉴 주소로 들어오면 연차 관리로 이동합니다. 각 메뉴의 탭은 주소에 기억되어 새로고침해도 같은 탭이 열립니다.

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-LV-COM-01 | 조회 기준 선택 | "연도별 조회" / "기간 조회" 라디오 | 연도별 기본값 = 당해년도, 기간 기본값 = 당해년도 1월 1일 ~ 조회 당일 |
| A-LV-COM-02 | 조회 필터 | 구성원 · 회사 · 조직 · 휴가그룹 · 휴가유형 · 활성여부 | 사용 현황 탭은 "등록방식" 필터 추가. 비활성 구성원도 "이름(비활성)" 형식으로 선택 가능 |
| A-LV-COM-03 | 필터 재설정 | [필터 재설정]으로 필터를 기본값으로 되돌림 | |
| A-LV-COM-04 | 엑셀 다운로드 | 현재 조회 조건으로 다운로드 | 다운로드 사유 입력 필수 |
| A-LV-COM-05 | 그리드 정렬 | 지정된 컬럼 헤더 클릭 시 정렬 | 보유현황: 사번·이름·조직·직급·휴가그룹·입사일·연차유형·귀속연도·일반·적립·사용시작일·사용종료일 / 사용 현황: 위 항목 + 등록방식·상태 |

## 4. 정책 · 비즈니스 룰
1. 휴가 제도·정산 기준은 **어드민 정의 → 휴가 그룹 상속 → 구성원 적용**의 3단계로 적용됩니다. 휴가 그룹의 구성원이 바뀌면 해당 구성원은 그룹의 제도/정산 기준을 즉시 상속합니다.
2. 휴가 그룹은 근무 그룹과 **독립**입니다. 같은 구성원이 서로 다른 휴가 그룹·근무 그룹에 속할 수 있습니다.
3. 이미 휴가 그룹에 적용된 제도/정산 기준은 사용여부를 "사용 안함"으로 바꾸거나 삭제할 수 없습니다.
4. 연차 정산은 **귀속연도 단위**이며, 1년 미만 연차는 합산 처리합니다. 다음 귀속연도가 정산된 경우 이전 정산은 취소할 수 없습니다. 1년 미만 연차를 부여보다 많이 쓴 부족분은 정산 기준의 "1년 미만 연차(월차) 정책"과 같은 방식(보상에서 차감 / 다음 해 부여에서 차감 / 청산 안 함)으로 처리합니다.
5. **근무 마감된 날짜**의 휴가는 요청·승인·취소 모두 불가합니다 ([근무 마감](../work/close-work-data.md)).
6. **정산된 휴가**는 요청·승인·취소 모두 불가합니다 (사용자 신청 시 "정산된 경우 요청 불가").
7. 연차 외 휴가는 사용자용 이름과 어드민용 이름을 따로 설정할 수 있습니다.
8. 휴가 사용 시간대를 **고정**으로 설정한 경우 30분 단위 검증이 적용되지 않고, 근무계획과 무관하게 사용할 수 있습니다.
9. **휴가 일수 계산** = 사용 시간(분) ÷ (일 소정근로시간 × 60), 소수점 둘째 자리에서 반올림. 일 소정근로시간은 일 근무계획 → 근무 그룹 설정 → 기본 8시간 순으로 적용됩니다.
10. 수동 휴가 지급 단위는 **시간만** 지원합니다(의도된 설계). 회사·사람마다 소정근로시간이 달라 "1일"이 몇 시간인지 모호해지기 때문입니다.
11. 연차 차감은 **사용 종료일이 빠른 연차부터** 차감합니다 (만료 임박 우선).
12. 초과 사용(잔여보다 많이 사용)은 연차 제도에서 허용한 경우에만 가능합니다.
    - 일반 연차: "연차 초과 사용" 허용(제한 없음 또는 최대 N시간) 시. 초과분은 정산 기준의 "연차 초과 사용분 정산 정책"대로 처리
    - 1년 미만 연차: "1년미만연차 초과 사용" 허용(제한 없음 또는 최대 N시간, 기본은 허용 안함) 시. 사용을 확정하는 시점에 이미 발생한 1년 미만 연차를 기준으로 판단하며, 아직 발생하지 않은 달의 연차를 당겨 쓰지는 않습니다. 한도는 달마다 초기화되지 않고 1년 미만 기간 전체에 걸린 총량입니다
    - 연차 외 휴가: 초과 사용 없음
    - 이미 초과된 상태는 규칙 변경·조정·취소 재계산 시에도 유지됩니다 (새 신청만 막힘)
13. 연차는 현재 **근무율(출근율 80% 등)과 무관하게** 부여됩니다.
14. 잔여가 마이너스인 귀속연도가 있으면 합산 잔여에 그대로 반영됩니다 (예: 2025년 −2일 + 2026년 15일 → 13일). 연도별 조회로 구분해서 확인합니다.
15. 연차 촉진은 시스템 전자문서와 노무수령거부 알림을 묶은 하나의 워크플로우입니다.
16. 1년 미만 연차의 귀속연도는 **연차기산일이 속한 회계연도**입니다(선부여 방식은 생성 작업 연도). 귀속연도로 조회할 때 1년 미만 연차가 기대한 연도에 나오지 않을 수 있습니다.
17. 보유현황의 사용 일수에는 **승인 완료분만** 반영됩니다. 신청중(결재중) 휴가는 잔여 계산에서만 미리 막습니다.
18. 연차는 생성 기준일(회계연도 시작일 또는 입사 월·일)에 소속된 휴가 그룹의 연차 제도로 생성됩니다. 상세 규칙은 [휴가 설정](./base-setting.md) 참고. (기획 확인 2026-11-05)
19. 연차 정산 취소 시 다음 귀속연도 잔여가 이월 일수보다 적으면 취소할 수 없고, 취소되면 이번 정산으로 넘어간 이월분만큼 다음 귀속연도 이월 일수에서 회수합니다. 연차 외 휴가는 이월분을 이미 썼으면 취소할 수 없습니다. (기획 확인 2026-11-05)
20. 어드민이 직접 등록한 휴가는 사용자 화면(내 근무·내 근무 상세·내 휴가·구성원 근무)에서 연차/연차 외 구분 없이 신청서 대신 '관리자 등록' 휴가 정보 창(모바일은 하단 시트)으로 표시됩니다. (기획 확인 2026-11-05)
21. 휴가 그룹의 임시저장(미확정)/확정 동작은 근무 그룹과 같습니다. 미확정 그룹은 내용 변경 없이도 [저장]으로 확정할 수 있습니다. (기획 확인 2026-11-05)

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 휴가 그룹에 적용된 연차 제도 사용여부 변경 | "휴가그룹에 적용된 연차 제도는 사용여부를 변경할 수 없습니다." |
| 휴가 그룹에 적용된 연차 제도 삭제 | "휴가그룹에 적용된 연차 제도는 삭제할 수 없습니다." |
| 근무 마감일 / 정산된 휴가의 요청·승인·취소 | 처리 불가 |
| 초과 사용 한도 초과로 신청 | "초과사용 가능 시간이 부족합니다. (남은 초과사용 가능 시간: n시간 n분)" |
| 1년 미만 연차 — 사용일에 발생한 연차가 없거나 아직 발생 전인 연차로 신청 | "생성된 휴가보다 더 많이 사용할 수 없습니다." / 발생분이 하나도 없으면 "생성된 연차가 없습니다." |

## 6. 연관 기능
| 휴가 영역 동작 | 영향 받는 화면 |
|---|---|
| 휴가 제도 변경 | 휴가 그룹 매핑, 사용자 잔여 표시, 신청 시 선택 가능한 휴가 |
| 휴가 그룹 구성원 변경 | 구성원의 적용 제도/정산 기준 즉시 변경, [휴가 그룹 이력 관리](./group-history.md)에 이력 기록 |
| 연차 자동생성 | 사용자 잔여 휴가·캘린더 표시 |
| 수동 휴가 지급/등록 | 사용자 화면에 "관리자 등록 휴가" 별도 모달 표시 |
| 연차 정산 | 정산된 휴가의 사용자 신청 차단 |
| 사용자 휴가 신청 승인 | 잔여 차감, 어드민 사용 현황 탭에 노출 |
| 근무 마감 | 마감일 휴가 요청/승인/취소 불가 ([근무 마감](../work/close-work-data.md)) |
| 연차 촉진 | 사용자 [연차촉진](../../user/attendance/annual-leave-encouragement.md) 화면, 통지/계획서 전자문서, 노무수령거부 팝업 |

- [근무 그룹 설정](../work/group-setting.md) — 휴가 그룹과 같은 그룹 패턴
