> 연차 관리 · 연차 외 휴가 관리와 별개의 독립 메뉴입니다.

## 1. 개요
근로기준법에 따른 미사용 연차 사용 촉진 절차를 운영하는 화면입니다. 어드민이 연차 촉진 작업을 만들고 대상자 확인 → 미사용 연차 통지 → 사용시기 지정 통보 → 노무수령거부 현황 순으로 진행하며, 구성원은 [연차촉진 (사용자)](../../user/attendance/annual-leave-encouragement.md) 화면에서 문서를 확인합니다.

## 4. 정책 · 비즈니스 룰
1. 연차 촉진 작업은 **삭제 기능이 없습니다** (추가 계획 없음 확인).
2. 생성 후에는 작업명과 메모만 수정할 수 있습니다.
3. 연차 촉진은 시스템 전자문서 + 노무수령거부 알림이 묶인 하나의 워크플로우입니다.
4. 1년 미만 연차 촉진은 "분할 촉진"이면 근로기준법 기준(1년 근로기간 종료 3개월 전을 기준으로 이전·이후 발생분)으로 2건, "단일 촉진"이면 1건이 생성됩니다. 단일 촉진은 법정 촉진 효력이 인정되지 않을 수 있습니다.
5. 연차 사용 여부는 지정일에 연차를 쓴 경우만 "O"로 인정합니다.
6. 연차 촉진 대상 일수에는 [연차 관리](./annual-management.md)의 수동 조정값이 반영되지 않습니다. 의무 사용 일수는 자동 생성분(+ 정산 기준 설정에 따라 전년도 이월분)으로만 계산하고, 조정분은 모두 '의무 사용 외'로 보는 것이 의도된 설계입니다(기획 확인 2026-11-05).
7. 촉진 양식(통지서 · 계획서 · 통보서)은 회사별로 준비해야 하며, 세 가지 모두 있어야 작업을 만들 수 있습니다.
8. 대상/비대상은 대상자가 만들어질 때 한 번 판정되며, 비대상은 이후 촉진 기간을 바꿔도 대상으로 바뀌지 않습니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 회사 선택 전 양식 선택란 | 비활성, 툴팁 "회사를 먼저 선택한 후 연차촉진 양식을 선택합니다." |
| 해당 회사에 양식이 없어 선택하지 못한 채 [확인] | "미사용 연차 통지서 선택은 필수입니다." 등 양식별 필수 메시지 (별도 "양식 없음" 안내는 없음) |
| 작업 생성 완료 / 실패 | "연차촉진 작업이 생성되었습니다." / "연차촉진 작업 생성 실패" |
| 미사용 연차 통지 확인 | "(대상자)에게 미사용 연차 통지서와 사용 계획서 작성 요청 알림을 보내시겠습니까?" → "미사용 연차 통지서와 사용 계획서 작성 요청 알림을 발송 완료하였습니다." |
| 사용시기 통보 확인 | "(대상자)에게 사용시기 통보서를 전달하시겠습니까?" → "사용시기 통보가 완료되었습니다." |
| 통보 대상 전원이 연차를 모두 사용 | "사용시기 통보 불가" — "선택한 구성원 전원이 통보 중 연차를 모두 사용해 사용시기를 통보할 수 없습니다." |
| 촉진기간 엑셀 업로드 실패 예 | "해당 사원은 이 촉진 작업의 대상자가 아닙니다." / "이미 1차 촉진 통지서가 발송되어 변경할 수 없습니다." / "이미 발송된 촉진 기간의 종료일은 단축할 수 없습니다. 연장만 가능합니다." / "촉진 기간이 연차 사용기간을 벗어났습니다." |
| 노무수령거부 알림 설정 OFF | 사용자 팝업 미노출 |
