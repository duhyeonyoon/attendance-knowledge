> **메뉴** 근무관리 › 근무 › 근무 대시보드  
> **URL** `/attendance/work/dashboard`  
> **사용자** 어드민(근무 담당자)

## 1. 개요

어드민이 **특정 일자(기본 오늘) 자사 구성원들의 근무 상태를 한눈에** 확인하는 화면입니다 (안내 문구: "구성원의 일별 근무 현황을 모니터링하고 관리합니다."). 근무 누락 구성원을 걸러 보고, 누락 구성원에게 근무 누락 알림을 수동 발송할 수 있습니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 필터 | 조회 날짜 · 구성원 · 회사 · 조직 · 누락 건만 보기 · 조회 · 필터 재설정 | 조회 날짜는 단일 일자만 선택 가능(필수, 기본 오늘). 회사 기본 = 어드민 소속 회사 |
| 목록 | 체크박스 / 구성원 / 사번 / 회사 / 조직 / 근무계획 / 최종 누락 여부 / 근무시간 / 출근 / 퇴근 / 휴가 / 기타근무 / 재택 / 근무 내역 변경 / 활성 여부 / 알림 | 구성원 · 사번은 좌측 고정 |
| 알림 발송 | 행 체크박스 · 상단 "알림 발송" 버튼 · 행별 "발송" 버튼 | 근무 누락 알림 수동 발송 |

**컬럼 표시 내용**

| 컬럼 | 표시 |
|---|---|
| 최종 누락 여부 | 누락이면 "누락", 아니면 "-" (툴팁: 출근 또는 퇴근 기록이 누락된 경우 '누락'. 단, 종일 기타근무 · 휴가가 승인되었거나 기타근무와 휴가 시간 합이 소정근로시간 이상이면 누락 아님) |
| 근무시간 | 출근 ~ 퇴근 총 시간에서 휴게 · 자리비움 등 근무 외 시간을 뺀 시간 (출근 인정 시각 설정 시 그 기준) |
| 출근 / 퇴근 | 최초 출근 · 최종 퇴근 시각. 지각 · 조퇴 기준을 설정한 경우 "(N시간 N분 지각/조퇴)" 함께 표시. 출근 · 퇴근 요청 진행 중이면 "요청중" |
| 휴가 / 기타근무 | 시간대 목록, 진행 상태에 따라 "(요청중)" / "(취소중)" 표시 |
| 재택 | 요청중 / 취소중 / 승인완료 |
| 근무 내역 변경 | 진행 중인 근무내역 변경(통합 근무내역 · 출퇴근 내역) 신청이 있으면 "요청중", 없으면 "-" |
| 알림 | "발송" 또는 "발송 완료" |

| A-WRK-DSH-06 | 구성원 · 회사 · 조직 필터 | 구성원 · 회사 · 조직 조건으로 목록을 좁혀 조회 | 회사 기본 = 어드민 소속 회사 |

## 4. 정책 · 비즈니스 룰

1. "누락 건만 보기"는 날짜와 관계없이 사용할 수 있습니다 (2026-10-22 변경 전에는 오늘 포함 이후 날짜에서 비활성).
2. 근무 누락 알림은 시스템 > 알림 설정에서 **"근무 누락 알림 (어드민 수동 발송)"**이 허용된 경우에만 사용할 수 있습니다.
3. 알림 대상 체크박스와 "발송" 버튼은 아래 4가지를 **모두** 만족할 때만 활성화됩니다.
   - 근무 누락 상태
   - 알림 컬럼이 발송 완료 상태가 아님
   - 요청중인 근무내역 변경(통합 근무내역 · 출퇴근 내역) 신청서가 없음
   - 활성 구성원
4. 발송 시점에 요청중인 근무내역 변경 신청이 생기거나 누락 상태가 바뀐 구성원은 발송에서 제외됩니다.
5. 근무 누락 알림은 **오늘 이전 날짜**에 대해서만 발송할 수 있습니다.

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 알림 조건 미충족 구성원 | 선택 체크박스 · "발송" 버튼 비활성 |
| 누락이지만 근무내역 변경 요청이 있는 구성원 | 툴팁 "통합 근무내역 변경 또는 출퇴근 내역 변경 요청건이 존재하여 알림을 발송할 수 없습니다." |
| 알림 발송 확인 | 제목 "근무 누락 알림 발송" / "{구성원}에게 회사 메일로 근무 누락 알림을 발송합니다. 알림은 설정한 웹·앱 알림, 팝업 방식으로 발송하며 시스템 > 알림설정에서 변경 할 수 있습니다." (여러 명이면 "{이름} 외 N명") |
| 발송 완료 | "알림 발송을 완료하였습니다." |
| 발송 실패 | 제목 "요청 실패 에러가 발생했습니다." / 서버 메시지 또는 "알림 발송이 실패했습니다." |
| 오늘 · 미래 날짜로 발송 요청 | "누락 알림 발송은 오늘 이전 날짜만 가능합니다." |
| 발송 중 상태 변경된 구성원 | 제목 "알림 발송 제외" / "아래 표시된 구성원들은 알림 발송 도중 통합 근무내역 변경 요청, 출퇴근 내역 변경 요청 또는 근무 누락 상태 변경이 발생하여 알림 발송에서 제외하였습니다." / "아래 구성원 제외, 알림 발송을 정상적으로 완료하였으며 새로고침 후 해당 구성원들을 다시 확인해주시기 바랍니다." + "알림 발송 제외 구성원" 목록(사유: "통합 근무내역 변경 요청" / "출퇴근 내역 변경 요청" / "근무 누락 상태 변경") |
