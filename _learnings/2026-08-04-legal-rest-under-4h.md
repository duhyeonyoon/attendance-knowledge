# 법정(자율) 휴게 계산 — 근무시간 4시간 미만일 때 (2026-08-04)

## 결론
4시간 미만이면 자동 휴게는 **0분**. 두 계산 함수 모두 동일.

## 계산 함수 2종 (`be:time/common/util/TimeServiceUtil.java`)
기본 상수: `CONST_TIME_COMMON.REST_STD_HOUR = 4.0`, `REST_HOUR_PER_STD = 0.5`(30분), `REST_MINUTE_PER_STD = 30`.
근무그룹 휴게 세팅(`workRestStdTime` / `workRestApplyTime`)이 있으면 그 값이 우선, 없거나 0 이하면 위 기본값.

### 1) `getHourlyRestMinutesByValidWorkTime` (:423) — 유효/계획 근무시간 기준
`floor(validMin / (stdHours*60)) * restPerStd * 60`
- 3.9h → 0분 / **4.0h → 30분** / 4.5h → 30분 / 7.5h → 30분 / 8h → 60분
- 즉 4시간 **미만 = 0분**, 4시간 도달 시 즉시 30분.

### 2) `getHourlyRestMinutesInTotalWorkTime` (:371) — 총 재실시간(출~퇴근) 기준
사이클 = total / 60 / (std + restPerStd) = /4.5h
- 4h 미만 → 0분
- **4h 정각 → 0분** (1번과 다름)
- 4h~4.5h 구간 → 초과분만 휴게 (4h20m → 20분)
- 4.5h → 30분, 이후 4.5h 사이클마다 30분

⚠️ **경계값 불일치**: 정확히 4시간일 때 유효근무시간 기준=30분, 총근무시간 기준=0분.
호출부가 어느 함수를 쓰는지에 따라 4시간 정각 케이스 결과가 달라진다.
(계획/신청 계산 = ByValidWorkTime 계열, 실제 근무 집계·연장휴게 = InTotalWorkTime 계열)

## 주의사항
- **고정휴게(`REST_APPLY_CD_1.FIX`)는 4시간 임계값과 무관.** `calculateFixedRestMinutes`는 근무 구간과 겹치는 고정휴게를 그대로 차감하므로, 3시간만 근무해도 고정휴게 구간(예 12:00~13:00)과 겹치면 휴게가 잡힌다. "4시간 미만이면 휴게 없음"은 **자율(HOUR) 휴게에만** 해당.
- `MemberDailyWorkPlan.java:287-296` — 자율휴게에서 restMinutes=0이어도 `restStartTime = 출근+restStdHour`, `restEndTime = 동일` 로 **길이 0짜리 휴게 row가 baseRestTime 리스트에 추가**됨. 4시간 미만 근무일의 계획 응답에 13:00~13:00 같은 항목이 실릴 수 있음 (화면 표시 확인 필요).
- `calcWorkEndTimeWithLegalRest` (:716)에 `//TODO 법정휴게 DB 저장 세팅대로 받아오도록 개선해야함` — 이 경로는 아직 상수 하드코딩(4h/30분), 근무그룹 세팅 미반영.

## 실사례 검증 — 계획 1시간 + 실제 09:00~18:00 재집계 시 휴게 30분 (2026-08-04)

케이스: 근무계획 없던 구성원에게 과거 누락일 09:00~18:00 근무내역 생성 → 1시간 템플릿(09:00~10:00, 소정 60분, 휴게 자동) 반영 → 재집계.
결과: 휴게 00:30 / 총근무 08:30 / 기본 01:00 / 연장 07:30.

**원인: 이 30분은 기본(법정) 휴게가 아니라 연장휴게(otRestMin).**
`be:time/common/workcalc/WorkTimeCalcService.java` 에서 휴게는 **기본 구간 / 연장 구간으로 쪼개져 각각** `getHourlyRestMinutesInTotalWorkTime`으로 계산된다.
- `:702-727` 기본구간 = 출근(또는 인정시각) ~ `expendStaTime`(연장 시작 = 계획 종료 10:00) = **60분 → 휴게 0분**
- `:756-761` 연장구간 = 10:00~18:00 = **480분 → 휴게 30분**, 연장근무 = 480-30 = 450분
- 총근무 = 540 - 0 - 30 = 510분(08:30), 기본 = 510-450 = 60분(01:00) → 스크린샷과 정확히 일치

왜 480분에 30분인가: 총근무시간 기준 함수는 4.5h 사이클이라 480분은 사이클 1개(30분)만 충족. 60분이 되려면 540분 필요.

⚠️ **구조적 함의**: 9시간 통으로 계산하면 휴게 60분이지만, 계획이 1시간이라 1h+8h로 분할되면서 0 + 30 = **30분**만 잡힌다. 계획 소정근로시간이 짧을수록 자동 휴게가 법정 기준보다 적게 산정될 수 있음.
- `isLegalBaseRestUsed` / `isLegalOtRestUsed` (`:453-455`) — 각각 기본휴게 / 연장휴게 설정이 `REST_APPLY_CD_1.HOUR`(자동)일 때만 이 경로 적용. 고정이면 미적용.
- 여기 경로는 근무그룹 세팅이 아니라 `CONST_TIME_COMMON` 상수(4h/30분) 하드코딩 사용.
