> **사용자** 어드민(근무 담당자)

## 1. 개요

구성원의 근무 결과를 **조회·수정·삭제·엑셀 다운로드**하는 어드민 핵심 화면입니다. 사용자가 출퇴근 위젯에서 남긴 기록이 집계되어 이 화면에 표시되고, 어드민이 출퇴근 기록을 직접 보정하면 다시 집계되어 사용자 화면에 반영됩니다.

- **전사 근무현황** 탭: 일별/월별 집계 결과 조회 + 엑셀
- **출퇴근 내역** 탭: 출퇴근 원본 기록 조회 + 어드민 직접 생성·수정·삭제 + 엑셀

## 4. 정책 · 비즈니스 룰

1. **근무시간 3종 정의**

   | 종류 | 정의 |
   |---|---|
   | 확정 근무시간 | 출퇴근 기록으로 계산된 유효 근무시간 (출퇴근만) |
   | 합산 근무시간 | 확정근무 + 근무인정 기타근무 − 휴가 (중복 구간 제외) |
   | 인정 근무시간 | 확정근무 + 근무인정 기타근무 + 근무인정 휴가 (중복 구간 제외) |

2. **산정 우선순위: 휴가 > 기타근무 > 출퇴근** — 같은 시간대가 겹치면 우선순위가 높은 것만 인정합니다.
3. 출근 인정 시각 이전의 출근 구간은 근무시간으로 인정하지 않습니다.
4. **어드민 직접 기록은 보정 기록 추가** 방식입니다. 원본은 그대로 두고, 삭제도 무효화 기록으로 처리합니다(사용자 화면에는 "누락").
5. **편집 차단**: 해당 날짜의 근무가 마감됐거나, 출근·퇴근·통합 근무내역 변경 신청이 결재중/수신처 처리중이면 직접 기록을 만들거나 고칠 수 없습니다. 마감 여부를 먼저 판단합니다.
6. **첫 기록 보호**: 출퇴근 기록이 없던 날의 첫 출퇴근 항목은 삭제할 수 없습니다.
7. **그룹 룰 준수**: 잔여 연장근무 시간을 넘는 기록은 어드민도 저장할 수 없습니다.
8. **사용자 측 영향**

   | 어드민 동작 | 사용자 화면 |
   |---|---|
   | 출퇴근 기록 직접 생성 | 캘린더에 기록 표시 + 관리자 등록 안내 |
   | 출퇴근 기록 직접 수정 | 출퇴근 위젯 버튼이 "근무 내역 변경"으로 바뀜 |
   | 출퇴근 기록 삭제 | 해당 기록이 "누락"으로 표시 |
   | 수정된 날짜에 사용자가 근무내역 변경 신청 | 신청 차단 + 안내 |
   | 수동 일/월 집계 실행 | 근무 요약 위젯·내 근무 데이터 재계산 |

9. 엑셀 다운로드는 감사 로그를 위해 **사유 입력이 필수**입니다(전사 근무현황·출퇴근 내역 모두). 편집 창의 "등록 사유"는 선택 입력입니다.
10. **조회 기간 제한**: 전사 근무현황 일별 60일, 출퇴근 내역 31일.

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 잔여 연장근무 시간 초과 기록 저장 | 저장 실패 — 초과 단위별 "일 단위 초과근무 제한시간을 초과합니다" / "주 단위 초과근무 제한시간을 초과합니다" / "월 단위 초과근무 제한시간을 초과합니다" / "월(휴일) 단위 초과근무 제한시간을 초과합니다" |
| 진행 중 신청서가 있는 날짜 선택 | "동일한 일자에 요청 중인 통합 근무내역 변경 신청이 있어, 통합 근무내역을 변경할 수 없습니다." + [적용] 비활성 |
| 마감된 날짜 선택 | "선택한 일자의 근무가 마감되어 통합 근무내역을 변경할 수 없습니다." + [적용] 비활성 |
| 오늘 이후 근무일 선택 | "근무일은 현재 날짜 이전으로만 선택할 수 있습니다." |
| 출퇴근 기록이 없는 날 선택 | "해당 날짜의 근무내역 존재하지 않습니다." / "(근무 내역 누락 상태)" |
| 첫 출퇴근 항목 삭제 | 삭제 버튼 비활성, 툴팁 "출퇴근 내역이 없는 날짜이므로 근무 내역 삭제가 불가합니다" |
| [적용] 클릭 | 확인창 "통합 근무내역 변경 확인" / "{이름}님의 통합 근무내역을 변경합니다. (적용일 : YYYY.MM.DD)" → "통합 근무내역 변경을 완료하였습니다." |
| 전사 근무현황 일별 기간 초과 | "조회 실패" / "조회 기간은 60일 이내로 해주십시오." |
| 조회 기간 미입력 | "조회 실패" / "조회 기간을 설정해주세요." |
| 출퇴근 내역 31일 초과 조회 | "조회 기간은 최대 31일 이내여야 합니다." |
| 엑셀 다운로드 사유 미입력 | 다운로드 불가 |
| (사용자) 어드민이 수정한 날짜에 근무내역 변경 신청 | "해당 일자의 근무내역은 어드민이 수정 및 확정하였습니다." ([요청] 비활성) |
| (사용자) 어드민이 등록한 근무 확인 | "해당 근무는 별도의 신청/승인 과정 없이 관리자에 의해 등록되었습니다." |

## 7. 확인 필요

- 어드민 직접 등록 기타근무의 사용자 측 흐름 전체 (확인된 부분: 사용자 화면 3곳에서 "관리자에 의해 등록" 안내 + 등록 사유 표시)
- 진행 중 신청서 차단 안내문이 출근·퇴근 신청인 경우에도 "통합 근무내역 변경 신청"으로만 표기되는데, 문구를 신청서 종류별로 나눌지 (실제 고객 문의에서 혼선 발생 확인. 문구 분리 계획은 확인되지 않음)
