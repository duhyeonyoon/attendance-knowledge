> **원본** `product/_legacy/admin-system-entry.md`

*원본 섹션: #2-2. 조직 설정 (L46–50) — Read Only* — 2026-11-05 코드로 화면 구성 보강 (`ad:src/components/attendance/module_setting/organization/`)

## 화면 구성

| 영역 | 구성 요소 |
|------|------|
| 헤더 | 타이틀 "조직 설정" + **[관리자 일괄 수정] · [새 조직 추가] 버튼 항상 비활성** (툴팁 "인사관리 모듈에서 설정이 가능합니다.") + [조직 엑셀 다운로드] |
| 연동 안내 (talenx 인사관리 연동 시) | "조직-구성원 연동 중입니다. 연동 시스템에서 조직-구성원 정보를 수정해야 합니다." / 연동 구분 / 마지막 연동 일자 |
| 조직 트리 | 조직명 · 조직장(2명 이상이면 "OOO 등 N명", 툴팁에 이름(사번) 목록) · 구성원 수("N명") · 돋보기(상세보기) |
| 조직 상세 다이얼로그 "조직 상세 정보" | 조직명 · 조직장(비활성이면 "(비활성)", 겸직이면 "(겸)") · 상위 조직 · 하위 조직 추가 · 구성원 표(이름 · 사번 · 활성 여부 · 조직) — 전 필드 disabled, [조직 삭제] [수정] [확인] 모두 비활성 |

- **인사 모듈과 연동된 조직 정보** 노출
- **조직 엑셀 다운로드**: 사유 입력 모달 "조직 데이터 엑셀 다운로드" 후 다운로드 (`ExcelDownloadReasonDialog`) — **(2026-11-05 해소) 구성원 정보와 동일하게 사유 입력 필수**
  - 엑셀 컬럼: 번호 · 조직명 · 조직 경로 · 조직장 · 조직장 사번 · 구성원 수, 파일명 `조직 정보_<일시>`
  - 데이터 없으면 "엑셀 다운로드 가능한 데이터가 없습니다." / 실패 시 "조직 정보 다운로드에 실패했습니다."
- 조직 상세 조회 (관리자/구성원, **퇴직자 미조회**)
- 조회 실패: "조직 정보를 불러오는데 실패했습니다."

> 조직은 인사 모듈에서만 정의. 근무 모듈에서는 readonly.
