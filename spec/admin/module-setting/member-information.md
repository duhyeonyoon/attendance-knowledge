> **URL** `/attendance/module_setting/member_information_management`
> **사용자** 어드민(근무 총괄)

## 1. 개요
근무 모듈에 등록된 구성원 데이터를 조회하고, 구성원별 연차기산일(연차 산정 시작일)을 관리하는 화면입니다. 인사 모듈과 연동된 경우 인사 쪽 구성원 데이터가 이 화면에 반영됩니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 상단 | 타이틀, [구성원 등록] | [구성원 등록]은 항상 비활성 |
| 연동 안내 | "조직-구성원 연동 중입니다. 연동 시스템에서 조직-구성원 정보를 수정해야 합니다." / "연동 구분: talenx 인사관리" / 마지막 연동 일자 | talenx 인사관리와 연동 중일 때만 노출 |
| 필터 | 입사일 기간, 구성원, 회사, 조직, 휴가 그룹, 근무 그룹, 활성 상태, [조회], [필터 재설정] | 구성원 목록 필터링 |
| 목록 | 사번, 이름, 성별, 입사일, 연차기산일(편집), 휴가 그룹, 근무 그룹, 회사, 조직, 조직장 여부, 겸임/겸직, 직책, 직급, 직위, 호칭, 휴직 여부, 퇴사 여부, 퇴사일, 활성 여부, 생성시간, 인사 정보(재직 상태 · 활성 상태) | 페이지 단위 조회. 연차기산일 컬럼은 숨길 수 없음 |
| 목록 하단 | [항목 설정], [엑셀 다운로드], [변경 내용 취소], [저장] | [변경 내용 취소]/[저장]은 연차기산일 수정 시 활성화 |

## 3. 기능 상세
### 3.1 조회
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-MOD-MEM-01 | 필터링 | 입사일 기간 · 구성원 · 회사 · 조직 · 휴가 그룹 · 근무 그룹 · 활성 상태 조건으로 구성원 목록 조회 | — |
| A-MOD-MEM-02 | 필터 재설정 | [필터 재설정] 클릭 시 필터 값만 초기화 | 재조회는 하지 않음 |
| A-MOD-MEM-03 | 엑셀 다운로드 | "구성원 정보 엑셀 다운로드" 사유 입력 모달 후 다운로드 | 사유 입력 필수. 파일명 "구성원_정보_날짜" |
| A-MOD-MEM-04 | 인사 연동 정보 표시 | 인사 모듈 연동 중이면 페이지 상단에 연동 정보 노출 | 연동 안 함이면 미노출 |
| A-MOD-MEM-08 | 항목 설정 | [항목 설정]으로 목록 컬럼 표시 여부·고정 위치 변경 | 연차기산일 등 편집 컬럼은 숨김 불가 |

### 3.2 연차기산일 관리
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-MOD-MEM-05 | 연차기산일 수정/삭제 | 목록의 연차기산일 칸에서 날짜를 입력하거나 지움 | 수정이 발생하면 [변경 내용 취소] / [저장] 버튼 활성화. 유효하지 않은 날짜는 빨간 글씨로 표시되고 [저장] 비활성 |
| A-MOD-MEM-06 | 변경 내용 취소 | 수정한 내용을 수정 전 값으로 되돌림 | — |
| A-MOD-MEM-07 | 저장 | 수정한 연차기산일 저장 | 저장 실패 시 수정 내용이 초기화됨 |

## 4. 정책 · 비즈니스 룰
1. 연차기산일은 연차 산정의 시작일입니다. 연차기산일이 비어 있으면 입사일 기준으로 산정합니다 (화면 안내: "연차기산일 입력시 입사일 대신 해당 날짜를 기준으로 연차를 산정합니다."). 연차기산일이 1월 1일이 아니고 입사일 기준인 경우, 구성원 휴가 현황에서 귀속연도가 분리되어 연차가 두 행으로 조회될 수 있습니다.
2. 연차기산일을 바꿔도 **이미 생성된 연차는 다시 계산되지 않습니다.** 바뀐 기산일은 다음 연차 자동 생성 때부터 반영됩니다. 기존 연차의 사용 시작일과 새 기산일이 어긋나면 [연차 관리](../leave/annual-management.md)의 연차 조정이 막힐 수 있습니다.
3. 인사-근무 연동 중에는 구성원 추가/비활성이 인사 발령으로 결정됩니다 ([연동](../etc/sync.md) 참고). [구성원 등록]은 현재 사용할 수 없습니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 엑셀 다운로드 | 사유 입력 모달 노출 |
| 유효하지 않은 연차기산일 입력 | 빨간 글씨 표시, [저장] 비활성 |
| 저장 시 형식 오류 (서버) | "유효하지 않은 연차기산일을 포함합니다: (값)" |
| 저장 성공 | 목록 재조회 |
