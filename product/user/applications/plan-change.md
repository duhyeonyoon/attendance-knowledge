# 근무계획 변경 신청

> **메뉴** 근무 신청 › 근무계획 변경  
> **원본** `product/_legacy/appl-other-forms.md`

*원본 섹션: 4. 근무계획 변경 신청 (U19)*

**조건**: 어드민 근무그룹 설정 > 근무 신청서 관리 > 근무계획 변경 신청 **사용 여부 ON** (시드 데이터는 ON 상태). `KB:product/admin/work/group-setting.md` § "근무 신청서 관리" 참조. ~~현재 이 섹션에서 설정 가능한 유일한 신청서가 근무계획 변경~~ → **(2026-11-05 정정)** 근무 신청서 관리 목록은 근무계획 변경 / 근무계획 수립 / 통합 근무내역 변경 / 연장·휴일(사전·사후) / 대체근무로 확장됨 (`ad:src/locales/ko/attendance.json:228-240`). 사용 중지 시 "신청 불가 안내" / "신청서 사용이 중지되었습니다." 모달

**선택적 근로제 그룹 (2026-11-05 추가)**: 근무제 유형이 선택적 근로제인 근무그룹에서는 근무계획 변경 신청을 쓸 수 없고, [근무계획 수립 신청](./work-plan-establishment.md)(1031)으로 근무계획을 수립·변경한다. 어드민 툴팁 원문 "근무제 유형이 선택적 근로제인 근무그룹에서는 사용할 수 없습니다. 선택적 근로제 근무그룹은 근무계획 수립 신청서로 근무계획을 수립 및 변경합니다." (`ad:src/locales/ko/attendance.json:303`)

**핵심 개념 — 개인스케줄 vs 그룹스케줄** (체크리스트 L809–815):

```
개인스케줄: 사용자 화면의 근무스케줄 또는 근무계획 변경으로 생성된 스케줄
그룹스케줄: 근무그룹의 그룹스케줄에서 생성된 스케줄
우선순위: 개인스케줄 > 그룹스케줄 (개인 있으면 그룹 변경해도 적용 안 됨)
```

알려진 문제 (QA에 🚨 표시):
- 근무그룹 변경 시 개인스케줄이 삭제되지 않아서 이전 근무그룹 스케줄이 잔존 가능 (처리 예정) — **(2026-11-05 Slack 확인) 2026-11 현재 미해결, 고도화 미착수.** 계산은 남은 개인스케줄을 우선 적용하고 일부 화면만 현재 그룹 기준으로 걸러 보이지 않음. 운영은 고객 확인 후 개발자 데이터 삭제 + 재집계 (상세 [공통](./overview.md) § 알려진 제약)
- 위 경우 사용자 화면 근무스케줄에서 변경된 그룹의 개인스케줄 변경 확정해야 함
- **(2026-11-05 Slack 확인) 결재 완료 후 되돌리기**: 사용자·어드민 모두 승인 취소 기능 없음 → 원래 템플릿으로 근무계획 변경을 **다시 신청**. 미래 일자는 어드민 개인 근무 스케줄 관리에서 개인 스케줄 삭제도 가능(신청서는 남음) — #channeltalk 2026-11-03 https://hcgtheplus.slack.com/archives/C06ULEEM88M/p1793671272279939?thread_ts=1793668757.494899

**진입 경로**:
1. 과거 근무내역 변경요청서 → 유형을 근무계획 변경으로 변경
2. 내 근무 캘린더에서 클릭 가능한 케이스:
   - **오늘 / 미래 + 근무계획이 근무일**인 경우 (✅ 클릭 가능)
   - 미래 + 근무계획 미정 / 휴일 / 휴무일 (❌ 클릭 불가)
3. 출퇴근 위젯의 근무신청

**유효한 요청일**:
- "근무일" 근무계획으로 이루어진 기간
- "근무일" + "휴일"/"휴무일" 혼합 기간

**기간 유효성 (5가지)** — 동일 기간에 여러 밸리데이션이 있어도 **가장 가까운 것 1개만 노출**:

(2026-11-05 생략 없는 원문으로 교체, `pp:src/locales/ko/workflow.json` `PLAN_EDIT.validation.*`. `{기간}`은 해당 기간 표기)

| 케이스 | 메시지 |
|------|------|
| 선택 기간에 미정 근무계획 있음 | "선택한 기간에 기존 근무계획이 정해져 있지 않은 기간이 존재합니다.({기간})" + "근무계획이 존재하는 기간으로 요청일을 변경해주세요." |
| 선택 기간에 근무그룹 변경 있음 | "요청 시작일에 속한 근무그룹에 대해서만 근무계획을 변경할 수 있습니다.(~ {기간} 종료)" |
| 선택 기간에 요청된 근무계획 변경 있음 | "선택한 시간에 요청된 근무계획 변경 사항이 있습니다. 요청중인 기간의 근무계획은 변경할 수 없습니다.({기간})" |
| 선택 기간에 요청된 대체근무 신청 있음 | "선택한 기간에 요청된 대체근무 신청이 있습니다. 요청중인 기간의 근무계획은 변경할 수 없습니다.({기간})" |
| 선택 기간 전체가 휴일 | "선택한 요청일이 모두 휴일입니다. 근무 스케줄이 있는 근무일을 포함하여 선택해주세요.(휴일, 휴무일은 변경대상에서 제외됩니다)" |
| 마감된 기간 포함 | "선택한 기간의 근무가 마감되어 근무계획 변경을 할 수 없습니다." |

**변경 결과**:
- 기간은 휴일/휴무일 선택 가능하지만 **실제 변경은 불가** — **근무일 템플릿만 변경 가능**
- 기존 근무계획에 휴일은 노출되지 않음
- 기간으로 선택 시 기존 근무계획이 다르면 기간 별로 표시

**변경할 근무 계획 유효성**:
- 변경 이전과 이후 모두 동일 → "변경 이전과 이후가 동일합니다."

**근무 계획 변경 신청서 설정 유효성** (어드민에서 설정한 룰):
- 변경 대상 기간 외 일자 → 캘린더에서 비활성화 ("{시작} ~ {종료}까지의 근무계획만 변경 가능합니다.", 시작/종료는 "전월 1일"·"당월 말일" 등)
- 신청 가능 기간 외 → 경고 모달 "신청 가능한 기간이 아닙니다. (신청 기간: 매월 N일~M일)" + 신청서 닫힘
- 파일 첨부 / 코멘트 필수 여부 → "첨부파일을 업로드합니다." / "코멘트를 입력합니다."
- 과거 근무계획 변경 시 안내 "과거 근무계획을 변경하면 변경된 계획을 기준으로 근무시간을 재산정합니다." 

**마감 차단**: 요청/승인 불가
