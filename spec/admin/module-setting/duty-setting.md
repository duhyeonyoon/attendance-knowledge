> **URL** `/attendance/module_setting/duty_setting`
> **사용자** 어드민(근무 총괄)

## 1. 개요
근무 모듈에서 사용하는 직책 목록을 조회·관리하는 화면입니다. 인사 모듈과 연동된 경우에는 조회 전용이며, 근무 단독(인사 연동 안 함)으로 운영할 때는 직책을 직접 생성·수정·삭제하고 보기 순서를 바꿀 수 있습니다. 여기서 관리하는 직책은 직책자 권한의 직책그룹 구성 기준이 됩니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 상단 | [직책 생성], 인사 연동 정보 | 연동 정보는 인사 모듈 연동 시에만 노출. 연동 중에는 [직책 생성] 비활성 |
| 직책 목록 | 직책명, 구성원 수, 삭제, 상세, [순서 변경] | 운영 모드에 따라 노출 직책이 다름 (4.1 참고) |
| 직책 상세 | 직책명, 구성원 표(이름 · 사번 · 활성 여부 · 조직), [수정] | 여러 조직 본발령 + 겸 소속은 툴팁 표시 |

## 3. 기능 상세
### 3.1 조회
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-MOD-DUT-01 | 인사 연동 정보 표시 | 연동 중이면 상단에 연동 정보 노출, 화면은 조회만 가능 | — |
| A-MOD-DUT-02 | 직책 목록 조회 | 운영 모드별 규칙에 따라 직책 노출 | 퇴직자는 미조회 |
| A-MOD-DUT-03 | 직책 세부 조회 | 직책 보유자 조회 | 동일 직책을 여러 조직에 본발령 + 겸 소속한 경우 툴팁으로 표시 |

### 3.2 근무 자체 관리 (인사 연동 안 함)
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-MOD-DUT-04 | 직책 생성 | 신규 직책을 목록 상단에 생성 | 직책명 중복 불가, 최대 20자 |
| A-MOD-DUT-05 | 직책 수정 | 직책명 수정 | 직책명 중복 불가, 최대 20자 |
| A-MOD-DUT-06 | 직책 삭제 | 삭제(X) → "삭제 요청" 확인 → 삭제 | 구성원이 있는 직책, 직책자 권한 그룹에 포함된 직책은 삭제 불가 |
| A-MOD-DUT-07 | 보기 순서 변경 | [순서 변경] → 순서 조정 → [저장] / [취소] | — |

입력 항목

| 항목 | 필수 | 형식/기본값 | 설명 |
|---|---|---|---|
| 직책명 | Y | 최대 20자, 중복 불가 | 미입력 시 "직책명이 없습니다." |

## 4. 정책 · 비즈니스 룰
### 4.1 직책 목록 노출 규칙
| 운영 모드 | 노출되는 직책 |
|---|---|
| 근무 단독 모듈 | 클라이언트의 모든 직책 |
| 인사 + 근무 연동 중 | 인사 발령이 있는 직책 + 인사 연동 이전에 근무에서 추가한 직책 |
| 공통 | 퇴직자는 미조회 |

1. 인사 연동 중에는 직책 생성·수정·삭제가 불가하며 조회만 가능합니다.
2. 인사에서 새 직책을 추가해도 해당 직책의 인사 발령이 없으면 근무 모듈에 연동되지 않습니다.
3. 인사 연동을 해제하면 근무 모듈에서 직책을 자체 관리하는 모드로 전환됩니다.
4. 직책자 권한의 직책그룹에 포함된 직책은 그룹에서 먼저 제외해야 삭제할 수 있습니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 직책명 미입력 | "직책명이 없습니다." |
| 중복 직책명 입력 | "이미 존재하는 직책입니다." |
| 20자 초과 입력 | "직책명은 최대 20자까지 입력할 수 있습니다." |
| 수정 시 변경 내용 없음 | "변경사항이 없습니다." |
| 생성 / 수정 성공 | "새 직책이 생성되었습니다." / "직책 정보가 저장되었습니다." |
| 삭제 확인 | "삭제 요청" — "[직책명] 직책을 삭제하시겠습니까?" |
| 구성원이 있는 직책 삭제 시도 | "삭제 실패" — "해당 직책에 속한 구성원이 있습니다. 구성원 관리에서 해당 구성원 다른 직책으로 변경한 후 삭제 가능합니다." |
| 직책자 권한 그룹에 포함된 직책 삭제 시도 | "삭제 실패" — "해당 직책이 직책자 권한 그룹에 사용되고 있습니다. 권한 설정에서 해당 직책을 제외한 후 삭제 가능합니다." |
| 삭제 성공 | "직책이 삭제되었습니다." |
| 순서 변경 성공 / 실패 | "직책 순서 수정이 완료되었습니다." / "순서 변경 실패" |
