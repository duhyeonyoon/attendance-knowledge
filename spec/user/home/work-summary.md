> **메뉴** 통합홈 › 기간 근무시간 요약 카드 (실근무 / 소정근무 / 잔여근무)
> **사용자** 사용자(구성원 본인)

## 1. 개요

선택한 기간(월/주)의 **실근무 · 소정근무 · 잔여근무 시간**을 요약해 보여주는 위젯입니다. 통합홈과 근무관리 › 내 근무 화면 양쪽에 표시되며, 기간 단위를 바꾸면 두 화면 모두 갱신됩니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 헤더 | 제목, [설정] 버튼(홈) / 케밥 메뉴(내 근무) | 기간 단위 설정 모달 진입 |
| 본문 | 실근무 / 소정근무 / 잔여근무 | 기간 내 근무시간 요약 + 그래프 |
| 본문 상세 항목 | 실근무: 근무일 · 근무시간 · 기타 근무시간 · 휴가사용 · 인정 근무시간 · 연장/야간/휴일 근무시간 / 소정: 소정근로일 · 소정근로시간 · 최대근로시간 / 잔여: 잔여 근무일 · 잔여 소정근로시간 · 잔여 최대근로시간 | 화면 라벨 그대로 |
| 본문 | Info(?) 아이콘 | 항목 설명 툴팁 |
| 탭 (조건부) | 소정 근무시간 / 최소 근무시간 | 최소근무시간이 설정된 경우만 노출 |

## 4. 정책 · 비즈니스 룰

1. **주 단위** 조회 시 한 주의 시작 요일은 어드민 근무 설정 › 시간 조회 탭의 "한 주의 시작 요일"을 따릅니다. 회사별 설정이 우선이고, 없으면 클라이언트 기본 설정을 적용합니다.
2. 최소 근무시간 탭 동작:

| 탭 | 표시 |
|---|---|
| 소정 근무시간 (기본) | 실근무 / 소정근무 / 잔여근무 |
| 최소 근무시간 | 실근무 정보만, 그래프 기준 = 최소근무시간 |

3. 최소 근무시간 표시는 특정 고객사 커스텀이며 해당 고객사 데이터(덤프) 환경에서만 테스트할 수 있습니다.
4. 수치는 정산기간이 아니라 **선택한 기간(월/주)** 기준으로 집계합니다. 선택 기간이 정산기간과 어긋나도 정산기간 값을 나눠 쓰지 않고, 선택 기간 자체로 다시 계산합니다 (기획 확인 2026-11-05).

   | 항목 | 계산 |
   |---|---|
   | 소정근로일 | 선택 기간 안의 근무 계획일 수 |
   | 소정근로시간 | 근무 그룹의 소정근로시간 기준이 '법적 기준'이면 주 40시간 ÷ 7 × 선택 기간 달력일수, '근무 계획 기준'이면 선택 기간 근무 계획 시간의 합 |
   | 최대근로시간 | 주 52시간 ÷ 7 × 선택 기간 달력일수 |
   | 잔여 소정·최대근로시간 | 위 값 − 인정 근무시간(휴가·기타근무 인정분 포함). 이미 채웠으면 0 |
   | 잔여 근무일 | 오늘을 제외한 이후 계획 근무일 (주말·휴일 제외, 기간 종료 시 0) |
   | 인정 근무시간 | 근무시간 + 인정되는 기타근무 + 인정되는 휴가 사용시간, 겹치는 시간대는 한 번만. 오늘이 포함된 기간은 전날까지만 집계 |

   선택 기간 중 근무 그룹이 바뀌면 그룹별 구간으로 나눠 계산해 더합니다.
5. 근무 그룹이 "근무시간 화면 표시 안 함"이면 통합홈에서 이 위젯이 표시되지 않습니다.
6. 각 항목의 ⓘ 안내 문구 예: 최대근로시간 "조회 기간 내 연장근무를 포함해 근무할 수 있는 법정 최대 기준 시간입니다." "주 52시간 기준으로 조회 기간 달력일수에 비례해 계산됩니다." / 근무일 "휴가나 기타근무만 있는 날은 근무일수에 포함되지 않습니다." / 잔여 소정근로시간 "소정근로시간에서 인정근무시간을 차감한 잔여 시간입니다."
