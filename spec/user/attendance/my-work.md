> **메뉴** 근무관리 › 내 근무
> **URL** `/attendance/work`
> **탭** (요약) 실근무 · 소정근무 · 잔여근무 + 근무 캘린더
> **사용자** 사용자(구성원 본인)

## 1. 개요

사용자가 매일 보는 핵심 화면입니다. 한 달의 **근무 기록 · 근무 계획 · 휴가 · 기타근무 · 재택 · 진행 중 신청서**가 날짜별 캘린더 셀 하나에 종합되어 표시됩니다.
과거는 집계된 근무 결과, 오늘은 출퇴근 위젯의 실시간 상태, 미래는 근무 계획(=근무 스케줄)을 보여주며, 셀을 클릭해 근무내역 변경·근무계획 변경 등 신청서로 바로 진입합니다.

## 4. 정책 · 비즈니스 룰

### 4.1 시점별 표시

| 시점 | 표시 내용 |
|---|---|
| 과거 | 집계 기준 근무 결과. 휴일이면 휴일, 누락 조건 해당 시 "누락" |
| 오늘 | 출퇴근 위젯 이벤트 결과를 실시간 반영 |
| 미래 | 근무 계획(스케줄). 없으면 "미정" |
| 자정 ~ cutoff 이전 | 전날 데이터로 판정. cutoff = 계획 출근시각 − 3시간, 계획 없으면 06:00 ([출퇴근 위젯](../home/checkin-widget.md) 4.6과 동일) |

### 4.2 누락 판정 (과거 일자)

다음 중 하나라도 해당하면 "누락"으로 표시합니다.

1. 출퇴근 기록의 출근/퇴근 쌍이 맞지 않는다.
2. 출퇴근 기록이 없거나, 집계된 근무시간이 0이다.
3. (출퇴근 기록이 있을 때) 자리비움 시작/종료 쌍이 맞지 않는다.

판단 대상은 근무일이며, 근무일이 아니어도 기록이 생기면 같은 기준으로 판단합니다. 다음 경우는 누락으로 표시하지 않습니다.

- 종일 휴가이거나 종일 휴가를 요청 중
- 출근/퇴근 요청 중이거나 근무내역 변경 요청 중
- 승인된 종일 기타근무가 있는 날 (휴일·휴무일 제외)

### 4.3 근무시간 인정

| 상황 | 인정 결과 |
|---|---|
| 근무내역 변경 승인 | 입력한 근무시간 모두 인정 |
| 연장근무 자유 허용 | 입력한 근무시간 모두 인정 |
| 연장근무 미승인 | 표준근무시간 내만 인정, 나머지 비근무 |
| 연장근무 일부 승인 | 표준근무 + 승인된 연장시간만 인정, 나머지 비근무 |
| 휴일 | 사전 휴일근무 신청으로 승인된 시간만 인정 |

- 이 규칙은 스프린트 #38 배포 이후 집계된 데이터에만 적용됩니다 (이전 데이터는 집계 로직이 다름).

### 4.4 우선순위 · 가림 규칙

**셀 안 표시 순서** (데스크톱은 앞에서부터 3개, 태블릿 2개): 휴일 → 휴무일 → 근무 계획/근무 기록 → 근무 관련 요청 → 휴가 → 휴가 요청 → 기타근무 → 재택 → 기타근무 요청 → 근무계획 변경 요청 → 대체근무 요청 → 휴일근무(승인) → 연장근무(승인)

| 조건 | 결과 |
|---|---|
| 미래(출근 가능 시각 전) + 근무계획 변경 신청 진행 중 | 근무 계획 숨기고 요청 중만 표시 |
| 근무 관련 요청 중 문서 있음 | 근무 계획·기록 숨김 — **단, 연장/야간(사전·사후) 신청·취소가 있으면 예외** (함께 표시) |
| 대체근무·휴가·기타근무 요청 중 | 근무 계획은 그대로 표시하고 요청 항목 추가 (요청 중인 신청은 승인 전까지 계획을 바꾸지 않는다는 원칙, 기획 확인 2026-11-05) |
| 종일 휴가 + 미래 / 종일 휴가 요청 중 / 종일 휴가 + 근무 없음 | 근무 기록·계획 자체 숨김 |
| 휴일 또는 휴무일 + 근무 없음 | 근무 기록·계획 숨기고 "휴일"/"휴무" |
| 휴가·기타근무 취소 요청 중 | 원래 휴가·기타근무 항목 숨기고 "취소중"만 |

**모바일 대표 항목 (1셀 1개)**

1. 휴일근무·휴무일근무 날 → 근무 기록
2. 종일 휴가가 아닌 날 → 표시 순서의 첫 항목
3. 종일 휴가 날(휴가 1건) → 휴가
4. 그 외 → 첫 항목

나머지 항목은 날짜 아래 색 점으로 표시합니다 (휴가·재택·근무·기타근무 4종, 같은 종류는 1개).

### 4.5 기타

1. 근무시간 표시 안 함 그룹 + 출근 인정 시각 이전 출근 → 근무내역 변경 신청서에서 첫 출근시간이 **출근 인정 시각으로 보정**되어 표시됩니다.
2. 근무내역 변경·출퇴근 내역 변경 신청이 **승인 완료**된 날(오늘)은 출퇴근 위젯에서 출근/퇴근 버튼 대신 [근무 내역 변경] 버튼만 보입니다. 캘린더에서의 변경 신청은 막지 않습니다.
3. 근무 마감된 일자는 신청서가 열리지만 경고 문구가 표시되고 요청할 수 없습니다.
4. 근무 계획 = 근무 스케줄(동의어)이며, 계획 이름은 적용된 근무 템플릿 이름입니다.

**다른 기능의 결과가 캘린더에 반영되는 방식**

| 동작 | 셀 표시 |
|---|---|
| 출근 / 퇴근 / 자리비움 | 오늘 셀 "근무중" / "퇴근" / "자리비움" |
| 휴가 신청 → 승인 | "요청중"(휴가) → "휴가" |
| 기타근무 신청 → 승인 | "요청중"(기타근무) → 기타근무 이름 |
| 사전 휴일근무 / 연장·야간 승인 | "휴일근무" / "연장/야간근무" 추가 (오늘 이후, 출퇴근 전까지) |
| 근무계획 변경 신청 | "요청중" (미래면 계획 숨김) |
| 대체근무 신청 | "요청중" 추가 (계획은 유지) |
| 관리자 휴가 수동 등록 / 기타근무 직접 등록 | "휴가" / 기타근무 + 별도 확인 모달 |
| 어드민 휴일 추가, 근무 템플릿·출근지 변경 | 미래 셀의 휴일 / 근무 계획 정보 변경 |
