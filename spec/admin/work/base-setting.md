## 1. 개요

고객사(클라이언트) 단위의 **근무 마스터 데이터**를 정의하는 화면입니다. 회계연도·한 주의 시작 같은 시간 기준과, 휴일·출근지·근무 템플릿·기타근무 항목의 공통 목록을 여기서 관리합니다.

근무 그룹은 이 마스터를 상속받아 **사용 여부만 토글**하거나(휴일·출근지·기타근무 항목), 목록에서 골라 추가합니다(근무 템플릿). 따라서 이 화면의 변경은 모든 근무 그룹과 사용자 화면(출퇴근, 캘린더, 근무 스케줄)에 영향을 줍니다.

> 화면 이름 주의: 근무 그룹 상세의 "근무설정 탭"과는 다른 화면입니다. 이 화면은 고객사 공통 설정입니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 시간 조회 | "기본 설정"(회계연도 시작일, 한 주의 시작 — 조회 전용), "회사별 설정"(회사별 한 주의 시작 목록), [회사별 설정 추가] / [추가] | 회사별 한 주의 시작만 "회사 기준 추가" 모달로 등록 |
| 휴일 설정 | 리스트/캘린더 보기 전환, 동기화 버튼, [휴일추가], 사용중/사용안함 필터, 연도 이동 화살표 | 법정 공휴일·회사 휴일·근무그룹 휴일을 한 화면에 표시 |
| 출근지 설정 | 출근지 리스트, 사용중/사용안함 필터, [출근지 추가] | 공통 출근지 관리 + 근무그룹 출근지 조회 |
| 근무 템플릿 | 템플릿 리스트, 추가 → 상세 페이지 | 근무 계획(스케줄)의 종류 정의 |
| 기타근무 항목 설정 | 항목 리스트, 추가 → 상세 페이지 | 출장 등 기타근무 항목 정의 |

### 3.2 휴일 설정

휴일 유형은 3가지입니다.

| 유형 | 만드는 곳 | 영향 범위 | 이 화면에서 |
|---|---|---|---|
| 법정 공휴일 | 시스템(HCG) 관리, 동기화로 반영 | 고객사 전체 | 사용여부 / 유무급 / 메모만 수정 |
| 회사 휴일(공통) | 이 화면 | 고객사 전체(모든 근무그룹) | 추가·수정·삭제 |
| 근무그룹 휴일 | 근무 그룹 설정 | 해당 근무그룹만 | 조회만 |

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-WRK-SET-03 | 법정 공휴일 동기화 | 동기화 버튼으로 시스템 관리 법정 공휴일을 갱신 | 당해 연도부터 미래만 가능. 과거 연도는 "이전 년도의 법정공휴일은 불러올 수 없습니다." |
| A-WRK-SET-04 | 회사 휴일 추가 | [휴일추가] 모달에서 입력 | 추가된 휴일은 모든 근무그룹의 휴일 관리에 자동 공유되며, 그룹별로 사용 여부를 끌 수 있음 |
| A-WRK-SET-05 | 휴일 수정 | 리스트 로우 / 캘린더 타이틀 클릭 → 휴일 수정 모달 | 법정 공휴일은 사용여부·유무급·메모만 수정 가능. 사용여부를 끄면 확인 모달 표시 |
| A-WRK-SET-06 | 휴일 삭제 | 수정 모달에서 삭제 | 미래 날짜만 삭제 가능. 과거·오늘 날짜 휴일은 삭제 불가 |
| A-WRK-SET-07 | 리스트 보기 (기본) | 현재 연도 휴일을 날짜 오름차순 표시, 페이지당 100건, 화살표로 연도 이동, 사용중/사용안함 필터 | 근무그룹 휴일은 info 아이콘 마우스 오버 시 생성한 근무그룹 표시 |
| A-WRK-SET-08 | 캘린더 보기 | 월별 캘린더. 휴일 적용 범위(법정/회사/근무그룹)에 따라 색상 구분 | 같은 날짜에 여러 휴일이 있으면 가나다 순 |

### 3.4 근무 템플릿

근무 템플릿 = **근무 계획(근무 스케줄)의 종류**입니다. 근무 그룹은 여기서 정의한 템플릿을 골라 그룹스케줄에 적용합니다.

| 유형 | 만드는 곳 | 영향 범위 | 이 화면에서 |
|---|---|---|---|
| 공통 템플릿 | 이 화면 | 모든 근무그룹의 "템플릿 추가" 모달에서 선택 가능 | 추가·수정·삭제 |
| 근무그룹 템플릿 | 근무 그룹 설정 (또는 그룹에서 공통 템플릿 수정 시 자동 생성) | 해당 근무그룹만 | 상세 조회만 (info 아이콘으로 출처 그룹 확인) |

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-WRK-SET-13 | 템플릿 목록 / 사용여부 | 사용 = 근무그룹 템플릿 설정의 전체 템플릿에서 추가 가능, 사용안함 = 노출 안 됨 | 사용 → 사용안함으로 저장하면 모든 근무그룹에서 해당 템플릿 연결이 해제됨. 다시 사용으로 바꿔도 그룹별로 다시 추가해야 함 |
| A-WRK-SET-14 | 템플릿 추가 / 수정 (상세 페이지) | 별도 상세 페이지에서 입력. 설정을 바꾸면 상단 버튼 영역의 근무정보 요약이 실시간 갱신 | 저장 시 밸리데이션(4장). 수정·삭제는 공통 템플릿만 가능, 근무구분은 생성 후 변경 불가. 템플릿명이 연결된 그룹의 사용 중 템플릿명과 겹치면 저장 불가 |
| A-WRK-SET-15 | 근무구분 분기 | 근무일 → 모든 속성 입력 / 휴일·휴무 → 템플릿명·색상만 입력(나머지 숨김) | — |
| A-WRK-SET-16 | 출근시간 분기 | 자유롭게 출근 → 코어타임 설정 가능 / 정해진 시각 → 고정 출근시간 필수 | 고정 출근시간 미입력 시 저장 불가 |
| A-WRK-SET-17 | 휴게시간 / 연장휴게시간 | 자동 적용 또는 고정 | 고정 선택 시 휴게시간 범위 1개 이상 필수 |

## 4. 정책 · 비즈니스 룰

1. **마스터–그룹 상속**: 이 화면 = 고객사 마스터, 근무 그룹 = 사용 여부 토글(근무 템플릿은 목록에서 선택 추가).

   | 영역 | 그룹에서 할 수 있는 것 | 마스터에서 사용안함 / 삭제 시 |
   |---|---|---|
   | 휴일(법정·회사) | 사용 여부 토글 | 그룹 휴일 관리 리스트에서 제외, 사용자 캘린더에 반영 |
   | 출근지(공통) | 사용 여부 토글 | 그룹 출근지 관리 리스트에서 제외, 사용자 출퇴근 위치 검증 대상에서 제외 |
   | 근무 템플릿(공통) | 전체 템플릿에서 골라 추가, 수정 시 그룹용으로 분리 저장 | 그룹 전체 템플릿에서 미노출 |
   | 기타근무 항목 | 사용 여부 토글 | 그룹 리스트·사용자 신청서 옵션에서 미노출. **삭제 시 모든 그룹 연결도 삭제** |

2. 근무그룹에서 만든 휴일·출근지·근무 템플릿은 이 화면에 **조회 전용**으로 표시되며 info 아이콘으로 출처 그룹을 확인합니다.
3. 공통 근무 템플릿을 근무그룹에서 수정하면 원본은 그대로 두고 "근무그룹" 구분 템플릿으로 새로 저장됩니다(복제, 기획 확인 2026-11-05). 저장 후 수정 불가 항목(휴게시간 계산 기준 등)은 이 화면의 템플릿이든 근무그룹 구분 템플릿이든 바꿀 수 없습니다 (추정 — 적용 범위가 이 항목들에 한정되는지 미검증).
4. 법정 공휴일 동기화는 **당해 연도부터 미래만** 가능합니다.
5. 휴일 삭제는 **미래 날짜만** 가능합니다(과거·오늘은 집계 데이터 보호를 위해 불가).
6. 회사별 한 주의 시작은 회사당 한 번만 등록할 수 있고, 등록 후에는 변경·삭제할 수 없습니다. 해당 회사 구성원의 근무 집계가 이미 있으면 등록 자체가 불가합니다.
7. 휴일·출근지 사용여부를 끌 때는 영향 범위를 알리는 확인 모달을 거칩니다.
8. 기타근무 항목은 다른 영역과 달리 **삭제가 그룹 연결까지 지웁니다** — 운영 중에는 삭제 대신 사용안함 처리를 권장(추정).
9. 근무 템플릿 저장 밸리데이션:

   | 조건 | 결과 |
   |---|---|
   | 지각 기준 시각 < 고정 출근 시각 | 저장 불가 |
   | 조퇴 기준 시각 < 고정 출근 시각 | 저장 불가 |
   | 조퇴 기준 시각 > 고정 퇴근 시각 | 저장 불가 |
   | 출근 인정 시각 > 고정 출근 시각 | 저장 불가 ("정해진 시각에 출근"일 때만 검사, "자유롭게 출근"은 생략) |
   | 출근 인정 시각 > 지각 기준 시각 | 저장 불가 (자유 출근에도 적용) |

10. 공통 근무 템플릿을 사용안함으로 바꾸면 모든 근무그룹에서 연결이 해제됩니다(재사용 시 그룹별 재추가 필요).
11. 출근 인정 시각은 자유/정해진 시각 출근 모두 설정 가능하며 근무시간 산정 효과도 같습니다(인정 시각 이전 출근 구간은 근무시간으로 인정하지 않음).

## 7. 확인 필요

- 기타근무 항목 기록 방식 "직접등록"이 언제 활성화되는지 (활성화 일정 미확인. 현재는 요청/승인 + 본인 결재선으로 대체 운영 안내)
- 근무그룹에서 공통 템플릿 수정 시 복제(4절 3번)가 실제 화면 동작과 일치하는지 검증
- 회사 휴일 추가·사용안함 처리가 근무그룹에 반영되는 시점(즉시 여부)
