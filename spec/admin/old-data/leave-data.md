> **메뉴** 근무관리 › 과거 데이터 관리 › 과거 휴가 데이터 관리
> **URL** `/attendance/old_data_management/leave_data`
> **사용자** 어드민(근무 총괄, 서브어드민)

## 1. 개요
서비스 도입 이전 또는 외부 시스템의 과거 휴가 데이터를 엑셀로 업로드해 조회 전용으로 보관하는 화면입니다. 필터·조회·업로드·삭제·권한 패턴이 [과거 근무 데이터 관리](./work-data.md)와 거의 같으므로, 공통 명세는 해당 페이지를 보고 이 페이지에는 차이점만 적습니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 필터 | 연도 필터(필수), 회사 · 구성원 · 조직 · 휴가 유형, [조회], [필터 재설정] | 연도 기본값: 올해, 지울 수 없음 |
| 목록 | 기본 정보 · 휴가 정보 · 부여 정보 · 사용 정보 · 잔여 정보 · 정산 결과 · 메모 (4.1 양식과 동일 컬럼) | 행 체크박스, [삭제] |
| 액션 | [과거 데이터 업로드] | 드래그 앤 드랍 모달, [엑셀 양식 다운로드] |

## 3. 기능 상세
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-OLD-LV-01 | 조회 | 진입 시 자동 조회 없이, [조회] 클릭 시 연도 필터로 조회 | 연도 필터 필수 |
| A-OLD-LV-02 | 엑셀 양식 다운로드 | 업로드 모달에서 양식 다운로드 | — |
| A-OLD-LV-03 | 과거 데이터 업로드 | 과거 근무와 동일한 업로드·밸리데이션 흐름 | 컨펌 문구만 "휴가" |
| A-OLD-LV-04 | 삭제 | 체크박스 선택 후 [삭제] | — |
| A-OLD-LV-05 | 권한별 조회 범위 | 근무 총괄 전체 / 서브어드민은 본인 소속 회사 사용자가 등록한 데이터만 | — |

## 4. 정책 · 비즈니스 룰
1. [과거 근무 데이터 관리](./work-data.md)의 정책을 동일하게 따릅니다 (조회 전용, 집계 영향 없음, 필수 필터, 수동 조회, 행별 밸리데이션, 권한별 조회 범위).
2. 과거 근무와의 차이:

| 항목 | 과거 근무 | 과거 휴가 |
|---|---|---|
| 필수 필터 기본값 | 이번달 연월 | 올해 연도 |
| 업로드 컨펌 문구 | "조회용 과거 근무 데이터" | "조회용 과거 휴가 데이터" |
| 데이터 단위 | 구성원 × 연도/월 | 구성원 × 휴가 유형 × 귀속연도 |
| 추가 필터 | — | 휴가 유형 |

### 4.1 엑셀 양식 (과거 휴가)
| 구분 | 컬럼 |
|---|---|
| 기본 | 사번 · 이름 · 회사 · 조직 · 직급 · 입사일 · 연차기산일 |
| 휴가 정보 | 휴가 유형 · 귀속연도 · 사용 시작일 · 사용 종료일 |
| 부여 정보 | 부여 · 자동 · 조정 · 부여-이월 (각 일 / 시간) |
| 사용 정보 | 사용 · 의무 사용 · 의무 사용외 (각 일 / 시간) |
| 잔여 정보 | 잔여 (일 / 시간) |
| 정산 결과 | 소멸 · 보상 · 정산-이월 (각 일 / 시간) |
| 기타 | 메모 |

- 필수: 사번 · 이름 · 회사명 · 휴가 유형 · 귀속연도 · 사용 시작일 · 사용 종료일
- 형식: 귀속연도 YYYY, 날짜 YYYYMMDD, 숫자는 소수점 아래 4자리까지

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 업로드 데이터 정상 | "총 n건의 조회용 과거 휴가 데이터를 추가합니다." 컨펌 |
| 업로드 완료 | 스낵바 |
| 필수값 누락 | "휴가유형명은 필수 입력 항목입니다." / "귀속연도는 필수 입력 항목입니다." / "사용시작일은 필수 입력 항목입니다." / "사용종료일은 필수 입력 항목입니다." 등 |
| 형식 오류 | "귀속연도 형식이 올바르지 않습니다. (YYYY)" / "날짜 형식이 올바르지 않습니다. (YYYYMMDD)." / "숫자 형식이 올바르지 않습니다. (소수점 아래 4자리까지 허용)." |
| 삭제 확인 | "과거 휴가 데이터 n건을 삭제합니다. 계속 진행하시겠습니까?" |
| 업로드 데이터 오류 | "총 n건에서 m개의 데이터 오류 확인이 필요합니다." + 오류 행 순차 표시 |
