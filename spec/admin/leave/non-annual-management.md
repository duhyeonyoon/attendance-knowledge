> **사용자** 어드민(휴가 담당자)

> 예전 "휴가 지급 및 관리" 화면에서 분리된 메뉴입니다. 탭 구성과 기능은 분리 전과 같고, 탭은 주소에 기억되어 새로고침해도 유지됩니다.

## 1. 개요
경조사·병가 등 연차 외 휴가를 구성원에게 지급(수동 지급)하고, 정산·삭제하며, 사용 기록을 조회·수동 등록하는 화면입니다. 조회 필터·엑셀 다운로드 등 탭 공통 동작은 [휴가 공통 정책](./overview.md) § 3.1을 따릅니다.

## 4. 정책 · 비즈니스 룰
1. 수동 휴가 지급 단위는 **시간만** 지원합니다(의도된 설계). 소정근로시간이 회사·사람마다 달라 "1일"이 8시간인지 7시간인지 모호하기 때문입니다.
2. 정산 방식은 보상 / 이월 / 소멸 3가지이며, 어느 방식이든 정산 후 잔여는 0이 됩니다.
3. 이월 정산한 휴가를 이미 사용했다면 정산을 취소할 수 없습니다.
4. 정산 완료 건, 사용분을 이관할 수 없는 건은 삭제할 수 없습니다.
5. 수동 지급한 연차 외 휴가는 **사용일수와 관계없이 귀속연도 기준**으로 사용자·매니저 화면에 조회됩니다. 같은 귀속연도에 같은 휴가를 여러 번 지급하면 건별 기한을 상세정보에서 확인할 수 있습니다.
6. 연차 외 휴가에는 초과 사용 기능이 없습니다. 그래서 사용 현황의 수동 등록에서 잔여가 부족한 건은 강제 등록 없이 자동 제외됩니다.
7. 정산이 완료된 귀속연도에는 같은 휴가 유형을 추가로 지급할 수 없고, 신청중 상태에서 정산이 완료된 휴가는 승인할 수 없습니다.
8. 정산 여부는 휴가의 마감(정산 완료) 여부로 판단합니다. 보상·이월·소멸 값은 정산이 완료된 경우에만 채워지며, 화면은 그 값을 그대로 표시합니다. (기획 확인 2026-11-05)

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 휴가 유형 선택 전 지급 대상에 마우스 오버 | "휴가 유형을 먼저 선택 후 지급대상을 선택합니다." |
| 정산 확인 | "ㅇㅇㅇ 등 n명에 대해 YYYY년도 (휴가명)를 정산(보상, 이월, 소멸) 및 마감합니다." + "요청중인 상태에서 정산이 완료된 휴가는 승인 불가로 처리되며, 정산이 완료된 귀속연도에는 동일한 휴가 유형을 추가로 부여할 수 없습니다." |
| 정산 취소 확인 | "… 진행된 YYYY년도 (휴가명) 정산을 취소합니다." + "휴가 마감이 해제되며 보상, 이월, 소멸 내역이 정산 전 상태로 복원됩니다. …" |
| 수동 등록 일부 불가 | "총 n건 중 m건의 휴가는 등록할 수 없습니다. 중복 휴가 및 휴가 부족 건은 등록이 불가하며 자동으로 제외됩니다. 이어서 진행하시겠습니까?" |
| 엑셀 A~F열 빈 값 / 형식 오류 | 행별 오류 다이얼로그 |
| 엑셀 검증 통과 | 총 데이터 건수 + 휴가별 지급 건수 다이얼로그 |
| 이월 정산 휴가 사용 후 정산 취소 | 오류 모달 |
| 삭제 불가 건 선택 후 삭제 | "연차 외 휴가 삭제 오류" — "부여한 휴가를 이미 사용했거나 정산 완료한 경우 휴가 삭제를 할 수 없습니다." + "삭제를 하기 위해서는 연차 외 휴가 사용현황 탭에서 휴가 사용 내역을 삭제하거나 정산 취소를 해주시기바랍니다." + 삭제 불가한 구성원 목록(사유: 휴가 사용 / 정산 완료) |
| 삭제 완료 | "연차 외 휴가 삭제를 완료하였습니다." |
