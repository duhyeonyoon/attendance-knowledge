# 2026-07-14 프로덕션 QA 검증 중 발견 사항

출처: [#063] 체크리스트 3차 테스트 (올인원컴퍼니 테스트 워크스페이스, 두현 AIO3673 / QA두현테스트 휴가그룹 / 정산기간1주그룹)

## 검증된 명세 (KB 내용 실증)

- **수동 휴가 지급 대상 노출 조건 실증**: 지급 대상 자동완성은 선택한 휴가 유형이 매핑된 휴가그룹 소속자만 노출. 유형이 어느 그룹에도 매핑 안 돼 있으면 항상 "No options" — 버그처럼 보이지만 정상 동작 (KB:product/admin/leave/overview.md C-2와 일치). 고객 문의 시 "휴가그룹에 해당 유형이 매핑되어 있는지" 먼저 확인할 것.
- **근무 마감**: 일괄 마감 캘린더에서 당일 포함 이후 날짜 선택 불가(과거만). 마감 시 사용자 휴가 신청 문구 "선택한 기간의 근무가 마감되어 휴가를 신청할 수 없습니다. 마감되지 않은 근무 일자에 한해 휴가 신청이 가능합니다.", 근무내역 변경 문구 "선택한 일자의 근무가 마감되어 근무내역을 변경할 수 없습니다." 해제(일괄 해제)는 마감 내역 탭에서, 해제도 이력 행으로 남음 (KB:product/admin/work/close-work-data.md와 일치).
- **연차 자동생성**: 그리드 체크박스 대상자 단위 생성, 연도별(2025/2026/2027) 실행. 조회 연도에 두 귀속연도 행(1년미만연차 + 연차) 동시 표시. 1년미만연차 개별기한 팝업은 "가장 사용기한이 빠른 휴가부터 표시" 정렬.
- **사전 휴일근무**: 동일 요청일 기존 문서 존재 시 안내 "선택한 날짜에 이미 신청한 휴일 근무가 있습니다. 기존 근무 정보와 중복이 아닌 경우에만 근무 신청이 가능합니다." + 기존 건 목록 표시. 승인건 취소는 별도 "사전 휴일근무 취소 신청" 결재 문서로 생성(기존 문서 링크 포함).

## 새 발견 / 확인 필요 (두현님 확인 요망)

1. **[버그 의심] 연차 외 휴가 개별기한 팝업 타이틀 오표기** — 구성원 휴가 현황에서 수동부여 휴가(연차 외)의 돋보기 팝업 제목이 "1년 미만 연차"로 나옴. 기능은 정상, 타이틀 하드코딩 의심. `pp` 쪽 개별기한 팝업 컴포넌트 확인 필요.
2. **간주근무제 그룹은 근무시간 제한 설정 불가** — 근무그룹 설정 > 근무시간 관리의 "최대 근무시간 제한"/"초과근무시간 제한" 라디오가 disabled(제한 없음 고정). 사전 휴일근무 신청서의 "잔여 N시간" 배지는 표시되지만 초과 신청이 차단되지 않는 현상(2차 🔍)과 연결 — 간주근무제에서 잔여 배지의 산정·강제 로직이 어디서 오는지 `be` 확인 필요.
3. **[불일치] 그룹 신청서 목록 vs 실동작** — 정산기간1주그룹 근무 신청서 관리에 "사전 휴일 근무 신청" 사용여부 "-"(미사용)로 표시되는데, 사용자 화면에서는 신청 노출·제출·승인 모두 가능. 설정 반영 시점/캐시/노출 조건(휴일근무 허용 설정 우선?) 확인 필요.
4. **Cmd+Z 되돌리기** — 근무스케줄 수정에서 스테이징·프로덕션 모두 자동화 키 입력으로 재현 실패. 실제 키보드 확인 필요 (자동화 CDP 조합키 특성일 가능성 잔존).
