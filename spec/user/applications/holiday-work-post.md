> **메뉴** 근무 신청 › 휴일 근무(사후)
> **진입** 출퇴근 위젯 [근무신청] › "휴일 근무(사후) 신청"
> **문서유형** "휴일 근무(사후) 신청" / "휴일 근무(사후) 취소 신청"
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
이미 지난 휴일에 근무한 시간을 **사후에** 승인받는 신청서입니다. 근무그룹의 휴일근무 허용이 '승인 시에만 근무 가능'이고, 어드민이 사후 신청서를 사용으로 켠 경우에만 보입니다(기본값은 미사용). 입력 방식과 시간 계산은 [휴일근무(사전) 신청](./holiday-work.md)과 같고, 고를 수 있는 날짜가 "오늘 이전의 휴일"이라는 점이 다릅니다. 승인되면 사전 승인과 똑같이 근무 집계에 반영되며, 실제 출퇴근 기록과 겹치는 시간만 휴일근무로 인정됩니다.

## 4. 정책 · 비즈니스 룰
1. 대상은 **현재 근무 귀속일 이전의 휴일**만. 휴무일 근무는 이 신청서 대상이 아님.
2. 메뉴는 휴일근무 허용 '승인 시에만 근무 가능' + 사후 신청서 사용일 때만 보임. 사후 신청서는 근무그룹별로 어드민이 켜야 함(기본 미사용).
3. 저장 시점에는 **신청 대상일의 근무그룹** 설정으로 다시 확인. 휴일근무 허용 '근무 불가'면 신청 불가.
4. 당일 과거 시각 정책은 적용하지 않음.
5. 시간 겹침은 **사전·사후 휴일근무 신청을 합쳐서** 판정 (신청일 전일~익일, 요청중·승인 건). 예: 사전 승인 18:00~20:00이 있으면 사후 19:00~21:00은 불가, 20:00~21:00은 가능.
6. 최대 초과근무 한도: 근무그룹 휴일근무 근무시간 포함여부가 '포함'이면 실제 휴일근무가 이미 집계돼 있어 서버는 추가 차감하지 않음, '승인시간만 포함'이면 신청 시간을 차감. (화면은 정책과 무관하게 신청 시간을 잔여와 비교 — 7. 확인 필요)
7. 최소 초과근무시간은 신청서 1건 단위.
8. 승인되면 사전 휴일근무 승인과 동일하게 집계. '승인시간만 포함'이면 승인 시간 ∩ 실제 출퇴근 기록만 인정 → 출퇴근 기록이 없으면 인정 시간 없음.
9. 마감된 일자는 신청·승인·취소 신청·취소 승인 모두 불가.
10. 승인 후 취소는 취소 신청서로만 가능 (대상이 과거라 즉시 취소 경로 없음).

- **승인돼도 실제 근무한 시간만 인정**: 사전·사후 모두 승인 구간과 실제 출퇴근 기록이 겹치는 시간만 인정되며, 출퇴근 기록이 없는 날은 승인돼도 인정 시간이 없습니다 (기획 확인 2026-11-05).
- **한도 초과 시 신청 차단**: 사후 신청도 최대 초과근무 한도를 넘으면 신청 단계에서 막습니다. 요청중인 사후 신청 시간은 사전 신청의 한도 계산에도 포함됩니다.

- **허용 설정과 신청서 사용 여부 (기획 확인 2026-11-05)**: 구성원이 소속된 근무그룹은 설정을 수정할 수 없고, 허용 옵션을 바꾸려면 그룹을 복제해 새 그룹으로 옮깁니다. 허용 옵션이 '승인 시에만'이 아니면 어드민 근무 신청서 관리에서 해당 신청서 행이 비활성되며 툴팁으로 활성화 조건을 안내합니다. 사후 신청서는 기본 '사용 안 함'이라 관리자가 켜야 합니다. 신청서 노출은 오늘 소속 근무그룹 설정 기준입니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 신청서 사용 중지 | 모달 "휴일 근무(사후) 신청 불가 안내" / "휴일 근무(사후) 신청서 사용이 중지되었습니다." |
| 마감된 날짜 선택 | "선택한 날짜는 근무가 마감되어 신청이 불가합니다." + [요청] 비활성 |
| 요청일 미선택 | "요청일을 입력합니다." |
| 시작 / 종료 미입력 | "시작 시각을 입력합니다." / "종료 시각을 입력합니다." |
| 종료가 시작보다 앞 | "종료 시각이 시작 시각 전입니다." |
| 시작 = 종료 | "종료 시각이 시작 시각과 같습니다." |
| 근무 가능 시간대 밖 | "당일 HH:mm ~ 익일 HH:mm 이내로 신청합니다." |
| 야간 불가인데 22~06시 포함 | "야간 근무 불가로 해당 시간(22:00 ~ 06:00)을 제외한 시간으로 신청하시기 바랍니다." |
| 기존 휴일근무와 겹침 | "선택한 기간에 이미 신청한 휴일 근무가 있습니다. 중복요청은 불가합니다." |
| 잔여 초과근무시간 초과 | "<초과한 기준(휴일, 주간, 월간휴일, 월간)> 기준 잔여 시간을 초과했습니다." |
| 최소 기준 미달 | "휴일 근무시간이 최소 기준(Nh)보다 적습니다." |
| 첨부 / 코멘트 필수 미입력 | "첨부파일을 업로드합니다." / "코멘트를 입력합니다." |
| (서버) 오늘 이후 날짜 | "사후 휴일근무는 지난 휴일에 대해서만 신청할 수 있습니다." |

| (서버) 마감 | "선택한 일자의 근무가 마감되어 사후 휴일근무를 신청할 수 없습니다." |

| (서버) 신청서 미사용 | "사후 휴일근무 신청을 사용할 수 없도록 설정되어 있습니다." |

## 7. 확인 필요
- 화면의 최대 초과근무 검증이 근무시간 포함여부 '포함' 그룹에서 서버보다 엄격하게 막는지 — 기획 기준은 "집계에서 제외되더라도 한도 초과 시 신청 단계에서 막는다"(화면 동작과 일치). 서버가 허용하는 경우가 실제로 있는지 스테이징 확인 필요
- 자정 직후(근무 귀속일이 아직 전날인 시간대)에 전날 휴일을 고르면 서버에서 거절되는지
- 상단 툴팁 문구에 "사전 승인"이 그대로 나오는 것이 의도인지
