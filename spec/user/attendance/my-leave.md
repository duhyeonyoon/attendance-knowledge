> **URL** `/attendance/leave`
> **탭** 예정휴가 · 사용기록
> **사용자** 사용자(구성원 본인)

## 1. 개요

사용자가 본인의 **연차·연차 외 휴가 잔여를 확인하고 휴가를 신청·취소**하는 화면입니다. 예정 휴가와 사용 기록을 탭으로 보고, 잔여 휴가 칸에서 휴가 유형을 골라 바로 신청서를 엽니다. 즐겨찾기한 구성원/조직의 휴가 현황 캘린더도 함께 제공합니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 상단 헤더 | 연차 전체 / 사용 / 잔여 | 시간 + 일 단위. 연차(또는 1년 미만 연차) 생성 전이면 숨김 |
| 잔여 휴가 | 휴가제도별 잔여시간, "사용기간 이내" 토글, [더 보기] | 기본 4개 노출. 이름은 어드민의 **사용자용 휴가제도명** |
| 탭: 예정 휴가 | 요청중/승인완료 + 미래 휴가 목록, 요청중 칩, > 버튼 | 신청서 확인·취소 |
| 탭: 사용 기록 | 과거 휴가 목록 | — |
| 캘린더 위젯 | 즐겨찾기 구성원/조직 휴가 현황, 월 이동, [오늘] | 요청중 휴가는 휴가 유형별 요청중 시간 표시 |

## 4. 정책 · 비즈니스 룰

### 4.1 휴가 일수 환산

`휴가 일수 = 휴가 시간(분) ÷ (일소정근로시간 × 60)` — 소수 둘째 자리 반올림, 끝자리 0 생략.

| 예 (일소정 8시간) | 결과 |
|---|---|
| 13시간 30분 | 1.69일 |
| 12시간 | 1.5일 |
| 16시간 | 2일 |

**일소정근로시간 결정 순서**

| 순위 | 기준 |
|---|---|
| 1 | 그날 적용된 **근무 템플릿의 하루 근무시간** (일별 근무계획) |
| 2 | 근무 그룹의 **표준근로시간** (근무 그룹 › 근무설정 › 기본 설정) |
| 3 | 기본값 8시간 |

- 관리자 직접 휴가 등록·휴가 정산 경로는 근무 템플릿과 관계없이 근무 그룹 표준근로시간만 사용합니다. 따라서 단축 근무 템플릿을 쓰는 구성원은 같은 사용 시간이라도 사용자 신청 경로와 일수가 다르게 환산될 수 있습니다.
- 운영 원칙(기획 확인 2026-11-05): 휴가는 **시간 단위**로 관리하고, **일수 표시는 근무 그룹 표준근로시간 기준 환산**입니다. 근무 템플릿의 하루 근무시간은 **종일 사용 시 차감할 시간**을 정하는 기준입니다(템플릿 없는 날은 표준근로시간). 단축근무 그룹도 표준근로시간은 8시간으로 두고 템플릿만 줄이도록 안내합니다. 이 원칙에 따르면 관리자 경로의 환산이 원칙과 일치합니다.
- 단축근무(예: 3시간) 인원은 근무 그룹을 바꾸지 말고 3시간짜리 근무 템플릿을 만들어 개인 근무계획에 적용하면 그날부터 휴가 1일 = 3시간으로 환산됩니다.
- 단, 휴가 사용 시간대가 **고정**(예: 종일 = 8시간)인 휴가제도는 근무계획과 무관하게 고정 시간이 차감되므로, 단축근무용으로는 별도 휴가 그룹·휴가제도가 필요합니다.

### 4.2 잔여 휴가 정렬

1. 1년 미만 연차
2. 연차
3. 연차 외 — 수동 부여 (사용 종료일 빠른 순)
4. 연차 외 — 주기에 따라 반복 사용 (이름순)
5. 연차 외 — 신청에 따라 부여 (이름순)

### 4.3 연차 외 휴가 노출 조건

공통: 사용자의 휴가 그룹에 매핑된 유효한 휴가제도만 대상.

| 부여 방식 | 노출 조건 |
|---|---|
| 수동 부여 | **지급 이력이 있어야** 노출 |
| 주기에 따라 반복 사용 | 현재 날짜가 사용 가능 기간 안이면 자동 노출 (지급 이력 무관) |
| 신청에 따라 부여 | 매핑만 되면 노출. 잔여 시간은 빈칸 |

추가 조건: 성별 제한이 있으면 사용자 성별과 일치해야 함 / "사용기간 이내" 토글 ON이면 사용기간 내 항목만.
→ "휴가가 안 보임" 문의 시 확인: ① 휴가 그룹 매핑 ② 수동 부여면 지급 이력 ③ 사용기간 제한 ④ 성별 제한.

### 4.4 신청 시간대 제약

- 신청 시간은 **당일 출근 가능 시각 ~ 익일 출근 가능 시각** 이내여야 합니다. 출퇴근 위젯의 하루 경계([출퇴근 위젯](../home/checkin-widget.md))와 같은 규칙입니다.
- 시작: 당일이 고정 출근 근무일이면 **당일 계획 출근시각 − 3시간**, 아니면(자율·휴일 등) 당일 06:00.
- 종료: 익일이 고정 출근 근무일이면 **익일 계획 출근시각 − 3시간**, 아니면 익일 06:00. 단, 당일이 근무일이고 익일이 근무일이 아니면 당일 계획 출근시각 + 21시간까지.
- 연차 외 휴가는 휴가제도의 휴일/휴무일 포함 설정에 따라 휴일·휴무일에도 사용할 수 있습니다.

### 4.5 주기 반복 사용 휴가

1. 신청 기간에 해당하는 주기의 잔여를 확인하고, 여러 주기에 걸치면 주기별 기한을 표시합니다.
2. 현재 주기를 모두 소진해도 다른(과거/미래) 주기 잔여가 있으면 신청서는 열립니다.
3. 신청 기간에 소진된 주기가 하나라도 포함되면 신청 불가입니다.
4. 주기 시작일 = 근무 설정의 회계연도 시작일 (기본 1월 1일).

### 4.6 휴가 사용 시간 고정 설정

1. 설정된 종일 휴가 시간대로 사용하며, 종일 해제 후 설정된 옵션 중 선택할 수 있습니다.
2. 근무계획과 무관하게(계획 시간 전후에도) 사용할 수 있습니다.
3. 30분 단위 검사가 적용되지 않습니다 (예: 20분 사용 가능).

### 4.7 1년 미만 연차

| 케이스 | 동작 |
|---|---|
| 같은 사용기간 1건 (부여방식 = 선부여) | 안내 없음. 사용기한 이후 신청 시 "사용기한 이내로 요청합니다. (~ YYYY.MM.DD)" |
| 다건 (선부여 아님) | 클릭 시 "남은 1년 미만 연차를 먼저 확인합니다." → 상세 모달(각 시간 합 = 잔여). 요청중이면 노란 글씨 "#시간 요청중" |

### 4.8 요청 이후

- 요청 시 예정 휴가에 요청중 칩과 함께 추가됩니다.
- 승인 완료 시 잔여에서 차감, 취소 승인 시 다시 더해집니다.
