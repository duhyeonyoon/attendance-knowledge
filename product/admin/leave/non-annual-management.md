## C-2. 연차 외 휴가 보유현황 탭 (L1031–1091)

조회 + 정산 + 수동 지급 + 삭제. 상단 안내 "구성원들에게 부여된 연차 외 휴가와 사용 및 잔여 내역을 관리합니다"

**버튼**: [지급 내역] · [연차 외 휴가 정산 ▾](정산 / 정산 취소) · [수동 휴가 지급], 그리드 안 [삭제] (`ad:src/components/attendance/leave/non_annual_management/contents/summary_record_tab/contents/Header.tsx`)
- 행을 체크하면 [연차 외 휴가 정산] · [수동 휴가 지급]은 **비활성** (체크는 삭제 전용)

### 지급 내역 화면

[지급 내역] 버튼 → 지급/차감 내역 화면 (조회기간 조정, 디폴트 1년 전부터)
- 표시 단위 설정 가능 ([더보기] 버튼) → 일/시간 컬럼 분기

### 연차 외 정산 (L1054–1067)

**정산 방식 3가지**:
- **보상**: 정산 결과의 보상 컬럼에 추가, 잔여 = 0
- **이월**: 정산 결과의 이월 컬럼에 추가, 잔여 = 0
  - 이월 시 휴가 사용 종료일 선택 가능 (선택한 휴가 귀속연도 다음 해 1월 1일부터)
- **소멸**: 정산 결과의 소멸 컬럼에 추가, 잔여 = 0

- 정산 확인 문구: "{{name}} 등 n명에 대해 {{year}}년도 {{휴가명}}를 정산(보상, 이월, 소멸) 및 마감합니다." + "요청중인 상태에서 정산이 완료된 휴가는 승인 불가로 처리되며, 정산이 완료된 귀속연도에는 동일한 휴가 유형을 추가로 부여할 수 없습니다."

**정산 취소**:
- 확인 문구: "… {{year}}년도 {{휴가명}} 정산을 취소합니다." + "휴가 마감이 해제되며 보상, 이월, 소멸 내역이 정산 전 상태로 복원됩니다. 선택한 구성원에 대하여 다시 해당 귀속년도의 휴가 유형을 부여 및 사용이 가능합니다."
- 이월로 정산한 휴가를 이미 사용했다면 → 정산 취소 시 에러 모달

### 삭제 (L1051–1052)

체크박스 선택 후 [삭제] → "연차 외 휴가 삭제" 확인: "수동으로 등록한 연차 외 휴가 n건을 삭제합니다. 계속 진행하시겠습니까?" → 완료 "연차 외 휴가 삭제를 완료하였습니다."

다음은 삭제 불가 ("연차 외 휴가 삭제 오류" — "부여한 휴가를 이미 사용했거나 정산 완료한 경우 휴가 삭제를 할 수 없습니다." + "삭제를 하기 위해서는 연차 외 휴가 사용현황 탭에서 휴가 사용 내역을 삭제하거나 정산 취소를 해주시기바랍니다." + "삭제 불가한 구성원 n", 사유 라벨 "휴가 사용" / "정산 완료"):
- 정산 완료 건
- 사용분을 다른 휴가로 이관할 수 없는 건 (동일 유형 휴가 잔여 < 사용)
- 체크박스 클릭 시 [연차 외 휴가 정산] / [수동 휴가 지급] 버튼은 비활성화

### 수동 휴가 지급 (L1068–1090)

**직접 입력 등록**:
- 입력 필드: 휴가 유형 / 지급 대상 / 귀속연도 / 지급 시간 / 사용 시작일/종료일 / 적용일 / 메모
- **지급 단위 = 시간만 가능** (의도된 설계) — 화면에 단위 셀렉트("시간")가 있으나 비활성 고정 (`ad:...NonAnnualLeavePaymentManualContent.tsx`):
  > 일 단위로 입력하면 모호함이 발생함. 소정근로시간이 회사/사람마다 달라서 "1일"이 8시간일지 7시간일지 명확하지 않음. 시간 단위로 강제해서 항상 정확한 양을 입력하도록 함
- **지급 대상 의존성**: 휴가 유형 먼저 선택 후 활성화. 마우스 오버 시 "휴가 유형을 먼저 선택 후 지급대상을 선택합니다." (2026-11-05 locale 확인 — ~~"휴가 종류를…"~~)
- 휴가 유형 선택 시 해당 휴가를 지급 가능한 구성원만 표시 (한 번에 다중 선택)
- 적용일 디폴트 = 당일 — **(2026-11-05 확인) 날짜 선택기가 비활성이라 당일로 고정, 사용자가 바꿀 수 없음** (`ad:...non_annual_management/contents/summary_record_tab/contents/NonAnnualLeavePaymentManualContent.tsx` 적용일 DatePicker `disabled`). 적용일 = 연차 외 휴가의 '노출 시작일' 성격(Slack #sq-time 2024-03-21). 2026-11-05 Slack 검색: 필수 여부 별도 논의 없음
- 필수 입력 모두 채워야 [적용] 활성화
- 확인 문구: "{{name}}님 등 n건의 {{휴가명 n시간}}을 지급합니다." → 일부 실패 시 "부분 지급 완료"(지급 완료 n건 / 지급 불가 n건), 전부 실패 시 "일괄 지급 불가"

**엑셀 파일 등록**:
- 양식 다운로드 → 엑셀 작성 → 업로드
- A~F열 빈값 또는 포맷 오류 → 행별 밸리데이션 다이얼로그
- 통과 → 총 데이터 건수 + 휴가별 지급 건수 다이얼로그 → 확인 시 업로드
- 성공 시 보유현황 탭 데이터 갱신 + [지급 내역] red dot

**사용자/매니저 화면 가시성 (2026-05-15 갱신)**:
- 수동 부여한 연차 외 휴가는 **사용일수와 상관없이 귀속년도 기준**으로 사용자/매니저 화면에 조회됨
- 귀속년도 내 동일 휴가 여러 개 부여 시 → **개별 기한으로 상세정보** 확인 가능
- 매니저 측 동작은 `KB:product/user/attendance/member-work.md` § "연차 외 휴가 (수동 부여 휴가) 테스트" 참조

## C-4. 연차 외 휴가 사용 현황 탭 (L1154–1198)

상단 안내 "구성원별 연차 외 휴가 사용 내역을 조회하고 관리합니다". 버튼: [등록 내역](현재 **항상 비활성**) · [휴가 수동등록]

연차 사용 현황 탭과 거의 동일 패턴. **차이점**:
- 휴가 유형 입력 시 **해당 연차 외 휴가제도를 사용할 수 있는 구성원**만 노출 (휴가 유형 툴팁: "연차 외 휴가 제도에 등록된 휴가 제도명(어드민)입니다.")
- 실패 분류가 **중복 휴가 / 휴가 부족 / 기타** 3가지뿐 (`be:LeaveManagementService.buildDirectNonAnnualLeaveResultDto`). 부족 건은 무조건 자동 제외되고 분기는 [이어서 진행]만 — "총 n건 중 m건의 휴가는 등록할 수 없습니다. 중복 휴가 및 휴가 부족 건은 등록이 불가하며 자동으로 제외됩니다. 이어서 진행하시겠습니까?"
- **(2026-11-05 해소)** ~~연차 부족 분기가 없는 이유 = 잔여 룰이 다르기 때문(추정)~~ → 연차 외 휴가는 **초과 사용 자체가 구현돼 있지 않음** (`be:CalcLeaveService` "TODO) 연차외휴가 초과사용여부 확인"). 연차 외 휴가 제도에 남은 `overUsePmitYn`도 차감 로직에서 참조하지 않음 (`_learnings/2026-07-29-annual-leave-concept-map.md`)
