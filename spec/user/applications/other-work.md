> **사용자** 구성원(신청자) · 결재자

## 1. 개요
어드민이 정의한 기타근무 항목을 신청하는 신청서입니다. 다른 신청서와 달리 **기간 신청**과 **일자별 종일/직접 입력**을 지원하여 근무 신청서 중 가장 복잡합니다. 어드민이 직접 등록한 기타근무는 신청·승인 없이 반영됩니다.

## 4. 정책 · 비즈니스 룰
1. 어드민 '기타근무 항목 관리'에 항목이 있어야 신청 가능 (근무그룹 상속).
2. 항목별로 코멘트/첨부 필수 여부를 어드민이 설정.
3. 같은 날 종일 신청이 있으면 추가 신청 불가.
4. 기간에 마감된 일자가 포함되면 요청 불가.
5. 유효성 검사는 기간 → 일자별 → 요청 3단계로 수행.
6. 근무귀속일(당일 XX:XX ~ 익일 XX:XX) 범위를 벗어난 시간은 신청 불가.
7. 기타근무 칩/요약이 재택 칩보다 우선.
8. 마감된 일자는 요청·승인·취소 모두 불가.

- **항목 정의 (기획 확인 2026-11-05)**: 기타근무 항목은 어드민 근무관리 › 근무 설정 › 기타근무 항목 설정 탭에서 만들고(같은 이름 중복 불가), 근무 그룹 설정 › 기타근무 항목 관리에서 그룹별 사용 여부를 켭니다. 새 항목은 모든 근무그룹에 '사용 안 함'으로 추가됩니다.
- **어드민 직접 등록**: 어드민 근무 데이터 관리 › 기타근무 현황 › 근무 수동등록(엑셀 업로드)으로 등록합니다. 사용자가 내 근무 캘린더·구성원 근무 현황·근무 정보에서 해당 건을 누르면 "해당 근무는 별도의 신청/승인 과정 없이 관리자에 의해 등록되었습니다." 안내가 뜹니다. 수동 등록 건은 어드민이 삭제할 수 있습니다(마감 건·신청서로 승인된 건 제외).

## 5. 메시지 · 예외 처리
| 단계 | 상황 | 화면 메시지 / 처리 |
|---|---|---|
| 기간 | 마감된 일자 포함 | "선택한 기간의 근무가 마감되어 근무를 신청할 수 없습니다." + "마감되지 않은 근무 일자에 한해 근무 신청이 가능합니다." (요청 불가) |
| 기간 | 기존 신청이 있음 | "선택한 기간에 이미 신청한 근무가 있습니다." + 기존 신청 목록 |
| 기간 | 기존 신청이 있는 날 종일 선택 | "이미 신청한 근무 요청이 있어 종일 선택이 불가합니다." |
| 기간 | 마감일 종일 선택 | "근무가 마감되어 종일 선택이 불가합니다." |
| 기간 | 모두 휴일/휴무일이고 토글 모두 비활성 상태로 요청 | "요청일을 선택합니다." |
| 일자 | 시작 = 종료 | "시작 종료시각이 같습니다." |
| 일자 | 시작 > 종료 | "종료 시각이 시작 시각 전입니다." |
| 일자 | 근무귀속일 범위 밖 | "당일 HH:mm ~ 익일 HH:mm 이내로 신청합니다." |
| 일자 | 기존 신청 시간과 겹침 | "선택한 시간에 이미 신청한 근무가 있습니다. 중복요청은 불가합니다." (입력한 시각은 비워짐) |
| 요청 | 종일 신청한 날에 다시 신청 | [요청] 버튼 비활성 |
| 요청 | 날짜 미선택 | [요청] 버튼 비활성 |
| 요청 | 직접 입력인데 시작/종료 미입력 | "시작 종료 시각을 입력합니다." / "시작 시각을 입력합니다." / "종료 시각을 입력합니다." |
| 요청 | 코멘트 필수 유형인데 미입력 | "코멘트를 입력합니다." |
| 요청 | 첨부 필수 유형인데 미첨부 | "첨부파일을 업로드합니다." |
| 어드민 직접 등록 건 조회 | | "해당 근무는 별도의 신청/승인 과정 없이 관리자에 의해 등록되었습니다." |
