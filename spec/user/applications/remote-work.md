> **메뉴** 근무 신청 › 재택근무
> **진입** 출퇴근 위젯 [근무신청] › 신청서 종류 선택
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
구성원이 특정 일자(또는 기간)에 재택근무를 하기 위해 승인을 받는 신청서입니다. 승인되면 근무지 제약 없이 출퇴근할 수 있고, 홈과 구성원 근무 현황에 재택 표시가 붙습니다.

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 요청일 | 기간 캘린더 (placeholder "기간 선택") | 날짜 하나만 고르면 단일 일자 |
| 경고 | 마감 일자 / 중복 일자 안내 박스 | 해당 일자 목록과 함께 표시 |
| 하단 | 코멘트, 첨부, 결재선, [요청] | [공통 정책](./overview.md) 참고 |

## 3. 기능 상세
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-APL-RMT-01 | 재택근무 요청 | 요청 기간과 결재선 선택 후 [요청] → 해당 기간으로 신청 | 하루만 선택하면 단일 일자 |
| U-APL-RMT-02 | 신청 일자 검증 | 기간 선택 시 요청 중인 재택, 이미 재택인 일자, 마감 일자를 확인해 경고 박스로 표시 | 하나라도 있으면 [요청] 버튼 비활성 (서버도 동일하게 차단) |
| U-APL-RMT-03 | 재택 칩 표시 | 승인 완료 시 홈 출퇴근 위젯 상단과 구성원 근무 현황에 재택 칩 표시 | 같은 날 기타근무 칩이 있으면 재택 칩 미노출 |
| U-APL-RMT-04 | 근무지 제약 해제 | 승인 이후에는 근무지 여부와 상관없이 출/퇴근 가능 (위치 검증 우회) | 승인 완료 건만 |
| U-APL-RMT-05 | 취소 신청 | 승인된 재택근무에 대한 취소 신청서 발행 | 별도 취소 신청서 존재 |
| U-APL-RMT-06 | 알림 | 신청/승인/반려/코멘트 시 알림 | 통합알림 설정의 "근무 내역/계획 변경 - 재택근무"로 OFF 가능 |

## 4. 정책 · 비즈니스 룰
1. 근무그룹 설정에서 **재택근무 허용**이 체크된 경우에만 신청 가능.
2. 기간 신청 가능 (단일 일자도 가능).
3. 재택 승인 = 근무지(GPS) 제약 해제.
4. 칩 우선순위: 기타근무 칩 > 재택 칩 (둘 다 있으면 기타근무만 표시). 칩 한 자리를 공유하며, 근무가 재택보다 중요하고 동시 발생은 드물다는 판단에 따른 의도된 정책.
6. 요청중이거나 이미 재택인 일자가 기간에 포함되면 신청 불가.
5. 마감된 일자는 요청·승인·취소 모두 불가.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 기간에 마감 일자 포함 | "선택한 기간의 근무가 마감되어 재택근무를 신청할 수 없습니다." + "마감되지 않은 근무 일자에 한해 재택근무 신청이 가능합니다." + 마감 일자 목록, [요청] 비활성 |
| 기간에 요청중·이미 재택인 일자 포함 | "선택한 기간에 이미 신청한 재택근무 계획이 있습니다." + "기존 재택근무 정보와 중복이 아닌 경우에만 재택근무 신청이 가능합니다." + 일자 목록, [요청] 비활성 |
| 요청일 미입력 | "재택근무일을 입력합니다." |
| 재택 허용 안 된 근무그룹 (서버) | "재택근무를 신청할 수 없는 근무그룹에 속해 있습니다." |
| 승인/취소 시 마감 일자 | 승인/취소 불가 |
