## 1. 개요

직책자/관리자가 **권한 범위 내 구성원의 근무 일정과 주간 근무 현황**을 확인하고, 들어온 승인 요청을 **요청 모아보기**에서 일괄 처리하는 화면입니다. 구성원 이름을 누르면 해당 구성원의 근무 상세 현황으로 이동합니다. 구성원 근무·구성원 휴가의 공통 권한/워크플로우 규칙도 이 문서에서 정의합니다.

## 4. 정책 · 비즈니스 룰

### 4.1 조회 범위 · 권한

1. 조회 범위 = 직책자 권한 + 권한 그룹 설정 ([직책자 권한](../../admin/authority/manager.md)). **별도 매니저 권한은 없습니다** (기획 확인 2026-11-05).
   - 직책을 묶은 '직책 그룹'마다 메뉴(구성원 근무 현황 / 구성원 휴가 현황 / 근무스케줄 역할 기준)와 범위('본인 조직' 또는 '본인 + 하위조직'), '조직장만 권한 부여' 여부를 정합니다. 발령상 직책 기준으로 자동 부여되며 개인 단위 예외는 둘 수 없습니다.
   - 조직도에서 조직장으로 지정돼 있어도 직책자 권한이 없으면 본인만 보입니다. '회사 전체' 범위 옵션은 없습니다.
   - **구성원 근무 일정 탭은 권한과 무관하게 모든 구성원이 볼 수 있고**(기본 필터 = 본인 조직), 근무 현황 탭과 요청 처리만 직책자 권한이 필요합니다.
2. 본인 소속 회사 하위만 조회되며, 조직은 소속 구성원이 있는 조직만 표시됩니다 (2025.04.17 기준 임시 제약).
3. 상위 조직 필터 시 하위 조직 인원이 포함됩니다.

### 4.2 근무 일정 타임라인

**겹침 우선순위 (목록 보기)**: 휴가 → 기타근무 → 재택근무 → 근무계획

**캘린더 보기 우선순위**: 휴가(시작시각순) → 기타근무(시작시각순) → 재택근무

| 일정 종류 | 표시 명칭 | 시작/종료 |
|---|---|---|
| 근무 계획 | 계획 | 아래 표 |
| 휴가 | "휴가" (통일) | 신청 시작~종료 |
| 기타근무 | 항목명 | 신청 시작~종료 |
| 재택근무 | "재택근무" (근무 계획 대체) | 근무스케줄 없으면 표시 안 함 |

근무 계획 표시 규칙: 24시간 안에 여러 건 가능(야간→주간 변경 등) / 휴일·휴무일·스케줄 없음은 표시 안 함 / 개인스케줄 > 그룹스케줄.

| 출근시각 | 퇴근시각 | 타임라인 | 하단 표시 |
|---|---|---|---|
| 고정 | 고정 | 계획 시작~종료 | 시작-종료 시각 |
| 자율 | 고정 | 09시부터 소정근로시간만큼 | 자율-소정근로시간 |
| 고정 | 자율 | 출근시각부터 소정근로시간만큼 | 출근시각-자율 |
| 자율 | 자율 | 09시~18시 (기본) | 자율-자율 |

부가 표시: 코어타임 = 점선 + 연보라 영역 / 휴게시간 = 빗금 (기본 휴게시간만, 연장 휴게 제외. 고정 휴게는 설정 시간대, 법정 휴게는 첫 휴게 발생 시각부터 자동 계산).

### 4.3 근무 상세 현황 일별 테이블

| 컬럼 | 규칙 |
|---|---|
| 타임 (휴가/기타근무) | 같은 날 여러 개면 **요청중 > 취소중 > 휴가 > 기타** 순으로 1개만, 나머지는 **+n**. 취소 요청 중인 휴가(기타근무)는 원래 항목을 숨김 |
| 근무 시간 | 근무내역 변경 요청 중이면 "요청중" + 출근/퇴근/자리비움 컬럼 빈칸 |
| 출근 / 퇴근 | 출근 요청중 / 퇴근 요청중 표시 |
| 평균 출/퇴근 | 익일로 넘어가면 24시 초과 표기 (예: 28:30) |

- 근무내역 변경·출근·퇴근 신청서는 동시에 진행할 수 없습니다. 진행 중 신청이 종결된 후 재신청할 수 있습니다.

### 4.4 요청 모아보기 · 승인

1. 결재선의 승인자는 통합홈 처리할 문서 위젯 또는 이 화면의 요청 모아보기에서 처리합니다.
2. 일괄 승인/반려 시 각 작성자에게 알림이 가고 작성자 캘린더가 즉시 갱신됩니다.
3. 같은 문서를 두 곳(예: 같은 계정 두 탭)에서 동시에 처리하면 한쪽은 실패합니다.
4. 근무지 외 출퇴근 요청의 위치는 **신청일로부터 3개월 이내**에만 확인할 수 있으며, 기간이 지난 위치 정보는 파기됩니다 (개인정보 보호).
5. 일괄 승인/반려는 문서별로 처리됩니다. 선택한 문서 중 일부만 처리될 수 있습니다.

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 주 근로시간 46h/52h 초과(예상) | 경고 표시 |
| 3개월 지난 근무지 외 요청 | "위치 확인 가능 기간(3개월)이 지났습니다." |
| 일괄 처리 확인 | "선택하신 문서를 일괄 처리 하시겠습니까?" |
| 문서 미선택 후 승인/반려 | "승인 문서 미선택" — "승인할 문서를 선택합니다." / "반려 문서 미선택" — "반려할 문서를 선택합니다." |
| 일괄 승인 결과 | 전부 성공 "일괄 승인 처리되었습니다." / 일부 실패 "부분 승인 처리되었습니다." + "부분 승인 완료" 팝업 / 전부 실패 "일괄 승인이 불가합니다." + "일괄 승인 불가" 팝업. 팝업에 "승인 완료 N건 / 승인 불가 N건"과 실패 문서·사유 |
| 일괄 반려 결과 | 같은 패턴 ("일괄 반려 처리되었습니다." / "부분 반려 처리되었습니다." / "일괄 반려가 불가합니다.", "반려 완료 N건 / 반려 불가 N건") |
| 승인/반려 처리 오류 | "승인 처리 중 오류가 발생했습니다. 잠시 후 다시 시도 바랍니다." (반려도 동일) |
| 동시 처리 경합 | 뒤에 처리한 쪽 실패 |
