## § U10-1. 구성원 휴가 일정 (L502–518)

**구성원들의 휴가를 일자별로 확인.**

### 필터 / 컬럼

- 필터: 구성원 이름, 조직
  - 본인 소속 회사 하위만
  - 2025.04.17 임시 제약 (구성원 있는 조직만)
- 컬럼: 구성원, 회사, 조직, 휴가일, 휴가시간, 시작시간, 종료시간
- **본 소속, 겸 소속, 본 소속의 상위, 겸 소속의 상위**로도 조회
- **페이지네이션 + 컬럼별 정렬**

## § U10-2. 구성원 휴가 현황 (L520–548)

### 권한별 조회 범위

- **직책자 권한 없음** → 본인만
- **직책자 권한 있음** → 권한 내 구성원 모두

**로컬 테스트 예** (L527):
- 직책자 권한에 팀장 직책 모두 + 구성원 근무 현황 권한 → 최성희 로그인 시 손예진 조회 가능

### 조회 룰

- **조회하는 연도에 사용기한이 걸린 연차** 조회
- **(2026-11-05 확인)** 조회 연도 = **회계연도 시작일 기준 1년** (근무 설정의 회계연도 시작일 + 1년 − 1일). 연도 선택지는 **작년 / 올해 / 내년** 3개 (`pp:.../member_leave_summary_tab/contents/FilterSection.tsx:80–93`, `be:timeold/service/leave/EmpLeavesService.java:368–425`)
- API: 개인 권한(ESS) → 본인, 근무 팀장권한 → 권한 내 구성원 (`be:timeold/controller/leave/EmpLeavesController.java:262`)

### 휴가유형 필터

> **(2026-11-05 갱신)** 2026-05 "구성원 휴가 현황에 연차 외 휴가 포함 + 필터 옵션 API 추가"(`hcgtheplus/optimiz-time#1425`) 이후 필터가 **2단 구조**로 바뀜.

- 1단 **휴가 유형**: "연차 휴가" / "연차 외 휴가"
- 2단 **세부 유형**:
  - 연차 휴가 → "전체 휴가" / "연차" / "1년 미만 연차"
  - 연차 외 휴가 → "전체 휴가" / 휴가제도 목록(필터 옵션 API)
- ~~**전체 연차** 필터: 연차 미생성 인원 → "휴가 유형이 생성 필요" 표시~~ → **(2026-11-05 해소)** 판정 기준:
  - **연차 휴가 > 전체 휴가**일 때만 생성 이력이 없는 구성원도 포함 (`TM_LEAVE_CRT` LEFT JOIN, `createdOnly = false`). 조회 연도 기간과 사용기간이 겹치는 연차/1년 미만 연차 생성 건이 **하나도 없으면** 해당 구성원 행의 **휴가 유형 컬럼에 "생성 필요"** (`CONST_TIME_CODE.ANNUAL_LEAVE_GENERATE_REQUIRED`, `EmpLeavesService#getLeaveName` L810–812), 부여/사용/잔여/요청중은 0
  - 그 외(연차/1년 미만 연차/연차 외 휴가 선택) → **생성된 인원만** 조회 (`createdOnly = true`, INNER JOIN)
- **전체 연차 외**: 해당 휴가가 생성된 인원만 조회

### 사용률 계산

- 연차 사용 시 **사용률 = 사용일 / 부여일** 기준

### 연차 조회 - 귀속연도 표시 룰

**연차 테스트** (L539–542):
- 어드민 > 구성원 정보에서 **연차기산일을 1월 1일이 아닌 다른 날로** 설정 + 연차제도 부여 기준 = **입사일 기준** 변경
- 작년/올해/내년 연차 생성 시 → 구성원 휴가 현황 올해/내년 조회 시 **동일 구성원 연차가 두 행으로** 조회됨
- 귀속연도 기준으로 각각 표시

### 1년 미만 연차 테스트 (L544–548)

- 연차기산일 = **작년 3월 이후 ~ 작년 12월 이전**으로 설정
- 작년, 올해 연차 생성 → 귀속연도가 작년/올해로 다르지만 **올해 조회 시 1년 미만 연차는 한 행**
- 귀속연도는 작년/올해 둘 다 표시
- **개별 기한** 표시 + 돋보기 클릭 시 상세 정보

### 연차 외 휴가 (수동 부여 휴가) 테스트 ⭐신규 (2026-05-15 갱신, ~L559–563)

어드민이 수동 부여한 연차 외 휴가가 본 화면에 어떻게 조회되는지:

- **어드민 > 휴가 지급 및 관리 > 연차 외 보유 현황 탭에서 수동부여 휴가를 부여하는 경우** → 구성원이 보유한 해당 휴가가 조회됨 (`KB:product/admin/leave/non-annual-management.md` § C-2 "수동 휴가 지급")
- **수동부여 연차 외 휴가는 사용일수와 상관없이 귀속년도 기준으로 조회** (= 모두 사용해도 그해는 노출)
- **귀속년도 내 동일한 휴가가 여러 개 부여된 경우** → 개별 기한으로 상세정보 확인 가능 (1년 미만 연차 다건 케이스와 유사 패턴)

> 의미: 어드민이 수동 부여한 휴가의 가시성 룰. 일반 연차/주기 반복 휴가와 다르게 **귀속년도 기준 단순 조회** + **다건 부여 시 개별 기한 노출**.
