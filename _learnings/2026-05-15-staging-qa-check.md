## 작업 패턴 인사이트

### staging 실측의 진짜 가치
KB는 코드 + QA 종합해서 정확하다고 생각했는데 **5개 영역에서 5개 누락 발견**. 특히:
- QA 미명시 + UI에 존재하는 필드/컬럼 (적용일, 마감 구분, 근무내역 변경 등)
- 코드 추적만으로 안 보이는 UI 항목 (조건부 표시, 동적 컬럼)

→ **staging 점검이 KB 최후의 검증 단계로 매우 유효**.

### 효율적 점검 전략
- 메인 페이지: `get_page_text` + `read_page interactive` 빠르게 구조 확인
- 모달: click 후 screenshot으로 시각 확인 (밸리데이션 위치 등)
- 위험 액션 회피 (실제 마감/알림 발송)
- 상세 페이지는 시간 비용 vs 가치 trade-off
