> **메뉴** 근무 신청 › 출퇴근 내역 변경
> **진입** 출퇴근 위젯 [근무신청] / 내 근무 캘린더 과거 날짜 / 출퇴근 위젯 "근무 내역 변경" 버튼
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
지난 근무일의 출퇴근·자리비움 **시각만** 바로잡기 위해 승인을 받는 신청서입니다. 입력 방식은 [통합 근무내역 변경](./reg-adjust.md)과 같지만, 승인되어도 정정한 시간의 **연장·야간·휴일근무를 승인된 것으로 보지 않습니다.** 근무그룹이 연장/휴일근무를 "승인 시에만" 허용하면, 그 시간은 연장/야간·휴일근무 신청을 따로 승인받아야 근무시간에 인정됩니다. 근무그룹별로 사용 여부를 켜야 쓸 수 있으며 기본값은 미사용입니다.

### 통합 근무내역 변경과의 차이
| 구분 | 통합 근무내역 변경 | 출퇴근 내역 변경 |
|---|---|---|
| 승인 시 정정 시간의 연장·야간·휴일 | 승인된 것으로 인정 | 인정하지 않음 (별도 신청 승인 필요) |
| 근무그룹 기본 사용 여부 | 사용 | 미사용 |
| 신청서 "변경 결과" | 근무시간·인정근무·연장/야간/휴일·잔여 초과근무·최소 연장 미인정까지 표시 | 출퇴근 구간·인정 시각·자리비움 합계 + 안내 문구만 |
| 둘 다 사용하는 근무그룹 | 유형 드롭다운에서 선택 | 캘린더·위젯 진입 시 **기본으로 열림** |
| 같은 날 둘 다 승인 | 나중에 승인된 신청이 최종 | 동일 |

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 유형 | 신청서 유형 드롭다운, 신청서 설명 | 그날 사용 가능한 변경 신청서와 근무계획 변경 사이 전환. 설명은 접기/펼치기 |
| 요청일 | 날짜 1개 + 경고 문구 | 마감·미사용·어드민 수정·중복 신청 시 경고 |
| 출퇴근 시간 | 출근 n / 퇴근 n (당일·익일 + 시각), [+] [×] | 현재 값이 왼쪽에 표시(없으면 빨간 "없음"). 누락 상태면 제목 옆 ! 아이콘 |
| 자리비움 | 시작 n / 종료 n / 코멘트, [+] [×] | |
| 변경 결과 | 출퇴근 n, (인정 시각), 자리비움 합계, 안내 2줄 | 바뀐 시각은 파란색 |

## 4. 정책 · 비즈니스 룰
1. 출퇴근·자리비움 **시각만** 정정한다. 정정한 시간의 연장·야간·휴일근무는 이 신청 승인만으로 인정되지 않고, 근무그룹 설정과 연장/야간·휴일근무 신청 승인 여부에 따라 확정된다.
2. 근무그룹 설정 › 근무 신청서 관리 › 출퇴근 내역 변경 신청의 **사용 여부**가 켜진 그룹에서만 사용(기본 미사용). 통합 근무내역 변경과 독립적으로 설정한다. 사용 여부는 **선택한 날짜에 소속된** 근무그룹 기준.
3. 둘 다 사용하는 근무그룹에서는 캘린더·위젯 진입 시 출퇴근 내역 변경이 먼저 열린다.
4. 같은 날 요청중인 출근 요청·퇴근 요청·통합 근무내역 변경·출퇴근 내역 변경이 있으면 신청할 수 없다.
5. 어드민이 근무내역을 직접 수정한 일자는 신청할 수 없다 (입력칸까지 잠김).
6. 마감된 일자는 신청·승인 모두 불가.
7. 휴일근무를 "근무 불가"로 설정한 근무그룹은 휴일 날짜에 신청할 수 없다.
8. 같은 날 변경 신청이 여러 번 승인되면 **나중에 승인된 신청**이 최종이다. 승인된 내용을 되돌리려면 같은 날짜로 다시 신청한다.
9. 결재 완료 후 사용자 취소 불가.

- **작성 진입**: 출퇴근 위젯·내 근무 캘린더에서만 작성합니다. 워크플로우 [문서 작성]에는 커스텀 신청서만 노출됩니다 (기획 확인 2026-11-05).

## 7. 확인 필요
- 첨부/코멘트 필수 여부 표시는 **오늘** 소속 근무그룹 기준, 사용 여부는 **신청일** 근무그룹 기준이라 근무그룹이 바뀐 구성원은 기준이 어긋날 수 있음 (개선 진행 중). 모든 근무 신청서 설정을 신청 대상 기간 기준으로 조회하는 고도화가 필요하다는 데는 합의됐으나 전체 일정은 미정
- 결재중인 출퇴근 내역 변경이 있는 날의 연장 한도·근무시간 계산이 결재 완료 후와 다르게 나오는 문제 (수정 진행 중)
- 어드민 직접 수정 일자 차단은 기획상 확정된 정책(어드민이 근무내역을 바꾼 날은 출퇴근 내역 변경도 신청 불가). 다만 현재는 화면에서만 막고 저장 시 서버에서 다시 막지 않음 — 보완 필요 여부 확인
- 어드민 근무 신청 내역 관리에서 반려·취소 건이 보이지 않는 것이 의도인지
