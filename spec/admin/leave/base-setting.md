> **사용자** 어드민(휴가 담당자)

## 1. 개요
회사의 휴가 마스터 데이터(연차 제도, 연차 정산 기준, 연차 외 휴가 제도)를 정의하는 화면입니다. 여기서 만든 제도는 [휴가 그룹 설정](./group-setting.md)에서 그룹에 연결되어 구성원에게 적용됩니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 연차 제도 탭 | 목록 / 상세(조회·추가·수정) | 연차 부여 기준, 1년 미만 연차, 첫 회계연도 연차, 근속연수별 연차, 사용 시간대 |
| 연차 정산 기준 탭 | 목록 / 상세(조회·추가·수정·삭제) | 의무 사용, 이월, 보상 규칙 |
| 연차 외 휴가 제도 탭 | 목록 / 상세(조회·추가·수정) | 명칭(사용자용/어드민용), 부여 방식, 기간 제한, 휴일·휴무일 포함 여부, 사용 시간대 |

## 3. 기능 상세

## 4. 정책 · 비즈니스 룰
1. 휴가 그룹에 적용된 연차 제도 / 정산 기준은 사용여부 "사용 안함" 변경과 삭제가 불가합니다.
2. 연차 제도는 휴가 그룹에 적용된 상태에서도 **내용 전체를 수정**할 수 있으며, 수정 내용은 그 제도를 쓰는 모든 휴가 그룹에 즉시 반영됩니다. 반면 정산 기준은 저장 후 이름·메모·사용여부만 수정 가능합니다.
3. 고정 사용 시간대 항목은 시작 < 종료, 차감시간 ≤ (종료 − 시작)이어야 합니다.
4. 고정 사용 시간대로 설정된 휴가는 30분 단위 검증을 받지 않고 근무계획과 무관하게 사용할 수 있습니다.
5. 근속연수별 연차 설정은 이전 행보다 작은 근속연수를 입력할 수 없습니다.
6. 1년 미만 연차 부여 방식 중 "별도 기준"은 선택할 수 없습니다(비활성).
7. 1년 미만 연차 초과 사용은 기본 "허용 안함"이며, 허용해도 아직 발생하지 않은 달의 연차를 당겨 쓰지는 않습니다. 허용 여부와 한도는 연차를 실제로 쓰는 날짜에 소속된 휴가 그룹의 연차 제도를 따릅니다.
8. 연차는 생성 기준일에 소속된 휴가 그룹의 연차 제도로 생성됩니다. 생성 기준일은 회계연도 기준이면 해당 연도의 회계연도 시작일, 입사일 기준이면 해당 연도의 입사(연차기산) 월·일입니다. 회계연도 기준 그룹에 회계연도 시작일 이후 들어온 구성원은 그해 연차가 생성되지 않습니다. (기획 확인 2026-11-05)
9. 첫 해 연차: 입사일 기준이면 근속연수 0년 행이 설정된 경우에만 1년 미만 연차와 함께 0년차 연차를 생성합니다. 회계연도 기준이면 첫 회계연도 연차를 근속연수 0년 행의 일수(없으면 법정 15일)를 기준으로 첫 회계연도 설정(모두 부여 / 일할 / 월할)에 따라 계산합니다. 회계연도 기준에서 첫 회계연도만 입사일 기준으로 부여하는 설정은 없습니다. (기획 확인 2026-11-05)

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 휴가 그룹에 적용된 연차 제도 사용여부를 "사용 안함"으로 변경 | "휴가그룹에 적용된 연차 제도는 사용여부를 변경할 수 없습니다." |
| 휴가 그룹에 적용된 연차 제도 삭제 | "휴가그룹에 적용된 연차 제도는 삭제할 수 없습니다." |
| 자율 사용 시간대 체크박스 전부 해제 | "1개 이상의 연차 사용 단위를 설정합니다." |
| 고정 항목 시작=종료 / 시작>종료 | "시작 시각과 종료 시각이 같습니다." / "종료 시각이 시작 시각 전입니다." |
| 차감시간 > (종료−시작) | "차감 시간을 시작 종료 시각으로 계산한 시간 보다 같거나 작게 설정합니다." |
| 근속연수를 이전 행보다 작게 입력 | "근속연수는 이전 근속연수인 {n}보다 커야합니다." |
| 초과 사용 허용인데 허용시간 미입력 | "연차 초과사용 허용시간을 입력합니다." / "1년미만연차 초과사용 허용시간을 입력합니다." |
| 초과 사용 허용시간이 1 미만 | "연차 초과사용 허용시간은 1 이상의 정수로 설정합니다." / "1년미만연차 초과사용 허용시간은 1 이상의 정수로 설정합니다." |
| 일부 의무 사용 일수가 25일 초과 | "연차 법적 한도인 25일 이내로 입력합니다." |
| 기간 제한 "제한" 선택 후 제한일자 미입력 | 필수 입력 오류 |
