> **메뉴** 근무관리 › 휴가 › 휴가 그룹 이력 관리
> **URL** `/attendance/leave/group_setting_history_management`
> **사용자** 어드민(휴가 담당자)

## 1. 개요
구성원이 언제 어떤 휴가 그룹에 소속되었는지 **이력을 조회**하는 읽기 전용 화면입니다. 이력은 [휴가 그룹 설정](./group-setting.md)에서 구성원을 변경할 때 시스템이 자동으로 기록합니다. 화면 구성과 동작은 [근무 그룹 이력 관리](../work/group-history.md)와 같으며 "근무 그룹" 대신 "휴가 그룹"을 다룹니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 조회 필터 | 기간 선택(필수), 구성원, 회사, 조직, "휴가그룹(이력 기준) 선택" | |
| 이력 목록 – 기본 정보 | 사번 · 이름 · 회사 · 조직 · 직급 · 퇴사 여부(퇴사/재직) · 활성 여부(활성/비활성) · 현재 휴가 그룹 · 입사일 · 연차기산일 | 근무 그룹 이력의 "근무제 유형"에 해당하는 컬럼은 없음 |
| 이력 목록 – 소속 이력 정보 | 휴가 그룹 · 소속 시작일 · 소속 종료일 · 소속 일수 | 구성원 1명이 여러 그룹을 거치면 여러 행 |
| 액션 | 엑셀 다운로드 | |

## 3. 기능 상세
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-LV-GHI-01 | 이력 조회 | 조회 기간 내 휴가 그룹 소속 이력 조회 | 조회 기간 필수(삭제 불가), 기본값 = 올해 1월 1일 ~ 오늘, 최대 365일 |
| A-LV-GHI-02 | 휴가그룹 필터 | 선택한 휴가 그룹에 **이력상 소속**되었던 구성원 조회 | 현재 소속 기준이 아님 (예: 작년 그룹 X → 올해 그룹 Y로 옮긴 구성원도 그룹 X로 필터 시 작년 이력 노출) |
| A-LV-GHI-03 | 소속일수 표시 | 오늘 날짜 기준으로 소속 일수 계산 | 종료일이 확정되지 않았거나 미래면 오늘까지의 일수, **시작일이 미래(변경 예정)인 이력은 0일**. 마지막 이력의 종료일은 "9999.12.31"로 표시 |
| A-LV-GHI-04 | 엑셀 다운로드 | 조회 조건 그대로 다운로드 | 사유 입력 필수 |

## 4. 정책 · 비즈니스 룰
1. 읽기 전용 화면입니다. 이력의 추가·수정·삭제는 불가하며 그룹 구성원 변경 시 자동으로 쌓입니다.
2. 조회 기간은 필수이고 최대 365일입니다.
3. 필터는 이력 기준입니다(현재 소속 기준인 다른 화면과 다름).
4. 휴가 그룹에 한 번도 소속된 적 없는 구성원은 조회되지 않습니다.
5. 시작일이 미래인 이력(변경 예정)의 소속일수는 0일로 표시합니다. 종료일이 미래이거나 정해지지 않은 이력은 오늘까지의 일수로 표시합니다.
6. 퇴직한 구성원의 이력도 그대로 남아 조회됩니다.

## 5. 메시지 · 예외 처리
