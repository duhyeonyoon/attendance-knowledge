[휴가 그룹 이력 관리](../leave/group-history.md)와 화면·동작이 같아, 두 화면의 공통 명세를 이 페이지에 둡니다.

## 1. 개요

구성원이 언제부터 언제까지 어떤 근무그룹(휴가 측은 휴가그룹)에 소속되었는지 **이력을 조회**하는 읽기 전용 화면입니다. 이력은 [근무 그룹 설정](./group-setting.md)의 구성원 설정 탭에서 소속을 변경해 저장할 때 시스템이 자동으로 쌓으며, 이 화면에서 추가·수정·삭제할 수 없습니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 필터 | "조회 기간"(필수), "구성원", "회사", "조직", "근무 그룹(이력 기준)", "근무제 유형", [조회] / [필터 재설정] | 휴가 측은 근무 그룹·근무제 유형 대신 "휴가 그룹(이력 기준)". 활성 여부 필터는 없음 |
| 이력 리스트 — 기본 정보 | No · 사번 · 이름 · 회사 · 조직 · 직급 · 퇴사 여부("퇴사"/"재직") · 활성 여부("활성"/"비활성") · 현재 근무 그룹 | 휴가 측: 현재 휴가 그룹 · 입사일 · 연차기산일 |
| 이력 리스트 — 소속 이력 정보 | 근무 그룹 · 근무제 유형 · 소속 시작일 · 소속 종료일 · 소속 일수 | 휴가 측: 휴가 그룹 · 소속 시작일 · 소속 종료일 · 소속 일수. 한 구성원이 여러 그룹을 거쳤으면 여러 행 |
| 상단 버튼 | 엑셀 다운로드 | 사유 입력 필수 |

## 3. 기능 상세

### 3.1 조회

|---|---|---|---|
| A-WRK-GHI-01 | 이력 조회 | 필터 조건으로 소속 이력 조회. 조회 기간과 소속 기간이 하루라도 겹치는 이력을 보여줌 | 조회 기간은 필수(지울 수 없음), 기본값 올해 1월 1일 ~ 오늘, 최대 365일 |

## 4. 정책 · 비즈니스 룰

1. **읽기 전용** — 이력은 근무/휴가 그룹 구성원 변경 저장 시 자동 기록되며, 이 화면에서 편집할 수 없습니다.
2. 이력이 쌓이는 방식: 구성원 변경일이 새 이력의 시작일이 되고, 직전 이력은 변경일 전날로 종료됩니다(빈 기간 없음). 마지막(진행 중) 이력의 종료일은 9999.12.31로 표시됩니다.
3. **필터는 이력 기준** — 근무 데이터 관리 등 다른 화면(현재 소속 기준)과 다릅니다. 예: 작년 그룹 X → 올해 그룹 Y로 옮긴 구성원은 그룹 X로 필터해도 작년 이력이 조회됩니다.
4. 근무그룹에 한 번도 소속된 적 없는 구성원은 조회되지 않습니다.
5. 조회 기간은 필수이며 최대 365일입니다.
6. 소속 일수는 오늘 기준으로 계산합니다. 시작일이 미래인 이력은 0일, 진행 중이거나 종료일이 미래인 이력은 오늘까지의 일수입니다.
7. 퇴직한 구성원의 이력도 그대로 남아 조회됩니다.
8. 엑셀 다운로드 시 사유 입력이 필수입니다(감사 로그).
9. 근무그룹에 이력이 한 건이라도 있으면 해당 근무그룹은 삭제할 수 없습니다([근무 그룹 설정](./group-setting.md) 참조).

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 조회 기간 비우기 시도 | 지울 수 없음(필수). 기간 없이 조회 시 "조회 실패" / "기간을 선택해주세요." |
| 조회 기간 365일 초과 | "조회 실패" / "조회 기간은 365일 이내로 설정합니다." — 조회되지 않음 |
| 소속 종료일 헤더 툴팁 | "마지막 소속 이력의 종료일은 9999.12.31로 표시됩니다." |
| 소속 일수 헤더 툴팁 | "소속 일수는 오늘 날짜 기준으로 계산됩니다. 종료일이 확정되지 않았거나 미래 날짜인 경우에도 오늘까지의 일수로 표시되며, 시작일이 미래인 이력은 0일로 표시됩니다." |
| 엑셀 다운로드 사유 미입력 | 다운로드 불가 |
