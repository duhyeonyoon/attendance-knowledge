> **URL** `/attendance/member_leave`
> **탭** 구성원 휴가 일정 · 구성원 휴가 현황
> **사용자** 직책자·관리자 (권한 없으면 본인만)

## 1. 개요

직책자/관리자가 권한 범위 내 구성원의 **휴가 일정과 휴가 보유·사용 현황**을 확인하고, 들어온 휴가 승인 요청을 **요청 모아보기**에서 일괄 처리하는 화면입니다. 공통 권한·워크플로우 규칙은 [구성원 근무](./member-work.md)와 같습니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 탭: 구성원 휴가 일정 | 필터(구성원 이름, 조직), 목록, 페이지네이션 | 일자별 구성원 휴가 |
| 탭: 구성원 휴가 일정 | 요청 모아보기 버튼 | 빨간 dot + 건수 |
| 탭: 구성원 휴가 현황 | 연도(작년/올해/내년), 휴가 유형 2단 필터, 목록, 엑셀 다운로드 | 구성원별 휴가 부여·사용 현황 |

**구성원 휴가 일정 컬럼**: 구성원, 회사, 조직, 휴가일, 휴가시간, 시작시간, 종료시간 (컬럼별 정렬 가능)

## 3. 기능 상세

### 3.1 구성원 휴가 일정

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-ATT-MBL-01 | 휴가 일정 조회 | 구성원 휴가를 일자별 목록으로 조회, 페이지네이션 + 컬럼 정렬 | 본인 소속 회사 하위만 |
| U-ATT-MBL-02 | 필터 | 구성원 이름·조직으로 필터 | 본 소속·겸 소속과 각 상위 조직으로도 조회 |
| U-ATT-MBL-03 | 요청 모아보기 | 빨간 dot+건수 → 휴가 승인 요청 목록 → 여러 건 선택 후 일괄 승인/반려 | 실패 시 실패 문서와 사유 표시 |

### 3.2 구성원 휴가 현황

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-ATT-MBL-04 | 휴가 현황 조회 | 조회 연도(회계연도 시작일 기준 1년)에 사용기한이 걸친 휴가를 구성원별로 표시 | 직책자 권한 없으면 본인만, 있으면 권한 내 구성원 모두 |
| U-ATT-MBL-05 | 휴가유형 필터 | 1단 "연차 휴가" / "연차 외 휴가" → 2단 "전체 휴가" / "연차" / "1년 미만 연차" (연차 외는 "전체 휴가" / 휴가제도 목록) | 4.2 참고 |
| U-ATT-MBL-07 | 엑셀 다운로드 | 현황 목록을 엑셀로 다운로드. 다운로드 전 "다운로드 사유" 입력 팝업 | 사유 미입력 시 "사유를 입력해야 다운로드 가능합니다." |
| U-ATT-MBL-06 | 개별 기한 상세 | 다건 부여 휴가(1년 미만 연차, 수동 부여 연차 외)는 개별 기한 표시, 돋보기로 상세 | — |

## 4. 정책 · 비즈니스 룰

### 4.1 조회 범위

1. 직책자 권한 없음 → 본인만 / 있음 → 권한 내 구성원 모두.
2. 본인 소속 회사 하위만 조회되며, 조직은 소속 구성원이 있는 조직만 표시됩니다 (2025.04.17 기준 임시 제약).

### 4.2 휴가 현황 표시 규칙

| 대상 | 규칙 |
|---|---|
| 연차 휴가 > 전체 휴가 | 조회 연도에 걸친 연차·1년 미만 연차 생성이 하나도 없는 구성원도 포함되며, 휴가 유형 칸에 "생성 필요" 표시 (부여·사용·잔여 0) |
| 연차 / 1년 미만 연차 / 연차 외 휴가 선택 | 해당 휴가가 생성된 구성원만 |
| 사용률 | 사용일 ÷ 부여일 |
| 연차 (연차기산일 ≠ 1월 1일 + 입사일 기준 부여) | 귀속연도별로 분리 → 같은 구성원이 **두 행**으로 조회될 수 있음 |
| 1년 미만 연차 | 귀속연도가 달라도 **한 행**. 귀속연도 모두 표시 + 개별 기한, 돋보기로 상세 |
| 수동 부여 연차 외 휴가 | 사용일수와 무관하게 **귀속연도 기준** 조회 (모두 사용해도 그해는 노출). 같은 해 여러 건 부여 시 개별 기한으로 상세 |

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 연차 미생성 구성원 (연차 휴가 > 전체 휴가) | 휴가 유형 "생성 필요" |
| 엑셀 다운로드 사유 미입력 | "사유를 입력해야 다운로드 가능합니다." |
| 엑셀 다운로드 실패 | "다운로드 실패" — "엑셀 다운로드에 실패했습니다. 다시 시도해 주세요." |
| 일괄 승인/반려 일부 실패 | 실패한 문서와 사유 간략 표시 |
| 다른 탭/사용자가 먼저 처리한 문서 | 처리 실패 |
