> **메뉴** 근무 신청 › 대체근무
> **진입** 출퇴근 위젯 [근무신청] › 신청서 종류 선택
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
근무일과 휴일/휴무일을 **한 쌍으로 맞바꾸는** 신청서입니다. 휴일/휴무일에 근무하는 대신(대체 근무일) 원래 근무일을 쉬는 날(대체 휴일/휴무일)로 바꿉니다. 두 일자가 짝으로 묶이므로 다른 신청서보다 유효성 조건이 많습니다.

| 일자 | 대체 휴일/휴무일 | 근무스케줄상 근무일인 날만 선택 가능 |

## 4. 정책 · 비즈니스 룰
1. 근무그룹 설정 › 대체근무 관리 › 대체근무 허용 = **'승인 시에만 대체근무 가능'** 일 때 신청 가능.
2. 다음 경우 신청 불가:

| # | 불가 조건 |
|---|---|
| 1 | 이미 요청중인 대체근무 신청서와 중복 |
| 2 | 해당 일자에 근무계획 변경 신청서가 요청중 |
| 3 | 두 일자가 서로 다른 정산기간 |
| 4 | 두 일자가 서로 다른 근무그룹 소속 |
| 5 | 해당 일자의 그룹 설정이 대체근무 불가 |
| 6 | 대체 근무일의 기존 스케줄이 휴일/휴무일이 아님 |
| 7 | 대체 휴일/휴무일의 기존 스케줄이 근무일이 아님 |
| 8 | 선택 일자에 근무그룹/스케줄이 없음 |
| 9 | 근무 마감된 일자 (요청/승인 불가) |
| 10 | 해당 정산기간에 근무계획 수립 신청이 요청중 |
| 11 | 신청 후 근무그룹이 바뀜 (신청 시점과 현재 근무그룹이 다름) |

3. 대체근무와 근무계획 변경은 상호 배타 — 대체근무가 요청중이면 근무계획 변경 신청도 막힘.

- **결재 완료 후 되돌리기 (기획 확인 2026-11-05)**: 사용자·어드민 모두 승인 취소 기능이 없습니다. 날짜를 맞바꿔 대체근무를 다시 신청하는 것이 권장 방법입니다 (예: 11/7 근무 ↔ 11/10 휴무로 승인됐다면 11/10 근무 ↔ 11/7 휴무로 재신청). 대체 근무일·휴일이 미래 일자라면 어드민 개인 근무 스케줄 관리에서 해당 개인 스케줄을 삭제해 그룹 기본 스케줄로 돌릴 수도 있으나, 신청서는 그대로 남습니다. 지난 날짜·마감 기간은 화면으로 되돌릴 수 없습니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 1. 요청중 대체근무와 중복 | "해당 날짜에 이미 신청한 대체근무 요청이 있습니다. 기존 대체근무 정보와 중복되지 않는 경우에만 대체근무 신청이 가능합니다." + 기존 신청 내용("휴일 -> 근무일" 등) |
| 2. 근무계획 변경 요청중 | "해당 날짜에 이미 신청한 근무계획변경 요청이 있습니다. 기존 근무계획변경 정보와 중복되지 않는 경우에만 대체근무 신청이 가능합니다." |
| 3. 다른 정산기간 | "선택한 대체 근무일의 정산기간 안에 포함되는 날짜를 선택합니다. (시작 ~ 종료)" |
| 4. 다른 근무그룹 | "대체 휴일/휴무일 날짜가 선택한 대체 근무일과 다른 근무그룹입니다. 근무그룹이 같은 날의 경우에만 대체근무 신청이 가능합니다." |
| 5. 그룹 설정 대체근무 불가 | "대체근무 신청을 할 수 없도록 설정되어 있습니다. 담당자에게 문의바랍니다." |
| 6. 대체 근무일이 휴일/휴무일 아님 | "대체 근무일은 휴일 또는 휴무일만 선택할 수 있습니다." |
| 7. 대체 휴일/휴무일이 근무일 아님 | "대체 휴일/휴무일은 근무일만 선택할 수 있습니다." |
| 8. 근무그룹/근무계획 없음 | "근무그룹이 설정되어있지 않습니다." / "근무계획이 설정되어있지 않습니다." |
| 9. 마감된 일자 | "선택한 일자의 근무가 마감되어 대체 근무를 신청할 수 없습니다." |
| 10. 근무계획 수립 요청중 | "선택한 정산기간에 요청중인 근무계획 수립 신청이 있습니다. 근무계획 수립 신청이 완료된 후 대체근무를 신청할 수 있습니다." |
| 11. 근무그룹 변경 발생 | "근무그룹 변경이 발생했습니다. 현재와 대체근무 신청시점의 근무그룹이 다릅니다." |
| 일자 미선택 | "대체 근무일을 선택합니다." / "대체 휴무일을 선택합니다." |
| 코멘트 / 첨부 필수인데 미입력 | "코멘트를 입력합니다." / "첨부파일을 업로드합니다." |
| 신청서 사용 중지 | 모달 "대체근무 신청 불가 안내" / "대체근무 신청서 사용이 중지되었습니다." |
