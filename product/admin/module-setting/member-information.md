## 화면 구성

| 영역 | 구성 요소 |
|------|------|
| 상단 | 타이틀 "구성원 정보" + **[구성원 등록] 버튼(항상 비활성)** |
| 연동 안내 (구성원 제공자 = talenx 인사관리일 때만) | "조직-구성원 연동 중입니다. 연동 시스템에서 조직-구성원 정보를 수정해야 합니다." / "연동 구분: talenx 인사관리" / "마지막 연동 일자: YYYY.MM.DD" |
| 필터 | 입사일 기간 · 구성원 · 회사 · 조직 · 휴가 그룹 · 근무 그룹 · 활성 상태(활성/비활성) + [조회] [필터 재설정] |
| 목록 (서버 페이징) | 사번 · 이름 · 성별 · 입사일 · **연차기산일(편집 셀)** · 휴가 그룹 · 근무 그룹 · 회사 · 조직 · 조직장 여부 · 겸임/겸직(본/겸/겸직관리) · 직책 · 직급 · 직위 · 호칭 · 휴직 여부 · 퇴사 여부 · 퇴사일 · 활성 여부 · 생성시간 · 인사 정보(재직 상태 · 활성 상태) |
| 목록 하단 | [항목 설정](컬럼 표시·고정) · [엑셀 다운로드] · [변경 내용 취소] · [저장] |

- **필터링 + 엑셀 다운로드**
  - [필터 재설정] → 필터 초기화 (재조회 X)
  - 엑셀 다운로드 → 사유 입력 모달 "구성원 정보 엑셀 다운로드" (사유는 요청 헤더 `TALENX-LOG-REASON`로 전달), 파일명 `구성원_정보_YYYY-MM-DD`
- **인사 모듈 연동 시** → 페이지 상단에 연동 정보 노출 (`memberProvider === "TALENX_HRM"`)
- 연차기산일 컬럼 헤더 툴팁: "연차기산일 입력시 입사일 대신 해당 날짜를 기준으로 연차를 산정합니다."
- 연차기산일·편집 관련 컬럼은 숨김 불가(표시 체크 disabled), 핀 고정은 자유

## 연차기산일 수정/삭제

- 날짜 셀에서 직접 입력/삭제 (삭제 = 빈 값 저장 → 입사일 기준으로 산정)
- 수정 시 [변경 내용 취소] / [저장] 버튼 활성화 (`!isChanged` 이면 둘 다 비활성)
- [변경 내용 취소] → 수정 내용 되돌림
- **유효하지 않은 날짜**가 하나라도 있으면 셀 글자 빨간색 + [저장] 비활성 (`isInvalidBaseYmd`)
- 저장: `PATCH /time/members` (`be:controller/setting/MemberInformationController#updateMembers`) — 근무 총괄(`TALENX_TIME_ADMIN`) 전용
  - 백엔드 검증: 대상 없음 → "수정하려는 구성원이 없습니다.", memberId 없음 → "유효하지 않은 구성원을 포함합니다.", 날짜 형식 오류 → "유효하지 않은 연차기산일을 포함합니다: …"
  - 저장 실패 시 화면 편집값은 초기화
- **(2026-11-05 확인) 저장은 구성원의 연차기산일 값만 갱신하고 이미 생성된 연차는 재계산하지 않음** (`be:service/setting/MemberInformationService.updateMembers:75-98` — 단순 batch update, 후속 이벤트/재생성 호출 없음). 바뀐 기산일은 다음 연차 자동 생성(재생성) 시점부터 반영 → 기존 행과 어긋나면 연차 조정이 막힐 수 있음 (`KB:product/admin/leave/annual-management.md` § 기산일 검증 비대칭)
