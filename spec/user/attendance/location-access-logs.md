> **메뉴** 근무관리 › 위치정보 제공 조회
> **URL** `/attendance/location_access_logs`
> **사용자** 사용자(구성원 본인)

## 1. 개요

**다른 사람이 내 위치 정보를 조회한 이력**을 확인하는 개인정보 보호 화면입니다. 근무지 외 출퇴근 요청에 담긴 위치를 승인자·참조자가 열람하면 신청자의 이 화면에 로그가 쌓입니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 필터 | 년 셀렉트, 월 셀렉트 | 각각 "전체" 포함. 로그가 있는 년/월만 선택지로 표시 |
| 목록 | "사실 확인자료" 테이블: 사번 · 제공 받은자 · 위치정보 취득경로 · 주소정보 취득경로 · 제공 서비스 · 제공방법 · 이용제공일시 | 페이지네이션 |

## 3. 기능 상세

### 3.1 로그 조회

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-ATT-LOC-01 | 로그 목록 조회 | 내 위치를 조회한 이력을 테이블로 표시 | 페이지네이션 |
| U-ATT-LOC-02 | 필터 | 년/월 셀렉트로 기간 선택 → 해당 기간 로그만 표시 | 월을 고를 땐 년도도 선택해야 함 |

**테이블 컬럼**

| 컬럼 | 내용 |
|---|---|
| 사번 · 제공 받은자 | 내 위치를 조회한 사람 |
| 위치정보 취득경로 | 위치를 수집할 때(출퇴근 요청 시) 내 기기 정보 |
| 주소정보 취득경로 | "Google" |
| 제공 서비스 | "위치기반 출퇴근 기록 서비스" |
| 제공방법 | "서비스 내 조회" |
| 이용제공일시 | 조회된 일시 |

## 4. 정책 · 비즈니스 룰

**로그 기록 조건** — 아래 두 조건을 모두 만족해야 기록됩니다.

| 조건 | 설명 |
|---|---|
| 타인이 내 위치를 조회 | 근무지 외 출퇴근 요청 **문서를 여는 것**, 또는 **위치 확인**을 누르는 것 모두 기록. 본인 조회는 기록 안 함 |
| 위치 정보가 있음 | 요청에 위치(주소) 정보가 담겨 있어야 함 |
| 위치 정보 보관 기간 내 | 요청일로부터 3개월 이내. 3개월이 지나면 위치 정보가 파기되어 더 이상 조회·기록되지 않음 |

| 조회 경로 | 로그 |
|---|---|
| 워크플로우 › 받은 문서함에서 근무지 외 출퇴근 문서 확인 | 기록 |
| 근무관리 › 구성원 근무 › 요청 모아보기에서 확인 | 기록 |
| 브라우저 위치 허용 거부 + 위치 정보 없이 근무지 외 출퇴근 요청 → 타인 확인 | **기록 안 됨** |

**보존 기간**

| 대상 | 보존 |
|---|---|
| 출/퇴근 요청에 담긴 위치 정보 | 요청일로부터 3개월. 이후 매일 새벽 자동 파기 |
| 이 화면의 조회 로그 | 별도 파기 없이 계속 보관 |

- 조회 로그는 위치정보법상 '위치정보 이용·제공사실 확인자료'로, **최소 6개월 이상 자동 보존**이 요구됩니다. 로그에는 실제 위치(주소·좌표)를 남기지 않고 조회자·대상자·취득경로·일시만 남깁니다 (기획 확인 2026-11-05). 보존 상한(언제 파기할지)은 정해지지 않았습니다.

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 조회 결과 없음 | "위치정보 조회가 없습니다." |
| 년도 "전체" + 특정 월 선택 | "조회년도를 선택합니다." |

## 6. 연관 기능

- [출퇴근 위젯](../home/checkin-widget.md) — 근무지 외 출퇴근 요청과 위치 정보 생성
- [구성원 근무](./member-work.md) — 요청 모아보기의 위치 확인 (요청 3개월 이내만)

## 7. 확인 필요

- 조회 로그의 보존 **상한**을 둘지 (법적 하한 6개월은 충족 중, 현재 파기 기능 없음).
