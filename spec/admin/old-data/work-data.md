> **사용자** 어드민(근무 총괄, 서브어드민)

## 1. 개요
서비스 도입 이전 또는 외부 시스템에서 누적된 과거 근무 데이터를 엑셀로 업로드해 시스템에서 조회할 수 있게 하는 화면입니다. 데이터 마이그레이션·이력 보존 용도이며, 업로드한 데이터는 **조회 전용**으로 일반 근무 집계·정산에 영향을 주지 않습니다. [과거 휴가 데이터 관리](./leave-data.md)와 거의 같은 패턴이므로 두 화면의 공통 명세를 이 페이지에 둡니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 필터 | 연월 필터(필수), 회사 · 구성원 · 조직, [조회], [필터 재설정] | 연월 기본값: 이번달, 지울 수 없음. 회사·구성원·조직 선택지는 업로드된 데이터 기준 |
| 목록 | 사번 · 이름 · 회사 · 조직 · 직급 · 연도/월 · 근무 계획 · 사전 승인 추가 근무시간 · 지각/조퇴 · 확정 근무 시간(근무일 / 휴무일 / 휴일) · 메모 | 행마다 좌측 체크박스, 좌측 상단 [삭제]. 상단에 "조회용" 배지와 "실제 서비스에 영향을 주지않는 과거 데이터 조회용 페이지입니다." 안내 |
| 액션 | [과거 데이터 업로드] | 드래그 앤 드랍 업로드 모달 오픈 |
| 업로드 모달 | 파일 드래그 앤 드랍 영역, [엑셀 양식 다운로드] | — |

## 3. 기능 상세
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-OLD-WRK-01 | 화면 진입 | 데이터가 없는 상태로 열림 | 자동 조회하지 않음 |
| A-OLD-WRK-02 | 조회 | [조회] 클릭 시 필터 조건으로 조회 | 연월 필터는 필수이며 비울 수 없음 |
| A-OLD-WRK-03 | 엑셀 양식 다운로드 | 업로드 모달의 [엑셀 양식 다운로드]로 양식 파일 다운로드 | — |
| A-OLD-WRK-04 | 과거 데이터 업로드 | 엑셀을 드래그 앤 드랍 → 밸리데이션 → 정상이면 추가 컨펌 → [확인] 시 업로드 진행 → 완료 스낵바 | 오류가 한 행이라도 있으면 문제 행을 순서대로 표시하고 **전체를 업로드하지 않음** (정상 행만 올리지 않음). 비밀번호가 걸린 파일은 업로드 불가 |
| A-OLD-WRK-05 | 삭제 | 행 체크박스 선택 후 좌측 상단 [삭제] → "과거 근무 데이터 n건을 삭제합니다. 계속 진행하시겠습니까?" 확인 | 다중 선택 삭제 지원. 삭제는 복구 불가 |
| A-OLD-WRK-06 | 권한별 조회 범위 | 근무 총괄은 전체, 서브어드민은 본인 소속 회사 사용자가 등록한 데이터만 조회 | 4.1 참고 |

## 4. 정책 · 비즈니스 룰
1. 과거 데이터는 일반 근무 데이터와 분리된 **조회 전용** 데이터이며 근무 집계·정산에 영향을 주지 않습니다.
2. 필수 필터가 항상 채워져 있어야 조회할 수 있습니다 (빈 값으로 전체 조회 불가).
3. 페이지를 열 때 자동 조회하지 않고, [조회]를 눌러야 조회합니다.
4. 엑셀 업로드는 행 단위로 밸리데이션하며, 오류가 있으면 몇 번째 행에서 문제가 생겼는지 표시하고 파일 전체를 저장하지 않습니다.
5. 같은 구성원·같은 연월 데이터를 다시 업로드하면 덮어쓰거나 거부하지 않고 **새 행으로 추가**됩니다. 잘못 올린 경우 해당 행을 삭제해야 합니다.
6. 삭제는 복구할 수 없는 완전 삭제입니다.
7. 과거 데이터는 **어드민 전용**이며 사용자 화면에는 노출되지 않습니다.
8. 과거 데이터는 도입 고객사의 이전 시스템 기록을 옮겨 두기 위한 것으로, 근무 모듈의 구성원·소속·설정과 연결하지 않는 단순 기록입니다. 그래서 필수값과 형식만 검증합니다. (기획 확인 2026-11-05)
8. 업로드한 구성원 정보(사번·이름·회사명 등)는 엑셀 값 그대로 보관하며 근무 모듈의 구성원과 연결하지 않습니다.

### 4.0 엑셀 양식 (과거 근무)
| 구분 | 컬럼 |
|---|---|
| 기본 | 사번 · 이름 · 회사(명) · 조직 · 직급 · 연도/월 |
| 근무 계획 | 계획 근무일 · 계획 근무 시간 · 최대 근무 시간 |
| 사전 승인 추가 근무시간 | 연장/야간/휴일 근무시간 |
| 지각/조퇴 | 지각 횟수 · 지각 시간 · 조퇴 횟수 · 조퇴 시간 |
| 확정 근무 시간(근무일) | 근무일 · 총 / 기본 / 연장 / 야간 근무 시간 |
| 확정 근무 시간(휴무일) | 휴무일 근무일 · 휴무일 총 / 기본 / 연장 / 야간 근무 시간 |
| 확정 근무 시간(휴일) | 휴일 근무일 · 휴일 총 / 기본 / 연장 / 야간 근무 시간 |
| 기타 | 메모 |

- 필수: 사번 · 이름 · 회사명 · 연도/월. 연도/월은 YYYYMM, 시간 항목은 분 단위 0 이상 정수 (예: 1시간 30분 → 90)

### 4.1 권한별 조회 범위
| 권한 | 조회 범위 |
|---|---|
| 근무 총괄 | 전체 |
| 서브어드민 | 본인 소속 회사의 사용자가 등록한 데이터만 |

데이터 **등록자 기준**으로 같은 클라이언트 내 회사 간 데이터가 분리됩니다. "본인 소속 회사"는 업로드한 사람의 소속 회사이며, 엑셀의 회사명 컬럼과는 무관합니다.

### 4.2 과거 근무 / 과거 휴가 차이
| 항목 | 과거 근무 | 과거 휴가 |
|---|---|---|
| 필수 필터 기본값 | 이번달 연월 | 올해 연도 |
| 업로드 컨펌 문구 | "조회용 과거 근무 데이터" | "조회용 과거 휴가 데이터" |

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 업로드 데이터 정상 | "총 n건의 조회용 과거 근무 데이터를 추가합니다." 컨펌 |
| 업로드 완료 | "과거 근무 데이터 업로드가 완료되었습니다." |
| 업로드 데이터 오류 | "총 n건에서 m개의 데이터 오류 확인이 필요합니다." + "{행}행: {메시지}" 순차 표시 |
| 필수값 누락 | "사번은 필수 입력 항목입니다." / "이름은 필수 입력 항목입니다." / "회사명은 필수 입력 항목입니다." / "연도/월은 필수 입력 항목입니다." |
| 형식 오류 | "연도/월 형식이 올바르지 않습니다. (YYYYMM)" / "숫자 형식이 올바르지 않습니다. (0 이상의 정수만 허용)" |
| 비밀번호 설정 파일 | "비밀번호가 설정된 엑셀 파일은 업로드할 수 없습니다." |
| 삭제 확인 / 완료 | "과거 근무 데이터 n건을 삭제합니다. 계속 진행하시겠습니까?" / "과거 데이터 삭제를 완료하였습니다." |
