## 4. 정책 · 비즈니스 룰

| "승인 대기중" | 결재 대기 (목록 칩·근무 화면에서는 "요청중") |
| "담당자 처리중" | 담당자 처리 단계 |
| "승인완료" | 근무 데이터에 반영 |
| "반려" | 결재자가 반려 |
| "취소" | 결재 전 신청 자체 취소(회수) |
| "승인 후 취소" | 승인 건이 취소 신청으로 취소됨 |

| 위치 | 라벨 |

| 출퇴근 위젯 · 내 근무 · 구성원 근무 | "요청중", "취소중"(취소 신청서 결재 대기) |
| 결재 문서 상세 버튼 | "승인", "반려", "요청 취소" |

### 4.2 공통 룰
1. **근무그룹 허용 설정** — 사전 휴일근무·연장·야간은 그룹 설정이 '승인시에만'일 때만 신청 의미가 있음. '자유 허용'이면 신청 불필요, '불가'이면 신청 불가 및 출퇴근 위젯에서 사전 차단.
2. **근무 마감 차단** — 모든 신청서에서 마감된 일자는 요청·승인·승인 건의 취소요청·취소승인 모두 불가. 마감은 개인 단위.
3. **신청 vs 취소 신청 분리** — 결재 전 취소와 결재 완료 후 취소 신청은 별개 흐름. 결재 완료 후 취소는 새 신청서를 만드는 행위.
4. **요청 일자 캘린더** — 휴일근무는 근무일유형이 휴일인 날만, 연장/야간은 휴일이 아닌 날(근무일·휴무일)만 선택 가능 (정반대). 둘 다 오늘 이전 날짜는 선택 불가.
5. **기간 신청 가능 여부** — 휴일근무·연장/야간·근무내역 변경은 단일 일자. 재택·기타근무·근무계획 변경은 기간 선택 가능. 대체근무는 두 일자를 짝으로 선택.
6. **시간 검증** — 화면에서 1차 검증 후 서버가 최종 판정.
7. **최소 초과근무시간** — 합산이 아닌 신청서 1건 단위로 검증.
8. **최대 초과근무시간 미설정** — 법적 기준 잔여시간("잔여 12h", 주간 예상 근무가 40시간을 넘으면 52시간에서 뺀 값)이 표시만 되고, 초과해도 차단되지 않음.
9. **대체근무 ↔ 근무계획 변경 상호 배타** — 한쪽이 요청중이면 해당 일자에 다른 쪽 신청 불가.
10. **개인스케줄 우선** — 개인스케줄(근무스케줄 화면·근무계획 변경으로 생성)이 그룹스케줄보다 우선.
11. **어드민 직접 수정 일자** — 어드민이 출퇴근 내역을 직접 수정한 일자는 근무내역 변경 신청 불가.
12. **겹침 판정** — 같은 종류 신청서끼리만 비교(휴일근무↔휴일근무, 연장/야간↔연장/야간 — 사전·사후 신청을 합쳐서 비교). 요청중·승인 상태인 신청서 중 신청일 전일~익일 것과 시간이 겹치면 신청 불가.
13. **결재 완료 후 취소 가능 신청서** — 사전 휴일근무 · 사전 연장/야간 · 재택 · 기타근무 (+ 휴가) (**(2026-11-05)** + 사후 휴일근무 · 사후 연장/야간). 대체근무 · 근무계획 변경 · 통합 근무내역 변경 (**(2026-11-05)** + 출퇴근 내역 변경 · 근무계획 수립)은 결재 완료 후 취소 불가.
14. **신청서 설정** — 어드민 "근무 신청서 관리"의 신청서별 설정(사용 여부, 설명, 첨부/코멘트 필수 등)을 따름. 사용 중지된 신청서를 열면 "신청서 사용이 중지되었습니다." 안내 모달.

### 4.3 출퇴근 위젯·다른 화면에 미치는 효과
| 신청서 | 출퇴근 위젯 | 다른 화면 |
|---|---|---|
| 사전 휴일근무 | 승인 없으면 휴일 출/퇴근 시 안내문 확인 필요, 승인 시 정상 처리 | 내 근무에서 상세·취소 |
| 사전 연장/야간 | 승인 시간 외 → 안내문, 잔여시간 초과 → 차단. 그룹 설정이 '승인시에만'이면 예상 퇴근시간 초과 텍스트가 빨간색("승인 안 받으면 비근무"), '자유 허용'이면 주황색 | 내 근무에서 상세·취소 |
| 재택 | 승인 시 근무지(GPS) 제약 해제 + 재택 칩 | 구성원 근무 현황 재택 칩 |
| 기타근무 | 요약 표시(2건 이상 아코디언), 재택 칩보다 우선 노출 | 종일 승인 시 누락 처리 안 함, 캘린더 표시 |
| 대체근무 | 직접 영향 없음 | 근무계획 변경 신청 차단 |
| 근무계획 변경 | 직접 영향 없음 | 대체근무 신청 차단, 개인스케줄 생성 |
| 근무내역 변경 | "근무 내역 변경" 버튼으로 진입 | 어드민 직접 수정 시 차단 |

- **결재 완료 후 정정 (기획 확인 2026-11-05)**: 대체근무·근무계획 변경·통합 근무내역 변경·출퇴근 내역 변경·근무계획 수립은 기존 기록을 고치는 신청서라 취소 신청서가 없고, 어드민 근무 신청 내역 관리도 조회 전용입니다. 잘못 승인된 경우 올바른 내용으로 **다시 신청**하며 나중에 승인된 건이 최종입니다. 휴가처럼 기록 자체를 지워야 하는 신청서만 취소 신청서를 둡니다.
- **기타근무와 재택이 같은 날 겹칠 때**: 출퇴근 위젯·근무 현황 칩은 한 자리를 공유하며 기타근무를 우선 표시합니다. 전사 근무 계획 캘린더는 휴가 → 기타근무 → 재택 → 기본근무 순으로 정렬하고, 기타근무와 겹친 재택은 툴팁 등으로 함께 보여주는 방향입니다. 내 근무 캘린더는 현재 두 항목을 함께 표시하며, 이 화면의 규칙은 확인이 필요합니다 ([내 근무](../attendance/my-work.md) 7절).

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 마감된 일자 포함 | 요청·승인·취소 불가 |
| 같은 날 이미 신청된 문서가 있음 (휴일근무·연장/야간) | 겹치지 않으면 신청 가능하다는 안내 문구 |
| 어드민이 직접 수정한 일자에 근무내역 변경 | "해당 일자의 근무내역은 어드민이 수정 및 확정하였습니다." |
| 승인 시 마감일 | "근무가 마감되어 요청을 승인할 수 없습니다." |
| 취소 시 마감일 | "근무가 마감되어 요청을 취소할 수 없습니다." |
| 요청중 신청서 존재 | 출퇴근 위젯에 "요청중" 칩 |
