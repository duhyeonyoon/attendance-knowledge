> **사용자** 어드민(근무 담당자)

## 1. 개요

사용자가 올린 근무 관련 신청서를 어드민이 **조회·모니터링**하는 화면입니다. 신청서 종류별로 10개 탭이 있고, 각 탭은 사용자 화면의 신청서 1종과 짝을 이룹니다. 신청 결과(요청중 / 승인완료 / 취소 / 반려 / 승인완료 후 취소)를 확인하고 엑셀로 내려받는 용도이며, **이 화면에서 승인·반려는 할 수 없습니다**(결재는 결재 화면에서 처리). 예외적으로 **기타근무 신청 탭에서는 어드민이 엑셀 업로드로 기타근무를 직접 등록하고, 어드민이 등록한 건을 삭제**할 수 있습니다.

## 4. 정책 · 비즈니스 룰

1. 이 화면은 **조회 전용**입니다. 승인 · 반려 기능은 없으며 결재(워크플로우)에서 처리합니다. 유일한 쓰기 기능은 기타근무 수동 등록 · 삭제입니다.
2. 기타근무 탭만 어드민 직접 등록이 가능하며, 이렇게 등록된 기타근무는 신청-승인 절차를 거치지 않습니다.
3. 회사 필터 디폴트는 로그인 어드민의 회사, 조직 필터는 하위 조직을 포함해 조회합니다.
4. 엑셀 다운로드는 모든 탭에서 사유 입력이 필수입니다(감사 로그).
5. 어드민 등록 기타근무는 **근무 마감되지 않은 일자만** 삭제할 수 있고, 사용자가 신청한 기타근무는 이 화면에서 삭제할 수 없습니다.
6. 사전 · 사후 연장/야간의 야간 판정 기준은 22:00 ~ 06:00으로 고정입니다.
7. 탭마다 조회 · 표시되는 상태 종류가 다릅니다.
   - 근무계획 변경 · 재택근무 · 대체근무: 요청중 / 승인완료 / 취소 / 반려
   - 통합 근무내역 변경 · 출퇴근 내역 변경 · 기타근무: 요청중 / 승인완료 (반려 · 취소 건 미조회)
   - 연장/야간(사전 · 사후) · 휴일근무(사전 · 사후): 위 4종 + 승인완료 후 취소
8. 취소 신청서는 어느 탭에서도 별도 행으로 표시되지 않습니다. 재택근무는 "취소 상태" 컬럼, 연장/야간 · 휴일근무는 원 신청 상태("승인완료 후 취소")로 반영됩니다.
9. 휴가 신청은 이 화면이 아니라 [연차 관리](../leave/annual-management.md) · [연차 외 휴가 관리](../leave/non-annual-management.md) 화면에서 다룹니다. 출근/퇴근 요청은 결재(워크플로우)에서 처리됩니다.

### 어드민 동작의 영향

| 어드민 동작 | 영향 |
|---|---|
| 기타근무 수동 등록 | 사용자 [내 근무](../../user/attendance/my-work.md) 캘린더에 기타근무로 표시, 상세 시 관리자 등록 안내 다이얼로그 표시. 사용자 신청분과의 구분은 이 안내 다이얼로그("관리자에 의해 등록" + 등록 사유, 사유가 없으면 생략)로 하며 내 근무 캘린더 · 근무내역 상세 · 구성원 근무 현황에 동일 적용 (기획 확인 2026-11-05) |
| 기타근무 수동 등록 삭제 | 사용자 캘린더에서 제거, 근무 누락 판정이 바뀔 수 있음 |
| 신청 내역 조회 | 데이터 변경 없음 |
| 엑셀 다운로드 | 다운로드 사유 감사 로그 기록 |
