## 1. 개요
[휴가 설정](./base-setting.md)에서 정의한 연차 제도 · 연차 정산 기준 · 연차 외 휴가 제도를 묶어 **휴가 그룹**을 만들고, 그룹에 구성원을 배정하는 화면입니다. 화면 패턴은 [근무 그룹 설정](../work/group-setting.md)과 거의 동일합니다. 휴가 그룹은 근무 그룹과 독립적입니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 메인(목록) | 휴가 그룹 목록, [휴가그룹 추가], 페이징 | 최초 생성만 된 그룹은 "미확정" 태그 |
| 상세 – 휴가 설정 탭 | 휴가그룹명·메모, 연차 제도 / 연차 정산 기준 / 연차 외 휴가 제도 영역(각 [추가]), 우측 휴가설정 체크 리스트 | 그룹에 적용할 제도 선택 |
| 상세 – 구성원 설정 탭 | 검색 필터, 구성원 목록, 구성원 변경 모달 | 그룹 소속 구성원 관리 |

### 3.2 휴가 설정 탭
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-LV-GRP-05 | 그룹명 입력 | 휴가그룹명 입력 시 우측 휴가설정 리스트의 체크 표시 켜짐 | |
| A-LV-GRP-06 | 제도 추가 | 연차 제도 / 연차 정산 기준 / 연차 외 휴가 제도 각각 [추가] → 모달에서 선택 → 추가 | 연차 제도·연차 정산 기준은 그룹당 1개(단일 선택), 연차 외 휴가 제도는 여러 개 선택 가능. 정산 기준이 하나도 없으면 "연차 정산 기준이 없습니다." + [휴가 설정으로 이동]. 사용 안 함 처리된 제도가 연결돼 있으면 "사용 불가한 연차 제도"처럼 표시 |
| A-LV-GRP-07 | 제도 상세 보기 | 추가된 항목 클릭 → 상세 모달 | |
| A-LV-GRP-08 | 제도 제거 | 항목의 X 버튼으로 제거 | 확정 후에는 연차 제도 X 버튼, 정산 기준 [추가] 버튼 비활성화 + 툴팁("연차 제도는 최초 저장 이후 수정할 수 없습니다." / "연차 정산 기준은 최초 저장 이후 수정할 수 없습니다.") |
| A-LV-GRP-09 | 확정 후 수정 | 확정된 그룹은 이름·메모 수정, 연차 외 휴가 제도 추가/제거 가능 | 연차 제도·연차 정산 기준·회사는 변경 불가 |
| A-LV-GRP-10 | 저장 | 유효성 통과 시 즉시 저장 + 안내 모달 | 실패 시 오류 위치로 스크롤. **최초 저장 시 자동으로 다음 탭(구성원 설정)으로 이동** |
| A-LV-GRP-11 | 저장 전 탭 이동 | 저장 버튼 활성 상태에서 다른 탭 클릭 | "탭 이동" 모달: "변경사항이 저장되지 않았습니다. 저장하시겠습니까?" |

### 3.3 구성원 설정 탭
근무 그룹의 구성원 설정 탭과 동일한 패턴입니다.

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-LV-GRP-12 | 구성원 검색 | 필터: 휴가그룹 소속 기간, 키워드(성명/사번), 조직, 회사, 활성 여부 | |
| A-LV-GRP-13 | 구성원 변경 | 모달 좌측 검색 결과 ↔ 우측 그룹 소속, [>>] [<<] [>] [<] 버튼으로 이동 | |
| A-LV-GRP-14 | 변경일 지정 | 그룹 소속 변경 적용일 지정 | 기본값 = 당일. 기존 그룹이 없으면 입사일과 연차기산일 중 이른 날짜. **마지막 근무 마감일 이전으로 변경 불가** |
| A-LV-GRP-15 | 추가 구성원 표시 | 새로 추가된 구성원은 목록 상단에 노란색 배경으로 표시 | |

## 4. 정책 · 비즈니스 룰
1. 휴가 그룹은 근무 그룹과 독립입니다. 같은 구성원이 서로 다른 휴가 그룹·근무 그룹에 속할 수 있습니다.
2. 확정된 그룹은 연차 제도 · 연차 정산 기준 · 회사를 변경할 수 없습니다. 이름 · 메모 · 연차 외 휴가 제도는 변경 가능합니다.
3. 구성원이 그룹에 배정되면 그룹의 제도/정산 기준을 즉시 상속합니다.
4. 구성원 이력이 있는 그룹은 삭제할 수 없습니다.
5. 그룹 소속 변경일은 마지막 근무 마감일 이전으로 지정할 수 없습니다.
6. 연차 자동생성 시 생성 기준일에 휴가 그룹 소속이 없으면 생성이 실패합니다. 권장 순서는 연차기산일 입력 → 근무 그룹 배정 → 휴가 그룹 배정 → 연차 자동생성입니다.
7. 임시저장(미확정)/확정 동작은 근무 그룹과 같습니다. 미확정 그룹(최초 생성·복제 직후)은 내용 변경이 없어도 [저장]이 활성화되어 바로 확정할 수 있습니다. (기획 확인 2026-11-05)

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 그룹명 미입력 후 추가 | 필수 입력 오류 |
| 확정 그룹의 연차 제도 제거 / 정산 기준 추가 시도 | 버튼 비활성 + 툴팁 "연차 제도는 최초 저장 이후 수정할 수 없습니다." / "연차 정산 기준은 최초 저장 이후 수정할 수 없습니다." |
| 저장 유효성 실패 | 오류 위치로 스크롤 |
| 저장하지 않고 탭 이동 | "변경사항이 저장되지 않았습니다. 저장하시겠습니까?" |
| 변경일을 마지막 근무 마감일 이전으로 지정 | 변경 불가 |
