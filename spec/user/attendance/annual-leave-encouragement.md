## 1. 개요

어드민이 진행하는 **연차 사용 촉진 절차의 사용자 측 화면**입니다. 대상자는 여기서 미사용 연차 통지서를 확인하고, 연차 계획서를 작성·확정·서명하며, 어드민의 사용시기 지정 통보를 받습니다. 사용자는 어드민이 실행한 단계에 반응하는 구조입니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 헤더 | 연차촉진 그룹 셀렉트 | 본인이 속한 연차촉진 그룹 선택 |
| 문서 목록 | 미사용 연차 통지서, 연차 계획서 작성, 사용시기 지정 통보 | 단계별 문서와 상태 칩 |
| 연차 사용 계획 | 계획 목록 | 본인이 확정한 계획 / 어드민이 지정한 계획 |
| 연차 계획 작성 다이얼로그 | 계획 항목 입력 | 계획서 미작성 상태에서 문서 클릭 시 |

## 3. 기능 상세

### 3.1 연차촉진 단계

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-ATT-ENC-01 | 그룹 선택 | 어드민이 만든 연차촉진 그룹이 상단 셀렉트에 노출, 선택 시 해당 그룹 문서 표시 | 대상자로 지정된 경우 |
| U-ATT-ENC-02 | 미사용 연차 통지 확인 | 통지 문서 조회 후 확인(제출). 통지서에는 서명란이 없음 | 어드민이 통지 실행 후. 확인 전 상태 칩 "미서명", 확인 후 "확인완료" |
| U-ATT-ENC-03 | 연차 계획서 작성 | 통지 확인 후 노출되는 계획서 문서 클릭 → 작성 다이얼로그 | 계획서 미작성 상태 |
| U-ATT-ENC-04 | 계획서 확정 | [확정] → "작성한 연차 계획서를 정말 확정하시겠습니까?" → 확정 시 연차 사용 계획에 표시, 이후 계획서 문서 조회·서명 가능 | 확정 전까지 수정 가능. 사용시간 합계가 촉진 필요 시간과 같아야 확정 가능 |
| U-ATT-ENC-07 | 계획서 임시저장 | 작성 중 [임시저장] → "임시저장을 완료했습니다." | 다시 열면 임시저장 내용으로 시작 |

**연차 계획 작성 다이얼로그**

| 영역 | 구성 |
|---|---|
| 상단 요약 | 총 연차 · 의무 사용 연차 · 사용 연차 · 촉진 필요 (촉진 기준일 표시) |
| 사용시기 목록 | 행마다 사용일 + 사용시간(종일 체크 또는 시·분). [전체 종일 적용], [항목 추가], 행 삭제 |
| 안내 | "연차 계획서 작성은 휴가 요청과 무관하며 실제 사용할 휴가는 휴가 요청을 통해 등록하시기 바랍니다." |
| 버튼 | [임시저장], [확정], 닫기("정말 닫으시겠습니까?") |

| 항목 | 필수 | 형식/기본값 | 설명 |
|---|---|---|---|
| 사용일 | 필수 | 날짜 | 연차 사용기간 안, 휴일·휴무일 불가, 중복 불가 |
| 사용시간 | 필수 | 종일 또는 시·분 | 처음 열 때 촉진 필요 시간을 1일 표준근로시간으로 나눠 종일 행을 미리 만들고, 남는 시간은 마지막 행에 채움 |
| U-ATT-ENC-05 | 사용시기 지정 통보 수신 | 통보 문서 노출 + 연차 사용 계획에 어드민 지정 계획 표시 | 어드민이 통보 실행한 경우만 (선택 단계) |
| U-ATT-ENC-06 | 통보 알림 팝업 | 통보 날짜에 알림 팝업 | **확인 전까지 다른 화면 요소 클릭 불가** |

## 4. 정책 · 비즈니스 룰

| 단계 | 어드민 동작 | 사용자 화면 |
|---|---|---|
| 1 | 연차촉진 작업(그룹) 생성 | 셀렉트에 그룹 노출 |
| 2 | 미사용 연차 통지 실행 | 통지 문서 + 알림 → 조회·확인 |
| 3 | — | 연차 계획서 작성 → 확정 (어드민이 상세에서 열람) |
| 4 (선택) | 사용시기 지정 통보 | 통보 문서 + 강제 알림 팝업 |

1. 연차 사용 여부는 **연차**에만 집계됩니다. 지정 일자에 연차를 사용하면 어드민 노무수령거부 현황에 "O"로 표시됩니다.
2. **노무수령거부 팝업**: 전체 알림 ON + 일반 알림 ON + 노무수령거부 상세 알림 ON + 당일 미동의일 때, 지정 연차일에 연차를 쓰지 않았으면 팝업이 뜨고 동의 시 시간이 기록됩니다 (웹/앱 알림 구분).
3. 연차촉진 작업은 삭제할 수 없습니다 (2025.07.09 기준, 추가 계획 없음).
4. **서명이 필요한 문서는 연차 사용 계획서뿐입니다.** 미사용 연차 통지서와 사용시기 지정 통보서는 서명 없이 문서 확인으로 완료되고, 계획서는 확정 후 서명까지 해야 촉진 절차가 끝납니다. 회사 양식에 통지서 서명란을 추가할 수는 있지만 촉진 진행 상태에는 반영되지 않습니다 (기획 확인 2026-11-05).

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 사용시기 지정 통보 날짜 | 강제 알림 팝업 (확인 전 다른 요소 클릭 불가) |
| 노무수령거부 조건 충족 | 노무수령거부 팝업, 동의 시 시간 기록 |
| 계획서: 날짜·시간 미입력 | "날짜 및 시간을 입력해주시기 바랍니다." |
| 계획서: 같은 날짜 중복 | "동일한 날짜가 존재합니다. 날짜를 확인해주시기 바랍니다." |
| 계획서: 사용기간 밖 날짜 | "연차 사용기간 내의 날짜만 선택할 수 있습니다." |
| 계획서: 휴일·휴무일 | "휴일 및 휴무일은 신청이 불가합니다." |
| 계획서: 합계가 촉진 필요 시간 초과 | "촉진 필요 시간을 초과하였습니다." |
| 계획서: 합계가 촉진 필요 시간 미만 | "남은 시간을 모두 적용 후 확정 가능합니다." |
| 계획서: 사용시간 0 이하 | "사용시간은 0보다 커야 합니다." |
| 계획서: 기간 만료 | "기간이 만료되어 계획서 작성을 할 수 없습니다." |
| 계획서 확정 완료 | "확정을 완료했습니다." |
