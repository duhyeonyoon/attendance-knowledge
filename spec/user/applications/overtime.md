> **메뉴** 근무 신청 › 연장/야간근무(사전)
> **진입** 출퇴근 위젯 [근무신청] › 신청서 종류 선택
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
근무일(휴일이 아닌 날)에 연장근무 또는 야간근무를 하려는 구성원이 **사전에 승인**을 받는 신청서입니다. 근무그룹의 연장근무 또는 야간근무 설정이 '승인시에만'일 때 사용하며, 승인 시간·잔여시간이 출퇴근 위젯의 출퇴근 가능 여부와 안내에 반영됩니다. 연장과 야간은 하나의 신청서로 처리됩니다.

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 상단 | 연장 가능 시간 | 최대 초과근무 제한 설정 시 기준별 잔여시간 칩("[근무일] 3h", "[주간] …", "[월간] …") + 요청중 시간(아이콘 툴팁 "Nh 요청중"), 미설정 시 법적 기준 "잔여 12h"(주간 예상 근무 40시간 초과 시 52시간 − 주간 예상 근무) |
| 요청일 | 캘린더 | 근무계획이 휴일인 날짜·오늘 이전 날짜는 선택 불가(휴무일은 가능), 하루만 선택 |
| 시간 | 시작 시각 / 종료 시각 | 고정출퇴근제면 시작 시각에 계획 퇴근시간 기본 입력 |
| 결과 정보 | 연장/야간 정보 | 입력 시간으로 자동 판단해 "연장/야간 근무를 포함합니다." 등과 연장·야간 시간, 연장 휴게시간 표시 (연장/야간 선택 UI 없음) |
| 하단 | 결재선, [요청] / 임시저장 | [공통 정책](./overview.md) 참고 |

## 3. 기능 상세

### 3.1 신청
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-APL-OT-01 | 요청일 선택 | 근무계획이 휴일이 아닌 날짜 하루 선택 | 휴일은 [휴일근무(사전) 신청](./holiday-work.md) 사용 |
| U-APL-OT-02 | 기존 신청 안내 | 선택일 기준 전일/당일/익일에 신청된 연장/야간 문서가 있으면 "선택한 날짜에 이미 신청한 연장/야간 근무가 있습니다." + "기존 근무 정보와 중복이 아닌 경우에만 근무 신청이 가능합니다." 안내와 기존 신청 목록 | 시간이 겹치면 신청 불가 |
| U-APL-OT-03 | 시작 시각 기본값 | 선택일이 고정출퇴근제면 계획 퇴근시간을 시작 시각에 자동 입력 | 고정출퇴근제만 |
| U-APL-OT-04 | 시간 입력 검증 | 시작/종료 미입력, 역전, 동일 시 밸리데이션 | 휴일근무와 같은 패턴 |
| U-APL-OT-05 | 연장/야간 정보 | 신청 시간이 연장/야간에 해당하면 정보 표시. 연장·야간 어느 쪽도 없으면 오류 | 연장/야간 구분은 시간으로 자동 판단 |
| U-APL-OT-06 | 당일 과거 시각 신청 제한 | 현재 시각보다 이전 시각으로 신청하면 밸리데이션 메시지 | 연장근무 '승인시에만' + 당일 과거 시각 신청 '허용 안함' 설정 시 |
| U-APL-OT-07 | 최대 초과근무 표시/검증 | 잔여시간 + 요청중 시간 표시, 초과 시 밸리데이션 | 최대 초과근무 제한 설정 시 |
| U-APL-OT-08 | 법적 기준 표시 | 법적 기준 잔여시간 "잔여 12h"(주간 예상 근무 40시간 초과 시 52시간 − 주간 예상 근무) 표시. 표시 전용이며 초과해도 차단 안 함 | 최대 초과근무 제한 미설정 시 |
| U-APL-OT-09 | 최소 초과근무 검증 | 신청서 1건 기준 최소 미달 시 경고 + 신청 불가 | 최소 초과근무 제한 설정 시 |

## 4. 정책 · 비즈니스 룰
1. 근무그룹 설정 › 연장근무 = '승인시에만 연장 가능' **또는** 야간근무 = '승인시에만 야간 가능'일 때 신청 대상. 연장 '자유 허용'이면 신청 불필요, '불가'이면 출퇴근 위젯에서 사전 차단.
2. 출퇴근 위젯: 승인 시간 외 근무 → 안내문, 잔여시간 초과 → 차단. 예상 퇴근시간 초과 텍스트는 '승인시에만'이면 빨간색("승인 안 받으면 비근무"), '자유 허용'이면 주황색.
3. 야간근무도 이 신청서로 함께 처리.
4. 최소 초과근무시간은 신청서 1건 단위로 판정.
5. 최대 초과근무 제한 미설정 시 법적 기준 잔여시간은 표시만 되고 밸리데이션은 걸리지 않음 (화면·서버 모두 검증 생략).
6. 요청중이면 출퇴근 위젯에 "요청중" 칩 표시.
7. 마감된 일자는 요청·승인·취소요청·취소승인 모두 불가.
8. 겹침 판정은 같은 구성원의 요청중·승인 연장/야간(사전) 신청서 중 신청일 전일~익일 것과 시간 구간 비교. 휴일근무 등 다른 신청서와는 비교하지 않음.
9. 야간근무 불가 그룹이면 22:00~06:00이 포함된 시간은 신청 불가.
10. 신청 시간은 해당 일자의 근무 가능 시간대(당일 시작 ~ 익일 시작) 안이어야 함.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 요청일 미입력 | "요청일을 입력합니다." |
| 시작 / 종료 미입력 | "시작시각을 입력합니다." / "종료시각을 입력합니다." |
| 종료가 시작보다 앞 | "종료 시각이 시작 시각 전입니다." |
| 시작 = 종료 | "시작시각과 종료시각이 동일합니다." |
| 근무 가능 시간대 밖 | "당일 HH:mm ~ 익일 HH:mm 이내로 신청합니다." |
| 당일 과거 시각 신청 (허용 안함 설정) | "당일의 경우, 현재 시각 기준 과거 시각으로 신청이 불가합니다." |
| 야간근무 불가인데 22~06시 포함 | "야간 근무 불가로 해당 시간(22:00 ~ 06:00)을 제외한 시간으로 신청하시기 바랍니다." |
| 연장/야간이 포함되지 않은 시간 | "연장/야간 근무가 포함되어 있지 않습니다." |
| 기존 연장/야간 신청과 시간 겹침 | "선택한 기간에 이미 신청한 연장/야간 근무가 있습니다. 중복요청은 불가합니다." |
| 잔여 초과근무시간 초과 | "<초과한 기준(근무일/휴무일, 주간, 월간)> 기준 잔여 시간을 초과했습니다." |
| 최소 초과근무시간 미달 | "연장/야간 근무시간이 최소 기준(Nh)보다 적습니다." + 신청 불가 |
| 첨부 / 코멘트 필수인데 미입력 | "첨부파일을 업로드합니다." / "코멘트를 입력합니다." |
| 신청서 사용 중지 | 모달 "연장/야간근무(사전) 신청 불가 안내" / "연장/야간근무(사전) 신청서 사용이 중지되었습니다." |
| 마감된 일자 | 요청/승인/취소 불가 |
