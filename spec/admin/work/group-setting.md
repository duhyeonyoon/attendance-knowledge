> **URL** `/attendance/work/group_setting` (목록), `/attendance/work/group_setting/[근무그룹ID]` (상세)
> **탭(상세)** 근무 설정 · 구성원 설정 · 그룹 스케줄
> **사용자** 어드민(근무 담당자)

## 1. 개요

**근무그룹**은 근무 정책의 단위입니다. 구성원을 그룹에 묶고, 그룹마다 정산기간·근무기록 방식·연장/야간/휴일 근무 허용·출근지·휴일·그룹스케줄 등 근무 룰을 정합니다.

사용자 화면(출퇴근 위젯, 내 근무, 신청서 등)의 동작은 대부분 소속 근무그룹의 설정으로 결정됩니다. 한 번 확정한 그룹의 집계 룰은 바꿀 수 없으므로, 고객사 세팅 단계에서 신중하게 설정해야 합니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 목록(메인) | 필터, 근무그룹 목록, [근무그룹 추가], 복제, 삭제 | 임시저장 그룹은 "미확정" 태그 표시 |
| 상세 헤더 | 탭, [삭제] / [취소] / [저장] 버튼 | 최초 생성 직후에는 저장 시 다음 탭으로 이동 |
| 근무 설정 탭 | "기본설정" · "근무시간 관리" · "근무 신청서 관리" · "휴일 관리" · "출근지 관리" · "기타근무 항목 설정" · "기타설정" + 우측 "근무 설정 리스트"(체크리스트) | 그룹 룰 전체 |
| 구성원 설정 탭 | 소속 구성원 리스트, 구성원 변경 모달, 변경일 지정 화면 | 그룹 소속 관리 |
| 그룹스케줄 탭 | 템플릿 설정, 그룹스케줄 캘린더 | 그룹 단위 근무 계획 적용 |

## 4. 정책 · 비즈니스 룰

1. **임시저장 → 확정**: 신규 추가·복제 모두 임시저장으로 시작하고, 근무설정 탭을 한 번 저장하면 확정됩니다.
2. **확정 후 변경 범위**

   | 확정 후에도 변경 가능 | 확정 후 변경 불가(저장해도 원래 값 유지) |
   |---|---|
   | 그룹명·메모, 재택 허용, GPS/IP·모바일/PC 출퇴근 제한, 근무시간 표시, 대체근무 허용, 자동집계(개발 전), 최대 근무시간 제한, 최소 연장시간, 휴일·출근지·기타근무 사용 설정 | 연장/야간/휴일 허용, 정산(기간·기준), 근무유형, 근무기록 방식 등 집계 룰 |

3. **잘못 확정된 룰 정정 절차**: 그룹 복제 → 잘못된 설정만 수정 → 새 그룹에 구성원 소속 변경. 과거 일자에 반영하려면 재집계를 별도 요청합니다.
4. **복제 범위**: 근무설정 탭 전체, 휴일·출근지(근무그룹 유형은 새 항목으로 복제), 기타근무 사용 설정, 신청서 설정. **구성원·근무 템플릿·그룹스케줄은 복제하지 않습니다.**
5. **삭제 조건**: 임시저장 그룹은 조건 없이 삭제됩니다. 확정 그룹은 **구성원 설정 이력**이 한 건이라도 있으면 삭제할 수 없습니다 — 현재 소속 인원이 0명이어도 과거 배정 이력이 있으면 차단됩니다.
6. **연장시간 제한 입력 범위** ("정산기간의 근무시간 합계가 기본 근무시간을 넘어가면 연장근무로 기록" 방식일 때)

   | 정산기간 | 입력 가능한 제한 |
   |---|---|
   | 1주 | 주 단위 + 월 단위(휴일/전체) |
   | 2주 ~ 1개월 | 월 단위(휴일/전체) |
   | 2개월 · 3개월 | 자동 "제한 없음", 시간 제한 적용 비활성 |

7. **클라이언트 상속**: 휴일·출근지·기타근무 항목은 [근무 설정](./base-setting.md)에서 정의된 항목을 상속하며 그룹은 사용 여부만 정합니다. 근무 설정에서의 변경은 모든 그룹에 전파됩니다.
8. **마감 보호**: 마지막 근무 마감일 이전으로 구성원 변경일을 지정할 수 없고, 마감된 일자의 그룹스케줄은 추가·삭제·확정할 수 없습니다.
9. **야간 시간대**는 법정 기준 22:00~06:00 고정입니다.
10. **사용자 화면 영향**

    | 그룹 설정 | 사용자 화면 |
    |---|---|
    | 근무기록 관리 = 근무 계획 | 출퇴근 위젯에 출/퇴근 버튼 없이 "근무 중" 텍스트만 |
    | 근무기록 관리 = 외부 시스템 | 출퇴근을 외부 시스템 기록으로 처리 |
    | 휴일근무 불가 + 휴일 | 출근 시 차단 안내(퇴근은 안내 후 가능) |
    | 야간근무 불가 + 22~06시 | 출근 시 차단 안내(퇴근은 안내 후 가능) |
    | 연장근무 "승인 시에만 연장 가능" | 예상 퇴근시간 초과 시 빨간색 텍스트 ("연장 가능"은 주황색) |
    | GPS 제한 OFF 또는 출근지 없음 | 근무지 외 출퇴근 허용 |
    | 근무시간 미표시 | 근무시간 화면 미표시 |
    | 휴일 / 출근지 / 그룹스케줄 변경 | 사용자 캘린더·근무스케줄 휴일 표시, 출퇴근 위치 검증 대상, 내 근무 캘린더 계획에 반영 |
