> **메뉴** 근무관리 › 권한 › 서브어드민 권한
> **URL** `/attendance/authority/custom`
> **사용자** 어드민(근무 총괄)

## 1. 개요
근무 총괄이 특정 구성원(담당자)에게 범위와 종류를 지정해 어드민 권한을 위임하는 화면입니다. 구조는 **권한그룹(단위) → 담당자(사람) → 권한 범위(대상 구성원)** 이며, 권한그룹마다 근무관리 업무권한(5개 구분, 메뉴 단위 상세 분류) 중 허용할 권한을 고릅니다. 직책 기반 자동 부여는 [직책자 권한](./manager.md), 전체 모델은 [모듈 설정·권한 공통 정책](../module-setting/overview.md)을 봅니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 메인 | 권한그룹 목록 | 컬럼: No / 그룹명 / 회사 / 담당자 |
| 메인 | 필터 | 그룹명 / 담당자 |
| 메인 | [권한그룹 추가] | 그룹명 + 그룹 설명 입력 dialog |
| 상세 | ← 버튼, [권한그룹 삭제], 네비게이션 | 우측에 카드 이동 네비게이션 |
| 상세 | 카드 1 기본 설정 | 권한 그룹명 / 상세 설명 |
| 상세 | 카드 2 담당자 설정 | 담당자 현황 목록, [담당자 추가] |
| 상세 | 카드 3 권한 설정 | 근무관리 업무권한 표(구분 / 상세 분류 / 권한) |
| 담당자 설정 페이지 | 담당자·권한 기간, 담당 범위(회사 / 조직), 범위내 구성원 탭 | 탭: 담당 구성원 / 추가 구성원 / 제외 구성원 |

## 4. 정책 · 비즈니스 룰
1. 권한그룹은 담당자가 없을 때만 삭제할 수 있습니다. 기획상 기준은 "활성 담당자(권한 기간이 오늘과 겹치는 담당자)"이나, 현재는 권한 기간이 끝난 담당자가 남아 있어도 삭제가 막힙니다(기획 ≠ 구현, 확인 2026-11-05). 기간이 끝난 담당자는 수정할 수 없고 삭제 후 다시 등록해야 합니다.
2. 활성 상태 구성원만 담당자로 추가할 수 있습니다.
3. 권한 종료일이 지난 담당자는 목록에서 흐리게(투명도 0.3) 표시됩니다.
4. 범위내 구성원은 3가지로 분류됩니다.

| 탭 | 대상 | 가능한 동작 |
|---|---|---|
| 담당 구성원 | 담당 범위로 들어온 구성원 + 추가 구성원 | 제외 (추가 구성원이 아닌 경우) |
| 추가 구성원 | 명시적으로 추가한 구성원 | 추가 / 삭제 |
| 제외 구성원 | 명시적으로 제외한 구성원 | 복구 |

5. 제외 구성원 복구 시 담당 범위에 포함되면 담당 구성원으로 돌아가고, 포함되지 않으면 단순 삭제됩니다.
6. 담당 범위 내 비활성 구성원도 구성원 추가 dialog에서 조회됩니다.

### 4.1 업무권한 구분 · 상세 분류
상세 분류 하나가 어드민 메뉴 하나(또는 묶음)를 엽니다.

| 구분 | 상세 분류 | 열리는 메뉴 |
|---|---|---|
| 근무 설정 관리 | 근무 설정 / 근무그룹 설정 / 근무 그룹 이력 관리 | 같은 이름의 근무 메뉴 |
| 근무 실무 관리 | 근무 데이터 관리 / 근무 마감 / 근무 신청 내역 관리 / 개인 근무 스케줄 관리 / 근무 대시보드 | 같은 이름의 근무 메뉴 (근무 대시보드는 운영 환경 권한 설정 표에 노출, 확인 2026-11-05) |
| 휴가 설정 관리 | 휴가 설정 / 휴가그룹 설정 / 휴가 그룹 이력 관리 | 같은 이름의 휴가 메뉴 |
| 휴가 실무 관리 | "연차 관리, 연차 외 휴가 관리" / 연차촉진 | 연차 관리 + 연차 외 휴가 관리(한 권한으로 함께 열림) / 연차 촉진 |
| 과거 데이터 관리 | 과거 근무 데이터 관리 / 과거 휴가 데이터 관리 | 같은 이름의 과거 데이터 메뉴 |

7. 연차 관리와 연차 외 휴가 관리는 메뉴는 나뉘었지만 서브어드민 권한은 아직 하나("연차 관리, 연차 외 휴가 관리")로 묶여 있습니다. 메뉴별로 따로 부여하는 기능은 준비 중입니다. 메뉴 분리를 먼저 하고 권한 분리는 후속 작업으로 진행하기로 결정되어 있습니다(기획 확인 2026-11-05).

### 4.2 담당 범위 회사·조직 선택
- 단일회사·다중회사 모두 회사별로 조직을 골라 담당 범위를 지정할 수 있습니다. (예전에는 다중회사 고객사는 회사 단위 전체 조직만 선택할 수 있었으나 2025-12-24에 해제되었습니다.)
- 담당 범위의 근무그룹 선택 옵션은 화면에서 숨겨져 있습니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 권한그룹 목록 없음 | "권한그룹을 생성합니다." |
| 담당자 없음 | "담당자를 추가합니다." |
| 변경 사항 있는 상태로 이탈 | "알림" 컨펌 |
| 담당자 삭제 | "삭제" 컨펌 |
| 추가 구성원 삭제 | "구성원 삭제" 컨펌 |

| 담당 범위·구성원 미지정 후 저장 | "담당 범위 지정 또는 구성원을 직접 추가합니다." |
| 권한 시작일 삭제 후 저장 | "권한 시작일을 입력합니다." |
| 종료일이 시작일보다 이름 | "종료일은 시작일 이후의 날짜로 입력합니다." |
| 그룹명 / 그룹 설명 미입력 | "그룹명이 없습니다." / "그룹 설명이 없습니다." |
| 담당자가 있는 권한그룹 삭제 시도 | 버튼 비활성 + "담당자를 설정한 권한 그룹은 삭제할 수 없습니다." |

## 7. 확인 필요
- 담당 범위의 근무그룹 선택 옵션을 다시 노출할지 (숨김 이유가 특정 고객사 사정인지, 기획상 폐기인지 미확정)
- 연차 관리 / 연차 외 휴가 관리 권한을 분리해 부여하는 후속 작업의 일정
- 권한 기간이 끝난 담당자만 남은 권한그룹의 삭제 차단을 기획대로(활성 담당자 기준) 고칠 시점
