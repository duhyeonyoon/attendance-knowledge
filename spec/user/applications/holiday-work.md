> **메뉴** 근무 신청 › 휴일근무(사전)
> **진입** 출퇴근 위젯 [근무신청] › 신청서 종류 선택
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
근무계획상 휴일인 날에 근무하려는 구성원이 **사전에 승인**을 받기 위한 신청서입니다. 근무그룹의 휴일근무 설정이 '승인시에만 근무 가능'일 때 사용하며, 승인 여부가 휴일 출퇴근 시 출퇴근 위젯의 사전 검증에 그대로 반영됩니다.

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 상단 | 잔여시간 · 요청중 시간 | 최대 초과근무시간 제한이 설정된 경우에만 표시 |
| 요청일 | 캘린더 | 근무일유형이 "휴일"인 날짜만 선택 가능(휴무일·오늘 이전 날짜 불가), 하루만 선택 |
| 시간 | 시작 시각 / 종료 시각 | 당일·익일 구분 가능 |
| 결과 정보 | "변경 결과": 출퇴근, 휴게시간, 상세 시간, 근무시간 | 입력 시간 기준 자동 표시. 회사 휴게 기준으로 휴게시간 자동 부여("자동 차감"). 연장/야간 해당 시 "연장/야간 근무를 포함합니다." 등 추가 정보 |
| 하단 | 첨부, 결재선, [요청] / 임시저장 | [공통 정책](./overview.md) 참고 |

## 3. 기능 상세

### 3.1 신청
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-APL-HOL-01 | 요청일 선택 | 캘린더에서 근무일유형이 "휴일"인 날짜 하루를 선택 | 휴무일·근무일, 오늘 이전 날짜는 선택 불가 |
| U-APL-HOL-02 | 기존 신청 안내 | 선택일에 이미 신청된 휴일근무가 있으면 "선택한 날짜에 이미 신청한 휴일 근무가 있습니다." + "기존 근무 정보와 중복이 아닌 경우에만 근무 신청이 가능합니다." 표시 | 시간이 겹치면 신청 불가 |
| U-APL-HOL-03 | 시간 입력 | 시작/종료 시각 입력. 익일로 지정하면 다음 날 시각으로 계산되어 자정 넘는 근무 신청 가능 | |
| U-APL-HOL-04 | 결과 표시 | 입력 시간 → 추정 근무시간, 휴게시간·상세 시간 자동 표시 | |
| U-APL-HOL-05 | 연장/야간 정보 | 신청 시간이 연장/야간(22~06시)에 걸치면 추가 정보 표시 | |
| U-APL-HOL-06 | 최대 초과근무 잔여시간 | 상단에 잔여시간 + 요청중 시간 표시, 초과 시 밸리데이션 | 최대 초과근무시간 제한 설정 시 |
| U-APL-HOL-07 | 최소 초과근무 검증 | 신청서 1건 기준 최소시간 미달 시 경고 + 신청 불가 | 최소 초과근무시간 제한 설정 시 |

## 4. 정책 · 비즈니스 룰
1. 근무그룹 설정 › 휴일근무 = **'승인시에만 근무 가능'** 일 때만 신청 대상. '휴일근무 불가'이면 신청 불가 및 출퇴근 위젯에서 휴일 출근 사전 차단.
2. 승인이 없는 상태로 휴일에 출/퇴근하면 출퇴근 위젯에서 안내문 확인이 필요하고, 승인 시 정상 처리.
3. 요청중이면 출퇴근 위젯에 "요청중" 칩 표시.
4. 최소 초과근무시간은 신청서 1건 단위로 판정 (합산 아님).
5. 시간 검증은 화면 1차 검증 후 서버가 최종 판정.
6. 마감된 일자는 요청·승인·취소요청·취소승인 모두 불가.
7. "휴일" 판정은 일자의 근무일유형이 휴일인지로 함 (미래·당일은 근무계획 기준). 휴무일 근무는 연장/야간(사전) 신청서 대상.
8. 겹침 판정은 같은 구성원의 요청중·승인 휴일근무(사전) 신청서 중 신청일 전일~익일 것과 시간 구간 비교.
9. 과거 날짜는 신청 불가 (근무내역 변경 신청서 사용 안내). 당일 과거 시각은 '당일 과거 시각 신청' 정책이 허용 안함이면 불가.
10. 야간근무 불가 그룹이면 22:00~06:00 포함 시간 신청 불가. 신청 시간은 근무 가능 시간대 안이어야 함.

- **휴게시간 자동 부여 (기획 확인 2026-11-05)**: 해당 일자 근무 템플릿의 휴게 설정을 따릅니다. 자동 휴게(법정 4시간당 30분, 또는 N시간마다 M분)는 신청 시작 시각부터 구간을 계산하고, 고정 휴게는 신청 시간과 겹치는 부분만 반영합니다. 휴일은 소정 8시간까지 기본 휴게, 그 이후는 연장으로 보아 연장 휴게 설정을 적용합니다 (휴무일 근무는 전체가 연장이라 연장 휴게). 화면 안내는 "회사에서 지정한 휴게 기준에 따라 휴게시간이 자동으로 부여됩니다."

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 요청일 미선택/무효 | "요청일을 입력합니다." |
| 시작 시각 미입력/형식 오류 | "시작 시각을 입력합니다." |
| 종료 시각 미입력/형식 오류 | "종료 시각을 입력합니다." |
| 종료 시각이 시작 시각보다 앞 | "종료 시각이 시작 시각 전입니다." |
| 시작 = 종료 | "종료 시각이 시작 시각과 같습니다." |
| 근무 가능 시간대 밖 | "당일 HH:mm ~ 익일 HH:mm 이내로 신청합니다." |
| 당일 과거 시각 (허용 안함 정책) | "당일의 경우, 현재 시각 기준 과거 시각으로 신청이 불가합니다." |
| 야간근무 불가인데 22~06시 포함 | "야간 근무 불가로 해당 시간(22:00 ~ 06:00)을 제외한 시간으로 신청하시기 바랍니다." |
| 기존 휴일근무와 시간 겹침 | "선택한 기간에 이미 신청한 휴일 근무가 있습니다. 중복요청은 불가합니다." |
| 잔여 초과근무시간 초과 | "<초과한 기준(휴일, 주간, 월간휴일, 월간)> 기준 잔여 시간을 초과했습니다." |
| 최소 초과근무시간 미달 | "휴일 근무시간이 최소 기준(Nh)보다 적습니다." + 신청 불가 |
| 첨부 / 코멘트 필수인데 미입력 | "첨부파일을 업로드합니다." / "코멘트를 입력합니다." |
| 신청서 사용 중지 | 모달 "휴일 근무(사전) 신청 불가 안내" / "휴일 근무(사전) 신청서 사용이 중지되었습니다." |
| 마감된 일자 | "선택한 일자의 근무가 마감되어 사전 휴일 근무를 신청할 수 없습니다." (요청/승인/취소 불가) |
