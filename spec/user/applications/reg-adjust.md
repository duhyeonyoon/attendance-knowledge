> **메뉴** 근무 신청 › 근무내역 변경 (당일 / 과거)
> **진입** 출퇴근 위젯 "근무 내역 변경" 버튼 / 내 근무 캘린더 과거 날짜 / 출퇴근 위젯 [근무신청]
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
이미 기록된 출퇴근·자리비움 내역을 사후에 고치기 위해 승인을 받는 신청서입니다. 화면·문서 이름은 "통합 근무내역 변경"이며, 마감되지 않은 일자만 대상입니다. (별도의 "출퇴근 내역 변경" 신청서와 구분 — **(2026-11-05)** 차이는 4. 정책 9~11 참고) 출근 요청이 취소/반려되어 퇴근 기록만 남은 경우처럼 출퇴근 위젯이 변경을 요구하는 당일 케이스와, 과거 날짜를 고치는 일반 케이스가 있습니다.

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 출퇴근 시간 | 출근 / 퇴근 시각 (복수 회차) | 기존 입력값이 있으면 채워진 상태로 열림 |
| 자리비움 | 시작 / 종료 시각 | |
| 정보 | 출근 인정시간 안내, 초과근무 잔여시간, 연장 휴게시간 정보 | 조건별 표시 |
| 하단 | 결재선, [요청] | [공통 정책](./overview.md) 참고 |

## 3. 기능 상세

### 3.1 진입
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-APL-REG-01 | 당일 근무내역 변경 | 출퇴근 위젯에 "근무 내역 변경이 필요합니다" 문구와 "근무 내역 변경" 버튼 표시 → 신청서 진입 | 출근 요청이 취소/반려되어 출근 기록 없이 퇴근만 있는 경우 |
| U-APL-REG-02 | 당일 요청 후 상태 | 요청 시 "요청중" + 버튼 비활성, 승인 시 "퇴근" 상태 + 출근/퇴근 시간 노출 + 재신청 가능 | |
| U-APL-REG-03 | 일반 근무내역 변경 | 내 근무 캘린더에서 과거 날짜 클릭, 또는 출퇴근 위젯 [근무신청] → 근무내역 변경 | |
| U-APL-REG-04 | 근무계획 변경으로 전환 | 과거 근무내역 변경서에서 유형을 근무계획 변경으로 변경 | [근무계획 변경 신청](./plan-change.md) |

### 3.2 입력·표시
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-APL-REG-05 | 기존 값 채움 | 이미 입력된 출근/퇴근 정보가 있으면 입력된 상태로 오픈 | |

| U-APL-REG-08 | 익일 포함 경고 | 근무 귀속일 하루 범위를 벗어난 시각으로 요청 시 경고 모달 | 5. 메시지 참고 |
| U-APL-REG-09 | 최대 초과근무 잔여시간 | 변경 시간에 연장/야간이 포함되면 잔여시간 문구 표시, 초과 시 밸리데이션 | 최대 초과근무시간 제한 설정 시 |
| U-APL-REG-10 | 최소 초과근무 경고 | 휴일: 기본근무시간이 최소 미만 → 인정근무 제외 + 경고. 근무일/휴무일: 연장근무시간이 최소 미만 → 인정근무 제외 + 경고 | 근무그룹 최소 연장시간 설정 시 |
| U-APL-REG-11 | 연장근무 정보 | 연장 휴게시간이 포함되면 정보 표시. 고정 유형 연장 휴게시간은 시간 정보까지 확인 가능 | |
| U-APL-REG-12 | 신청 취소 | 결재 전 신청 회수("요청 취소") | 승인한 결재자가 없을 때만. 별도 취소 신청서 없음 — **결재 완료 후에는 사용자가 취소할 수 없음** |

입력 항목

| 항목 | 필수 | 형식/기본값 | 설명 |
|---|---|---|---|
| 요청일 | Y | 날짜 1개 | 오늘 이전만 |
| 출근 시각 | 출퇴근 행이 있으면 Y | 시:분, 당일/익일 / 기존 기록 | 행 추가로 복수 회차 가능 (개수 제한 없음) |
| 퇴근 시각 | 출퇴근 행이 있으면 Y | 시:분, 당일/익일 / 기존 기록 | 출근 이후여야 함 |
| 자리비움 시작·종료 | 자리비움 행이 있으면 둘 다 Y | 시:분 | 출퇴근 시간 이내 |
| 코멘트 | 신청서 설정 | 텍스트 | |
| 첨부 | 신청서 설정 | 파일 | |
| 결재선 | Y | | |

> 출퇴근·자리비움 중 최소 1건은 입력해야 하며, 행마다 시작(출근)·종료(퇴근)가 모두 있어야 합니다. 한쪽이 "없음"이면 요청할 수 없습니다.

## 4. 정책 · 비즈니스 룰
1. 마감되지 않은 일자만. 근무그룹의 신청서 설정에서 사용 불가면 신청 불가.
2. 어드민이 출퇴근 내역을 직접 수정한 일자는 변경 신청 불가.
3. 근무시간 표시 안함 + 출근인정시각 이전 출근 시 첫 출근시간을 출근인정시각으로 자동 보정.
4. 귀속일 범위를 넘는 시각은 선택한 날짜의 근무로 기록됨.
5. 최소 초과근무 미달분은 인정근무에서 제외(신청은 경고).
6. 간주근로자가 휴가를 사용한 날의 근무시간 계산:
   - 근무시간 = 소정근로시간 − min(소정근로시간, 기타근무시간)
   - 인정 근무시간 = 근무시간 + 기타근무시간 + 휴가사용시간
   - 최대 소정근로시간을 초과한 기타근무는 가산
7. 마감된 일자는 요청/승인 불가.
8. 같은 날 요청중인 출근·퇴근 요청, 통합 근무내역 변경, 출퇴근 내역 변경이 있으면 신청 불가.
9. **(2026-11-05)** 출퇴근 내역 변경과의 차이 — 통합 근무내역 변경은 승인 시 정정한 시간의 연장·야간·휴일 근무를 승인된 것으로 보지만, [출퇴근 내역 변경](./inout-record-change.md)은 승인으로 간주하지 않습니다 (근무시간 포함여부가 '승인시간만 포함'인 그룹에서는 별도 연장/야간·휴일근무 신청 승인분만 인정).
10. **(2026-11-05)** 근무그룹에 신청서 설정이 없으면 통합 근무내역 변경은 사용, 출퇴근 내역 변경은 미사용이 기본입니다. 두 신청서를 모두 사용하는 그룹에서는 내 근무 캘린더 과거 날짜·출퇴근 위젯 "근무 내역 변경" 버튼에서 출퇴근 내역 변경이 먼저 열리고, 신청서 상단 유형에서 바꿀 수 있습니다.
11. **(2026-11-05)** 같은 날 통합 근무내역 변경과 출퇴근 내역 변경이 모두 승인되면 나중에 승인된 건이 최종입니다.
12. **(2026-11-05)** 근무그룹의 휴일근무 허용이 '근무 불가'이면 휴일 일자는 신청할 수 없습니다 (요청 시 거절).

- **결재 완료 후 되돌리기 (기획 확인 2026-11-05)**: 기존 근무기록을 고치는 신청서라 취소 신청서가 없습니다. 잘못된 시간으로 승인됐다면 올바른 시간으로 다시 변경 신청하며, 나중에 승인된 건이 최종입니다. 어드민에도 승인 취소 기능은 없습니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 요청일 미입력 | "요청일을 입력합니다." |
| 미래 날짜 | "요청일은 현재 날짜 이전으로만 선택할 수 있습니다." |
| 입력 데이터 없음 | "통합 근무내역 변경 데이터를 입력합니다." |
| 출퇴근/자리비움 쌍 미완성 등 검증 실패 | "출퇴근, 자리비움 데이터 검증을 통과하지 못했습니다." |
| 퇴근이 출근보다 앞 | "퇴근시간이 출근시간 전입니다." |
| 출근 = 퇴근 | "출근시간과 퇴근시간이 동일합니다." |
| 두 번째 출근이 첫 번째 퇴근보다 앞 | "출근시간이 이전 퇴근시간 전입니다." |
| 자리비움 시작/종료 역전 | "종료시간이 시작시간 전입니다." |
| 자리비움이 출퇴근 시간 밖 | "자리비움 시간은 출퇴근 시간 이내로 작성해야합니다." |
| 자리비움 시작 = 종료 | "자리비움 시작시간과 종료시간이 동일합니다." |
| 출근시간이 출근인정시간 이전 | "출근인정 시각(HH:mm)부터 근무 시간으로 인정합니다." |
| 귀속일 범위 초과 (요청 시) | 경고 모달: "입력하신 출퇴근 시각은 익일 근무를 포함하고 있습니다." / "해당 시간은 선택한 날짜의 근무로 기록됩니다. 이대로 변경하시겠습니까?" |
| 잔여 초과근무시간 초과 | "<초과한 기준> 기준 잔여 시간을 초과했습니다." (안내: "잔여시간은 통합 근무내역 변경 신청 전 근무시간을 기준으로 산정된 초과근무 가능 시간입니다.") |
| 최대 근무시간 초과 | "최대 근무시간을 Nh 초과했습니다." |
| 최소 초과근무시간 미달 | "최소 연장근무시간(Nh)보다 작아 근무시간으로 인정되지 않습니다." + "(미인정)" 표시 |
| 같은 날 요청중 신청 존재 | "선택한 날짜에 이미 신청한 출근 요청이 있습니다." / "… 퇴근 요청이 있습니다." / "… 통합 근무내역 변경 요청이 있습니다." / "… 출퇴근 내역 변경 요청이 있습니다." ([요청] 비활성) |
| 근무그룹에서 사용 불가 | "해당 날짜에 소속된 근무그룹에서는 통합 근무내역 변경 신청서를 사용할 수 없습니다." |
| 어드민 직접 수정 일자 | "해당 일자의 근무내역은 어드민이 수정 및 확정하였습니다." ([요청] 비활성) |
| 당일 변경 필요 상태 | 출퇴근 위젯 "근무 내역 변경이 필요합니다" |
| 마감된 일자 | "선택한 일자의 근무가 마감되어 근무내역을 변경할 수 없습니다." (요청/승인 불가) |
| 휴일근무 '근무 불가' 그룹의 휴일 일자 요청 | "휴일 근무내역 변경을 할 수 없도록 설정되어 있습니다. 담당자에게 문의바랍니다." |
