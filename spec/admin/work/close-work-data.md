> **URL** `/attendance/work/close_work_data`  
> **탭** 개인별 마감 상태 · 마감 내역  
> **사용자** 어드민(근무 담당자)

## 1. 개요

특정 기간의 근무 데이터를 **확정**하는 화면입니다. 마감된 일자는 출퇴근 요청 · 각종 신청 · 승인 · 취소가 모두 차단되어, 급여/정산 계산의 신뢰 가능한 기준점이 됩니다. 어드민은 근무그룹과 기간을 지정해 일괄 마감하고, 구성원·일자별 마감 상태와 과거 마감 이력을 조회합니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|

| 일괄 마감 모달 | 회사 · 근무 그룹 · 마감 기간 · 메모 · 적용일 · 취소/확인 버튼 | 근무그룹 × 기간 단위로 마감 실행 |
| 마감 내역 탭 | 필터 · 목록(체크박스) · 일괄 해제 버튼 · 엑셀 다운로드 | 마감 실행 1건 = 1행. 필터: 조회 기간 · 구성원 · 회사 · 조직 · 근무 그룹 · 마감 구분. 컬럼: 마감 기간 / 마감 구분 / 근무 그룹("그룹명 등 N개") / 적용 구성원("N명") / 담당자 / 처리일 / 메모 |

선택한 탭은 URL에 유지됩니다.

## 4. 정책 · 비즈니스 룰

1. **마감 상태 단위는 구성원 × 일자**, **마감 실행 단위는 근무그룹 × 기간**입니다.
2. 마감 기간은 최대 **100일**(시작·종료일 포함)이며, 시작일과 종료일 모두 **오늘 이전**이어야 합니다 (당일 포함 마감 불가). 종료일이 시작일보다 앞설 수 없습니다.
3. 마감 대상은 기간 · 그룹 내 **아직 마감되지 않은 일자**입니다. 집계 데이터가 없는 날은 건너뜁니다. 대상이 0건이면 마감되지 않습니다.
4. **출퇴근 누락 · 미완성 근무내역 · 결재중 신청서가 있어도 마감은 차단되지 않습니다** (최초 구현부터 동일).
5. 마감은 해제할 수 있으며(마감 내역 탭 "일괄 해제"), 해제는 마감 이력 단위로 이루어지고 이력이 별도로 남습니다. 해제한 이력은 다시 해제 대상으로 고를 수 없으며, 다시 마감하려면 일괄 마감을 새로 실행합니다.
5-1. 마감 메모는 선택 입력입니다.
5-2. 일괄 마감은 진행 중(결재중) 신청서를 자동 반려 · 보류하지 않습니다. 신청서는 그대로 남습니다.
5-3. 구성원별 · 일자별로 개별 마감 · 해제하는 기능은 없습니다. 마감 · 해제 모두 근무그룹 × 기간(이력) 단위입니다. 특정 구성원만 해제가 필요해도 근무그룹 단위로 해제해야 합니다.
5-4. 마감된 일자의 결재중 신청서는 결재함에 "승인필요"로 남지만 **승인할 수 없고**(승인 시 "기한만료"로 거절) 반려만 가능합니다. 승인이 필요하면 마감 해제 → 승인 → 재마감 순서로 처리합니다 (기획 확인 2026-11-05).
6. 엑셀 다운로드는 사유 입력이 필수입니다(감사 로그).
7. 마감된 일자에는 아래 기능이 차단됩니다 (요청 · 승인 · 승인완료 건 취소요청 · 취소승인 모두 포함).

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 일괄 마감 시 회사 미선택 | "회사를 선택합니다" |
| 일괄 마감 시 근무그룹 미선택 | "근무 그룹을 선택합니다" |

| 시작일이 종료일보다 늦음 | 오류 얼럿 "마감 시작일은 종료일 이전이어야 합니다." |

| 서버 오류 얼럿 공통 | 제목 "요청 실패 에러가 발생했습니다.", 본문 = 위 오류 문구 |
| 확인 창에서 취소 | "정말 취소하시겠습니까?" |
| 밸리데이션 통과 후 적용 | 마감 기간 · 그룹을 보여주는 확인 창 |
| 마감 완료 | "근무를 마감했습니다." 후 목록 자동 갱신 |
| 일괄 해제 완료 | "마감된 근무를 해제했습니다." |
| 해제 대상 없음 | "해제할 마감 이력을 선택합니다." / "해제 대상 마감 이력이 존재하지 않습니다" |
| 엑셀 다운로드 사유 미입력 | 다운로드 진행 불가 |

## 7. 확인 필요

- "개별 마감" · "개별 해제" 기능의 도입 계획 (현재 구분값만 존재, 도입 계획은 확인되지 않음)
- 기획 초안의 "결재중 신청서가 있는 건은 마감에서 제외"가 현재(제외 없이 마감, 이후 승인 차단)로 바뀐 것이 확정 정책인지
- 마감된 결재중 문서를 결재함 목록에서부터 "기한만료"로 구분 표시할지 (개선 논의만 있음)
