**전자문서 양식 (2026-11-05 해소)**:
- 사전 준비: **시스템 › 양식관리**에서 유형 "동의서"로 미사용 연차 통지서 · 연차 사용 계획서 · 사용시기 통보서 3종을 만들어 둠 (#3760 테스트 방법)
- 양식 셀렉트는 **회사를 먼저 고른 뒤** 활성화 (툴팁 "회사를 먼저 선택한 후 연차촉진 양식을 선택합니다."). 선택한 회사의 양식을 한 번에 조회해 세부 유형별로 나눔 (통지서 `NOTICE_OF_UNUSED_PAID_LEAVE` / 계획서 `PAID_LEAVE_USAGE_PLAN` / 통보서 `NOTICE_OF_PAID_LEAVE_PERIOD`)
- ~~양식 없이 작업 생성 시 생성 불가 (추정)~~ → 해당 회사에 그 유형의 양식이 없으면 **셀렉트 옵션이 비어** 선택할 수 없고, [확인] 시 위 필수 메시지로 막힘. 별도 "양식 없음" 안내 문구는 없음. 백엔드도 템플릿 ID 3종을 필수 검증 (`be:validator/encouragementadmin/AdminEncouragementValidator.validateTemplateIds`)

**연차 유형별 생성 결과** (`be:service/encouragementadmin/AdminEncouragementManagementService.java:1190–1265`):
- **연차**: 작업 1건. 현재년도 기준 대상자 중 연차 미지급자 = 비대상, 나머지 = 대상
- **1년미만연차 + 분할 촉진**: 작업 **2건** — 두 번째 작업명에 "(1년미만연차 추가발생의 촉진)"이 붙음. 입사일 기준 1년 근로기간 종료 3개월 전을 기준으로 그 이전·이후 발생 월차를 나눔 (예: 입사 한달 후 부여 9일 + 2일 / 입사 후 바로 부여 10일 + 1일). 근로기준법 제61조 2단계 촉진. 매월 1개씩 부여하는 경우에 적합
- **1년미만연차 + 단일 촉진**: 작업 1건으로 1년 미만 연차 전체를 촉진. 선부여하는 경우에 적합. 화면 안내: "법정 촉진 절차를 충족하지 못하여 촉진 효력이 인정되지 않을 수 있음에 유의합니다."
- 1년미만연차: 지급된 1년미만연차의 기간이 만료되지 않은 인원이 대상

**수정**: "연차촉진 작업 수정"에서는 **작업명과 메모만** 수정 가능 (회사·양식·연차 유형·작업 기준·귀속연도 비활성). 백엔드 수정 API도 작업명·메모만 받음.

## 상세 화면 — 4단계 스텝

1. **대상자 및 현황 관리** (`employee_overview_step`)
   - 컬럼: 상태 / 사번 / 이름 / 회사 / 조직 / 휴가 그룹 / 입사일 / 연차기산일 / 연차정보(현재기준: 사용 시작일·종료일, 발생 일수, 의무 사용 일수, 사용 일수, 미사용 일수, 촉진 일수) / 1차·2차 촉진 시작일·종료일 / 사용 계획서 수립 종료일(1차 촉진일 + 10일) / 통지서·계획서·통보서 확인일 등. 각 날짜 컬럼에 계산식 툴팁
   - [대상자 관리] (대상자 추가/삭제 모달 — 필터: 회사·조직·휴가그룹·이름 또는 사번·"현재 휴가그룹 시작일 필터"). 비대상·대기·촉진 필요 상태가 아닌 구성원은 삭제 불가 (#3760)
   - [촉진기간 엑셀 업로드]: "'대상자 관리'를 통해 추가된 대상자에 한해서 촉진 기간 업로드가 가능합니다." 사번 필수, 1차/2차 시작·종료일(YYYYMMDD), 바꿀 회차만 입력. 실패 사유 예: "해당 사원은 이 촉진 작업의 대상자가 아닙니다.", "이미 1차 촉진 통지서가 발송되어 변경할 수 없습니다.", "이미 발송된 촉진 기간의 종료일은 단축할 수 없습니다. 연장만 가능합니다."
   - 엑셀 다운로드("연차 촉진 대상자 엑셀 다운로드")
2. **미사용연차 통지 및 사용 시기 지정 요청** (`unused_leave_notification_step`)
   - 통지 → "…에게 미사용 연차 통지서와 사용 계획서 작성 요청 알림을 보내시겠습니까?" → "미사용 연차 통지서와 사용 계획서 작성 요청 알림을 발송 완료하였습니다." 사용자에게 연차촉진 문서 발송 (사용자 연차촉진 화면에서 확인)
   - 통지서/계획서 클릭 → 전자문서 열람
3. **사용시기 지정 및 통보** (`usage_period_assignment_step`)
   - [사용시기 지정](엑셀 업로드 가능 — 사번·휴가일(YYYYMMDD)·사용분수(분 단위) 필수) → [사용시기 통보] → "…에게 사용시기 통보서를 전달하시겠습니까?" → "사용시기 통보가 완료되었습니다."
   - 통보 중 연차를 모두 쓴 구성원은 통보에서 제외: 전원이면 "사용시기 통보 불가", 일부면 "사용시기 부분 통보 완료" + "사용시기 통보 제외 구성원" 목록
   - 안내: "지정된 연차 사용일에 맞춰 노무수령거부 알림을 발송할 수 있습니다. 해당 알림은 시스템 > 알림설정에서 활성화할 수 있습니다."
4. **노무수령거부 현황** (`work_refusal_overview_step`)
   - 컬럼: 사번 / 이름 / 회사 / 조직 / 휴가 그룹 / 통보일 / 연차사용 시작·종료일 / 연차계획(연차 유형, 지정 연차일, 연차 사용여부) / 1차·2차 메일 발송일 / 통지팝업 열람일자·동의일자. 엑셀 다운로드

**대상자 상태 13종** (상태 유형 다이얼로그 문구): 비대상 · 대기 · 촉진 필요 · 촉진 미실시 · 미사용 연차 확인 필요 · 사용계획서 작성 필요 · 사용계획 서명 대기 · 사용계획 작성 완료 · 사용시기 지정 필요 · 통보 필요 · 통보 미실시 · 통보 완료 · 2차 비대상. 상태 전이는 1분 주기 배치. **비대상은 종착 상태**(재판정 없음) — `_learnings/2026-07-16-encouragement-non-target-dead-end.md`

**노무수령거부 팝업 노출 조건** (`ad-qa:L1239–1244`):
- 공통: 전체 알림 받기 + 일반 알림 + 노무수령거부 상세 알림 모두 ON + 당일 미동의
- 웹 알림만 ON: 데스크톱 환경만 노출
- 모바일 알림만 ON: 모바일 기기만 노출
- 둘 다 ON: 항시 노출
- 둘 다 OFF: 미노출
