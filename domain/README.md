# domain/ — 도메인 용어 / 비즈니스 룰

이 폴더는 **기능에 종속되지 않는** 횡단 지식입니다. (특정 화면 동작은 `product/` 참고)

## 문서 목록

- `glossary.md` — 도메인 용어집 (사람 / 시간 / 신청서 / 휴가 등)
- `business-rules.md` — 핵심 비즈니스 룰 (근무시간 인정 / 야간 / 휴일 / 마감 등)
- `decision-log.md` — 의사결정 로그 (왜 이렇게 동작하는가, 임시 제약 등) [TBD: 필요 시 생성]

## 작성 원칙

- 한 번 등장한 용어는 `glossary.md`에 등록 (중복 정의 방지)
- 룰은 출처 라인 번호를 함께 적어서 검증 가능하게
- "예정", "임시", "개발필요" 같은 시한적 동작은 `decision-log.md`로 분리해서 관리하면 stale 방지에 유리
