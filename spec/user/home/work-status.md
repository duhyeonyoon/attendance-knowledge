> **메뉴** 통합홈 › 출퇴근 카드 안 '근무 현황' 펼침 영역
> **사용자** 사용자(구성원)

## 1. 개요

통합홈 출퇴근 위젯 하단에서 **관심 있는 조직·구성원의 현재 근무 상태**를 확인하는 영역입니다. 별도 페이지가 아닌 위젯이며, 본인이 출근하면 본인 상태가 "근무중"으로 바뀌고 출퇴근 후 리스트가 자동 새로고침됩니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 근무 현황 리스트 | 구성원별 근무 상태 | 설정한 조직/구성원의 상태 표시. 웹은 스크롤, 모바일은 5개씩 |
| 검색 | 돋보기 | 리스트 내 구성원 이름 검색 |
| 설정 | 조직/사람 검색 | 리스트에 표시할 대상 추가/수정/삭제 |
| 모바일 아코디언 | 근무 현황 | 기본 **접힌** 상태 |

## 3. 기능 상세

### 3.1 근무 현황

| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| U-HOME-STS-01 | 근무 현황 조회 | 설정한 구성원의 근무 상태 리스트 표시 | 상위 조직을 추가하면 하위 조직 인원 상태도 표시 |
| U-HOME-STS-02 | 대상 설정 | 조직/사람 검색으로 리스트 대상 추가·수정·삭제 | 본인 소속 회사 하위 조직/구성원만 검색 가능 |
| U-HOME-STS-03 | 구성원 검색 | 돋보기로 리스트 내 이름 검색 | — |
| U-HOME-STS-04 | 자동 새로고침 | 출근/퇴근 처리 후 리스트 자동 갱신 | 출근 완료 시 본인 상태 "근무중" |

## 4. 정책 · 비즈니스 룰

1. 조회 대상은 **본인 소속 회사 하위**의 조직/구성원으로 한정됩니다.
2. 조직 목록은 **소속 구성원이 있는 조직만** 표시됩니다 (2025.04.17 기준 임시 제약, 회사-조직 관계 고도화 전까지).
3. 자정 이후에도 전날 출근 후 퇴근하지 않은 구성원은 cutoff 시각 전까지 "근무중"으로 표시됩니다 ([출퇴근 위젯](./checkin-widget.md) 4.6 참고).
4. 모바일: 5개씩 표시, 아코디언 기본 접힘.
