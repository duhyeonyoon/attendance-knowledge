# 구성원 근무/휴가 (사용자 U9, U10) — 매니저 관점

## 개요

**직책자/관리자가 자신의 권한 범위 내 구성원의 근무·휴가를 보는 화면.** 본인 화면(내 근무, 내 휴가)과 별개. 매니저는 여기서:
1. 구성원의 근무 일정/현황을 확인
2. 구성원의 휴가 일정/현황을 확인
3. **승인 요청 들어온 문서를 일괄 처리** (요청 모아보기)

| 영역 | QA |
|------|------|
| **U9** | 구성원 근무 + 근무 상세 현황 | `pp-qa:L390–499` (110줄) |
| **U10** | 구성원 휴가 (일정 + 현황) | `pp-qa:L500–549` (50줄) |

## 진입 위치

- 근무관리 GNB 탭 > 구성원 근무
- 근무관리 GNB 탭 > 구성원 휴가
- 통합홈 위젯의 "구성원 휴가" 타이틀 클릭 → 구성원 휴가 페이지로 진입

## § U9-1. 구성원 근무 일정 탭 (L395–446)

**조회 일자에 해당하는 하루(24시간)의 전사 구성원 근무 일정**.

### 필터

- **조회 일자** (일자별 이동)
- **구성원 / 조직** (인사정보 기반)
- **요청중 필터** (요청중 계획 포함 여부)

### 일정 종류 (4가지) + 우선순위

타임라인에 표시되는 4종:
1. **근무 계획**
2. **휴가 계획**
3. **기타근무 계획**
4. **재택근무 계획**

**겹침 시 우선순위**: 휴가 → 기타근무 → 재택근무 → 근무계획 (`KB:product/leave-domain.md` § "근무시간 산정 우선순위"의 휴가>기타>출퇴근 패턴과 일치)

**겹치는 일정 확인**:
- 겹치는 시간대에 **마우스 호버** → 팝오버로 중복 일정 표시
- 단, **휴가/기타근무/재택근무만 표시** (근무계획 + 다른 것 겹침은 별도 표시 X)

### 근무 계획 표시 룰

- **24시간 내 여러 건** 가능 (야간→주간 변경 등)
- **휴일/휴무일은 표시 X**
- 스케줄 우선순위: **개인스케줄 > 그룹스케줄** (`KB:product/appl-other-forms.md` § 4 일관)
- 스케줄 없으면 표시 X

**타임라인 시작/종료 시간 4가지 케이스**:

| 출근시각 | 퇴근시각 | 타임라인 구성 | 하단 표시 |
|------|------|------|------|
| 고정 | 고정 | 시작~종료 (계획 시각) | 시작-종료 시각 |
| 자율 | 고정 | 오전 9시부터 소정근로시간만큼 | 자율-소정근로시간 |
| 고정 | 자율 | 출근시각부터 소정근로시간만큼 | 출근시각-자율 |
| 자율 | 자율 | 9시 출근 / 18시 퇴근 (기본) | 자율-자율 |

**부가 정보**:
- **코어타임**: 타임라인 바탕에 **점선 + 연보라색 영역**
- **휴게시간**: **빗금** 표시
  - 기본 휴게시간만 표시 (연장 휴게시간 X)
  - 고정 휴게시간: 설정한 시간대로
  - **법정 휴게시간**: 첫 휴게 발생 시각부터 소정근로시간 계산값만큼 자동 생성

### 휴가 / 기타근무 / 재택근무 계획 (공통 룰)

| 종류 | 명칭 | 시작/종료 |
|------|------|------|
| **휴가** | "휴가"로 통일 | 신청 시작~종료 시각 |
| **기타근무** | 항목명 표시 | 신청 시작~종료 시각 |
| **재택근무** | "재택근무"로 표시 (근무 계획 대체) | (근무스케줄 없으면 표시 X) |

**공통 동작**:
- 승인 + 요청중 정보 확인 가능
- 요청중인 경우 → **요청중 아이콘** 표시

## § U9-2. 구성원 근무 현황 탭 (L447–473)

**소속 조직 구성원들의 근무 현황을 주 별로** 확인.

### 주 단위 조회

- **한 주의 시작 요일** = 어드민 근무관리 > 근무 설정 > 시간 조회 탭 (`KB:product/admin-work-setting.md` § 1)
- 회사별 설정 우선, 예외 없으면 클라이언트 기본 설정
- **로그인 사용자(직책자) 메인 발령 소속 기준** 표시

### 화면 구성

- **[오늘] 버튼**: 오늘이 포함된 주로 이동
- 캘린더 상단 좌측 화살표 → 주별 이동
- **구성원 이름 영역 클릭** → 해당 구성원의 **근무 상세 현황 페이지** 이동
- 구성원 이름 옆에 **현재 주의 실 근로시간 합계**

### 주 52시간 경고

- 합계가 **46시간 또는 52시간 초과** (또는 초과 예상)인 경우 → **경고 표시**

> 주 52시간 제도 컴플라이언스 시각화

### 페이징 + 필터

- **50명 초과** 시 다음 페이지 (페이징)
- 구성원 옆 필터: 조직 또는 구성원 검색
  - **본 소속, 겸 소속, 본 소속의 상위, 겸 소속의 상위**로도 조회
  - 조직 항목은 본 소속으로 표시
- 상위 조직 필터링 시 하위 조직 인원 포함

### 캘린더 셀 인터랙션

- **셀 클릭** → 상세 근무 내용 바텀시트
- 휴가/재택 등 신청 표시 클릭 → **신청 문서 Drawer**

### 요청 모아보기 (가장 중요한 매니저 기능) ⭐

- 요청이 있으면 **요청 모아보기 버튼에 빨간 dot** + 갯수 표시
- 클릭 시 → **로그인 사용자에게 들어온 승인 요청 목록**

**요청 종류별 동작**:
- 일반 요청: 클릭 → 문서 확인
- **근무지 외 출/퇴근**:
  - 3개월 이내 요청: **위치 확인 버튼** 클릭 → 위치 조회 가능
  - 3개월 이전 요청: 위치 정보 확인 불가
- **일괄 반려** / **일괄 승인** (여러 건 선택)
- **승인/반려 실패 시** → 실패한 문서 + 이유 간략 표시

> 동시 처리 경합 테스트: 같은 계정 두 탭에서 동시 승인 → 한 탭에서 실패

## § U9-3. 근무 상세 현황 (L474–499)

**구성원 근무 → 구성원 이름 클릭 시 진입.**

### 화면 구성

- 해당 구성원의 근무 상세 표시
- **월 또는 주기 변경 가능** (모바일은 바텀드로워)
- **새로 고침** → 클릭 시점 데이터 재로드
- 카드 클릭 / 일별 근무현황 셀렉트 → 필터 가능
- 해당 기간 내 **근무그룹 2개 이상**인 경우 → 셀렉트로 그룹 선택

### 모바일 특수

- 아래로 스크롤 시 **일별 상세현황 테이블 헤더 상단 고정**

### 1년 미만 구성원

- **입사 1년 미만** 구성원: 최근 1년이 아닌 **입사 이후 데이터만** 조회 가능
- 인사 ↔ 근무간 실시간 연동으로 신규 입사자 테스트 가능

### 평균 시간 표시

- 출/퇴근 평균이 익일을 넘어가는 경우 **24시 초과 표시** 가능 (예: 28:30)

### 지각/조퇴 표시

- **전일까지의 지각/조퇴 기록** → 일별 근무현황에 **빨간색 Info 아이콘**
- 호버 시 **몇 분 지각/조퇴** 툴팁
- **출근 인정 시각 이전 출근** → info 아이콘 + 호버 시 출근 인정 시각 툴팁

### 일별 근무현황 테이블 표시 룰

**참고**: 근무변경/출근/퇴근 신청서는 **동시 진행 불가**. 요청중 신청서가 종결 후 재신청 가능.

**타임 컬럼 표시 (휴가/기타근무 관련)**:
- 휴가 / 휴가 요청중 / 휴가 취소중 / 기타근무 / 기타근무 요청중 / 기타근무 취소중 표시
- **같은 날 여러 개 있는 경우** 우선순위: **요청중 > 취소중 > 휴가 > 기타** (1개만 표시)
  - 같은 날 문서 2개 이상 → **+n** 으로 추가 개수 표시 (바텀시트에서 전체 확인)
  - 클릭 시 1개면 drawer, 2개 이상이면 바텀시트 리스트
- **휴가 요청 취소 있으면 → 취소 대상 휴가 보이지 않음** (기타도 동일)

**근무 시간 컬럼**:
- **근무내역 변경 요청중** → "요청중" 표시 + 출근/퇴근/자리비움 컬럼 빈 채로
- 클릭 시 drawer

**출근/퇴근 컬럼**:
- 출근 요청중 / 퇴근 요청중 표시
- 클릭 시 drawer

## § U10-1. 구성원 휴가 일정 (L502–518)

**구성원들의 휴가를 일자별로 확인.**

### 필터 / 컬럼

- 필터: 구성원 이름, 조직
  - 본인 소속 회사 하위만
  - 2025.04.17 임시 제약 (구성원 있는 조직만)
- 컬럼: 구성원, 회사, 조직, 휴가일, 휴가시간, 시작시간, 종료시간
- **본 소속, 겸 소속, 본 소속의 상위, 겸 소속의 상위**로도 조회
- **페이지네이션 + 컬럼별 정렬**

### 요청 모아보기 (구성원 휴가 측)

U9의 요청 모아보기와 동일 패턴:
- 빨간 dot + 갯수
- 클릭 → 휴가 승인 요청 목록
- **일괄 반려/승인** (여러 건 선택)
- 승인/반려 실패 시 실패 문서 + 이유

## § U10-2. 구성원 휴가 현황 (L520–548)

### 권한별 조회 범위

- **직책자 권한 없음** → 본인만
- **직책자 권한 있음** → 권한 내 구성원 모두

**로컬 테스트 예** (L527):
- 직책자 권한에 팀장 직책 모두 + 구성원 근무 현황 권한 → 최성희 로그인 시 손예진 조회 가능

### 조회 룰

- **조회하는 연도에 사용기한이 걸린 연차** 조회

### 휴가유형 필터

- **전체 연차** 필터: 연차 미생성 인원 → "**휴가 유형이 생성 필요**" 표시
- **전체 연차 외**: 해당 휴가가 생성된 인원만 조회

### 사용률 계산

- 연차 사용 시 **사용률 = 사용일 / 부여일** 기준

### 연차 조회 - 귀속연도 표시 룰

**연차 테스트** (L539–542):
- 어드민 > 구성원 정보에서 **연차기산일을 1월 1일이 아닌 다른 날로** 설정 + 연차제도 부여 기준 = **입사일 기준** 변경
- 작년/올해/내년 연차 생성 시 → 구성원 휴가 현황 올해/내년 조회 시 **동일 구성원 연차가 두 행으로** 조회됨
- 귀속연도 기준으로 각각 표시

### 1년 미만 연차 테스트 (L544–548)

- 연차기산일 = **작년 3월 이후 ~ 작년 12월 이전**으로 설정
- 작년, 올해 연차 생성 → 귀속연도가 작년/올해로 다르지만 **올해 조회 시 1년 미만 연차는 한 행**
- 귀속연도는 작년/올해 둘 다 표시
- **개별 기한** 표시 + 돋보기 클릭 시 상세 정보

### 연차 외 휴가 (수동 부여 휴가) 테스트 ⭐신규 (2026-05-15 갱신, ~L559–563)

어드민이 수동 부여한 연차 외 휴가가 본 화면에 어떻게 조회되는지:

- **어드민 > 휴가 지급 및 관리 > 연차 외 보유 현황 탭에서 수동부여 휴가를 부여하는 경우** → 구성원이 보유한 해당 휴가가 조회됨 (`KB:product/leave-domain.md` § C-2 "수동 휴가 지급")
- **수동부여 연차 외 휴가는 사용일수와 상관없이 귀속년도 기준으로 조회** (= 모두 사용해도 그해는 노출)
- **귀속년도 내 동일한 휴가가 여러 개 부여된 경우** → 개별 기한으로 상세정보 확인 가능 (1년 미만 연차 다건 케이스와 유사 패턴)

> 의미: 어드민이 수동 부여한 휴가의 가시성 룰. 일반 연차/주기 반복 휴가와 다르게 **귀속년도 기준 단순 조회** + **다건 부여 시 개별 기한 노출**.

## ⭐ 매니저 워크플로우 흐름

**구성원 근무/휴가 = 매니저의 일괄 처리 진입점**:

```
[사용자 신청서 제출]
   ↓ 결재선 → 매니저(승인자)
[매니저: 통합홈 처리할 문서 위젯에 알림]
            OR
[매니저: 구성원 근무/휴가 → 요청 모아보기]   ← 본 화면
   ↓
[일괄 승인 / 일괄 반려 / 개별 처리]
   ↓
[사용자에게 알림 + 사용자 캘린더 즉시 반영]
```

### 통합홈 위젯과의 짝

- 통합홈의 "구성원 휴가" 위젯 → 클릭 시 이 화면의 **구성원 휴가 페이지** 진입
- 통합홈의 "처리할 문서" 위젯 → 워크플로우 화면 진입
- 구성원 근무/휴가의 요청 모아보기 → 더 매니저 친화적인 일괄 처리 UI

## Cross-domain 효과

| 동작 | 영향 |
|------|------|
| 매니저 일괄 승인 | N개 신청서 동시 처리 + 각 작성자에게 알림 + 작성자 캘린더 갱신 |
| 매니저 일괄 반려 | 동일하게 N개 알림 |
| 구성원 근무지 외 출퇴근 위치 확인 | **3개월 이내만** 가능 (이후는 위치 정보 폐기 추정) |
| 매니저가 신청 처리 동안 다른 탭에서 처리 시도 | 실패 처리 + 실패 사유 표시 |
| 구성원 휴가 현황 조회 | 직책자 권한에 따라 본인만 또는 권한 범위까지 |
| 구성원 이름 클릭 | 근무 상세 페이지 이동 (다른 view) |

1. **매니저 권한 = 직책자 권한 + 권한 그룹 설정** (`KB:product/admin-work-group.md` § "권한")
2. **본인 소속 회사 한정 조회** (다른 회사 구성원 X)
3. **2025.04.17 임시 제약**: 소속 구성원 있는 조직만 리스팅
4. **요청 모아보기 일괄 처리** = 매니저 핵심 기능
5. **근무지 외 위치 확인 3개월 룰** (개인정보 보호)
6. **동시 처리 시 한 쪽 실패** (낙관적 락 또는 유사 메커니즘 추정)
7. **U9 근무 일정 우선순위**: 휴가 > 기타근무 > 재택근무 > 근무계획
8. **U9 근무 현황 우선순위** (같은 날 휴가/기타): **요청중 > 취소중 > 휴가 > 기타**
9. **U9 근무 일정 호버 팝오버**: 휴가/기타근무/재택근무만 (근무계획 + 다른 것 = 별도 표시 X)
10. **주 46시간/52시간 경고** = 주 52시간제 컴플라이언스
11. **1년 미만 입사자 → 입사 이후 데이터만** (1년 이전 없으므로)
12. **출/퇴근 평균 시간 24시 초과 표시** (야간 근무 등)
13. **연차 두 행 조회**: 연차기산일 ≠ 1월 1일 + 입사일 기준 시 귀속연도 분리
14. **1년 미만 연차 한 행 조회**: 귀속연도 다르더라도 통합 표시 + 개별 기한
