> **메뉴** 근무관리 › 근무스케줄
> **URL** `/attendance/schedule` (수정 페이지 `/attendance/schedule/edit`)
> **탭** 내 기준 · 역할 기준
> **사용자** 사용자(조회) · 근무스케줄 수정 권한자(편집)

## 1. 개요

**근무 계획(=근무 스케줄)**을 보고 관리하는 화면입니다. 일반 사용자는 본인 스케줄을 읽기 전용으로 확인하고, **근무스케줄 수정 권한**이 있으면 작성 권한 대상 구성원의 스케줄을 편집·확정할 수 있습니다.
여기서 만든 스케줄은 개인스케줄로 저장되며 그룹스케줄보다 우선 적용됩니다. 근무 계획의 종류는 근무 템플릿입니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 탭: 내 기준 | 년/월 셀렉트, 템플릿 모아보기, 스케줄 그리드 | 본인 스케줄만 (읽기 전용) |
| 탭: 역할 기준 | 년/월, 근무그룹 셀렉트, 템플릿 모아보기, 미확정 스케줄 보기 토글, [수정] | 수정 권한자만 노출 |
| 그리드 헤더 | 날짜 | 주말 = 회색, 공휴일 = 빨간색 |
| 수정 페이지 | 대상자 리스트(좌), 캘린더, 대상자 필터(조직·성명), [반복 스케줄 적용], [비우기], [저장], 보기 방식 | 별도 페이지 |

| U-ATT-SCH-01 | 탭 노출 | 수정 권한 없음 → 내 기준만 / 있음 → 내 기준 + 역할 기준 | — |

| 항목 | 필수 | 형식/기본값 | 설명 |

| 휴일 템플릿 | 휴일 템플릿 적용 시 필수 | 근무 그룹의 휴일 템플릿 중 선택 | 미설정 시 "관리자 페이지에서 휴일 템플릿을 설정해주십시오", 미선택 시 "휴일 템플릿을 선택하십시오" |

## 4. 정책 · 비즈니스 룰

1. **개인스케줄 > 그룹스케줄**: 개인스케줄이 있으면 어드민이 그룹스케줄을 바꿔도 적용되지 않습니다. 이 화면이 개인스케줄을 만드는 진입점입니다.
2. **미확정 → 확정**: 저장한 스케줄은 미확정(확정 대기) 상태이며, 확정해야 구성원의 내 근무 캘린더에 반영됩니다. 확정 대기 스케줄은 수정 화면 달력에는 노출되지 않습니다.
3. 미확정 보기 진입 시:

| 상황 | 동작 |
|---|---|
| 현재 달에 확정할 스케줄 없음 | 모달 표시 후 확정할 스케줄이 있는 **가장 오래된 달**로 자동 이동 |
| 확정할 스케줄 있음 | **확정 필요 사원 우선 정렬** (기존 정렬 무시). 저장 직후에는 추가/삭제 확정 대기 사원이 최상단 |

4. 수정 중 다른 달로 이동했다 돌아와도 수정 내용은 유지됩니다. 저장하지 않고 페이지를 나가면 수정 내용은 사라집니다.
5. 수정 후 원래 데이터로 되돌리면 [저장]이 다시 비활성화됩니다.
6. **근무 마감**된 구성원이 기간에 포함되면 저장할 수 없습니다.
7. 근무 템플릿 목록 순서에는 정해진 기준이 없어 사실상 임의 순서이며, 사용자/어드민이 순서를 바꾸거나 시간순으로 정렬할 수 없습니다 (변경하려면 개발 필요). 구성이 바뀌지 않으면 순서는 유지됩니다.
8. **수정 권한**: 근무스케줄 메뉴는 모든 구성원에게 보이지만, 다른 구성원 스케줄을 보고 고치려면 어드민 › 근무관리 › 권한 › 직책자 권한에서 '근무스케줄(역할 기준)'이 켜진 직책 그룹에 속해야 합니다. 범위는 '본인 조직' 또는 '본인 + 하위조직'입니다. 권한이 없으면 내 기준 탭(본인 스케줄 읽기 전용)만 보입니다. 근무 그룹 설정 화면의 권한과는 별개입니다 (기획 확인 2026-11-05).
   - 직책자는 과거·미래, 근무일·휴일·휴무일 모두 수정할 수 있습니다. 구성원 본인은 근무계획 변경 신청으로만 바꿀 수 있습니다.
   - 선택적 근로제 그룹 구성원의 스케줄은 직책자가 바꿀 수 없습니다.
9. **반복 스케줄 '휴일 이후 반복 적용'** (휴일 근무 = 휴일 템플릿 사용일 때):

   | 선택지 | 동작 |
   |---|---|
   | 기존 근무 일정을 다음날로 미루어 적용 | 휴일에는 휴일 템플릿을 넣고, 그날 하려던 패턴을 다음날로 미룸 |
   | 휴일만큼 건너뛰고 적용 | 휴일에는 휴일 템플릿을 넣고, 그날 해당하던 패턴은 건너뛰고 다음 순서로 진행 |

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 미저장 상태에서 뒤로가기 / 다른 메뉴 이동 / 대상자 근무 그룹 변경 | 경고창 |
| 반복 스케줄 적용 기간에 확정 스케줄 존재 | 확정 스케줄 개수 알림창 |
| 미확정 보기 진입 시 현재 달에 확정할 스케줄 없음 | 모달 + 해당 달로 이동 |
| 기간 내 근무 마감 구성원 포함 | 저장 불가 |
