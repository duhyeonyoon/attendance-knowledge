## 화면 구성

**상단 헤더** (`Header.tsx`):
- 연차 휴가 전체/사용/잔여 (시간 + 일 단위)
- 연차 또는 1년 미만 연차 생성 전이면 해당 정보 숨김

**잔여 휴가** (`ResidualAnnualLeave.tsx`):
- 연차 외 휴가제도별 잔여시간 (시간 + 일 단위)
- **사용기간 이내 토글 ON** → 현재 사용 가능한 휴가만 표시
- 노출 이름 = 어드민 설정의 **사용자용 휴가제도명**

**휴가 일수 계산 공식**:
```
휴가 일 수 = 휴가 분 수 / (일소정근로시간 × 60)
```
- 소수점 둘째자리까지 반올림
- 소수점 마지막 자릿수 0 생략

| 예시 (소정근로시간 8시간) | 시간 → 일 |
|------|------|
| 13시간 30분 | 13.5 / 8 = 1.6875 → **1.69일** |
| 12시간 | 12 / 8 = 1.50 → **1.5일** |
| 16시간 | 16 / 8 = 2.0 → **2일** |

**"일소정근로시간"의 우선순위 ⭐ (2026-05-19 코드 검증)**:

`be:common/util/CenDdWorkTimeUtil#resolveWorkMinutes` + `be:service/leaveuse/UseLeaveService.java:1315–1325` (2026-11-05 dev 기준 라인):

1. **일별 근무계획 `DdWorkPlanVo.workTimeCd`** (= 그 날 적용된 근무 템플릿의 하루 근무시간) ← **최우선**
2. **근무그룹 `WorkGrpVo.cenDdWorkTime`** (= 어드민 > 근무그룹 > 근무설정 탭 > 기본 설정의 "표준근로시간") ← fallback
3. 기본값 480분(8시간) ← 둘 다 null

→ **단축근무(예: 3시간) 운영 레시피**:
- 근무그룹 손대지 말고 → 3시간짜리 **근무 템플릿 신규 생성** → 개인 근무계획에 깔면 끝
- 그러면 그 날부터 자동으로 휴가 1일 = 3시간 = 180분으로 환산됨
- 근무그룹 표준근로시간(cenDdWorkTime) 변경은 그룹 전체에 영향을 주므로 단일 인원 단축근무엔 부적절

**휴가 사용 시간대(자율 vs 고정) 영향**:
- **자율**: 사용자가 시간 단위로 선택 → 위 우선순위 룰로 환산 → 일계획 변경만으로 단축 시간 반영됨
- **고정 (종일=8시간 박혀있음)**: 휴가제도 자체에 시간이 고정되어 있어 일계획과 무관하게 8시간으로 깎임 → **단축근무 적용하려면 별도 휴가그룹 + 자율 또는 종일=3시간 고정 휴가제도 신설 필요**

## 휴가 신청 흐름

**진입**: 잔여 휴가 칸에서 휴가 유형 선택 → 자동으로 신청 drawer 오픈

**컴포넌트**: `pp:src/components/workflow/shared/template_drawer/contents/Leave.tsx`

**날짜 / 시간 입력**:
- 기간 선택 후 휴일/종일 휴가 신청한 날 → **회색처리 (disabled)**
- 날짜별 종일 선택 가능, 체크박스 해제 시 시간 선택
- **사용 시간 옵션** = 종일 > 차감시간 역순 > 시작시각 > 종료시각 > 항목명 순서
- 기간 신청 중 disabled 일자 있어도 신청 가능
- 연차 외 휴가는 휴일/휴무일 포함 여부 설정에 따라 휴일/휴무일 사용 가능

**요청 후**:
- 예정 휴가 목록 추가 + 요청중 chip
- > 버튼 클릭 → 신청서 확인 + 취소 가능
- 취소 시 목록에서 사라짐 (워크플로우에서는 취소 문서로 확인)
- 승인 완료 시 잔여 차감 / 취소 승인 시 다시 추가

**관리자 등록 휴가**: 신청서가 아닌 별도 확인 모달 (모바일은 바텀드로워)
- 어드민 > 휴가 지급 및 관리 > 연차 사용 현황탭 > 연차 수동등록으로 등록된 휴가

**기간별 사용 종료일이 다른 연차 외 휴가** (예: 보상휴가):
- "건별 기간/수량이 다른 휴가를 먼저 확인합니다." 버튼 → 모달
- 모달에 요청 중인 휴가도 표시

## 1년 미만 연차 특수 케이스

**CASE 1: 같은 사용기간의 1건 데이터** (부여방식 = 선부여):
- 안내 문구 없음
- 사용기한 이후 신청 → "사용기한 이내로 요청합니다. (~ YYYY.MM.DD)"

**CASE 2: 다건 데이터** (부여방식 != 선부여):
- 1년 미만 연차 클릭 시 → "남은 1년 미만 연차를 먼저 확인합니다." 안내
- 안내 클릭 → 잔여 1년 미만 연차 상세 정보 모달
- 모달 내부 각 시간 합 = 잔여시간
- 요청중인 경우 노란색 글씨로 "#시간 요청중"
- 사용 가능한 휴가보다 많이 사용 시 → "남은 1년 미만 연차의 사용기한을 확인합니다."

## 휴가 신청 밸리데이션 (L339–388) — 15개 조건

**날짜 선택**:
- 미선택 → 요청 버튼 비활성
- 모든 기간이 휴일/종일 / 마감 일자 / 정산된 휴가 → 요청 비활성

**주기 반복 사용 휴가** (예: 매달 1일 주기):
- 신청 기간에 따라 해당 주기 잔여 확인
- 여러 주기 포함 시 개별 기한 표시
- 현재 주기 모두 소진해도 신청서 연결됨 (과거/미래 주기 잔여 있으면 신청 가능)
- 신청 기간에 모두 소진한 주기 1개라도 포함 → 신청 불가

> 주기 시작일 = 근무 설정 > 회계연도 시작일 (디폴트 1월 1일)

**사용 시간 입력 - 직접 입력** (4가지):
- 시작 > 종료 → "종료 시간이 시작 시간 전입니다."
- 시작 = 종료 → "시작시간과 종료시간이 동일합니다."
- 시작/종료 차이 < 30분 → "휴가는 30분 단위로만 사용가능 합니다."
- 시작 또는 종료 미입력 → "시작 종료시간을 입력합니다."

**사용 시간 입력 - 시간 선택**:
- 시작 시간 입력란 클릭 후 미입력 → "시작 종료시간을 입력합니다."
- 퇴근시간 고정 + 근무시간 외 입력 → 안내문 "근무계획: 09:00 ~ 18:00 등" (신청 가능)

**사용 시간 입력 - 시간 옵션** (8가지):
- 시간 옵션 셀렉트 = 해당 휴가에 설정된 옵션
- 종일 옵션 사용 불가 시 → 종일 미선택 + 체크박스 비활성
- 종일 옵션만 있는 경우 → 체크박스 선택 + 비활성
- 일 계약 근무시간 초과하는 옵션 → 셀렉트에 미노출
- 이미 사용된 시간에 중복 입력 → "선택하신 기간에 이미 신청 된 휴가가 있습니다. 중복요청은 불가합니다."
- 요청 실패 후 → 에러 위치로 스크롤
- 1년 미만 연차 사용기한 초과:
  - 사용기한 = 발생시점부터 1년 → "남은 1년 미만 연차의 사용기한을 확인합니다."
  - 사용기한 = 입사일부터 1년 → "사용기한 이내로 요청합니다(기한)"
- 코멘트 입력 필수 → "코멘트를 입력합니다."
- 첨부파일 필수 → "첨부파일을 업로드합니다."

**근무 시간대 제약** (L378–381):
- 당일 출근 가능시간 이전(예: 당일 06:00 이전) 또는 익일 출근 가능시간 이후(예: 익일 06:00 이후) → "당일 06:00 ~ 익일 06:00 이내로 신청합니다."

  - 당일이 근무일(계획 출근시각 있음)이고 익일이 근무일이 아니면 종료 = `당일 계획출근 + 24시간 − 3시간` (24시간 보장)
  - 근무계획 데이터가 없으면 기본 계획(09:00~18:00 고정)으로 간주 → 06:00 ~ 익일 06:00
  - "−2시간"은 2025-02-25 이전 값. `hcgtheplus/optimiz-time#674` "출근일 기준시간 변경"에서 시스템 기본 05시→06시, 근무계획 기준 −2시간→**−3시간**으로 변경 (`DIFF_TIME_AVAILABLE_TO_WORK = 3`)

**휴가 사용 시간 고정 설정**:
- 설정한 종일 휴가 시간대로 사용
- 종일 체크박스 해제 후 설정 옵션대로 선택 가능
- **근무계획과 상관없이 사용 가능** (근무계획시간 이전/이후에도)
- **30분 단위 유효성 검사 미적용** (20분 사용 가능)
