> **메뉴** 근무관리 › 모듈 설정 (구성원 정보 · 조직 설정 · 직책 설정) / 권한 (직책자 권한 · 서브어드민 권한)
> **사용자** 어드민(근무 총괄)

## 1. 개요
모듈 설정·권한 메뉴 그룹 전체에 공통으로 적용되는 개념, 권한 모델, 비즈니스 룰을 모은 페이지입니다. 연동(인사·시스템 모듈), 모듈 설정, 총괄 권한, 권한(직책자·서브어드민) 4개 영역이 합쳐져 **"누가 무엇을 할 수 있는가"** 를 결정하며, 근무관리의 다른 모든 영역은 이 설정을 전제로 동작합니다. 각 화면의 상세는 개별 명세서를 봅니다.

## 2. 화면 구성
| 영역 | 화면 | 역할 |
|---|---|---|
| 연동 | 인사 데이터 연동 설정 / 시스템 계정관리 (근무관리 메뉴 외) | 인사 ↔ 근무 모듈 구성원 데이터 동기화 |
| 모듈 설정 | 구성원 정보 · 조직 설정 · 직책 설정 | 인사 데이터의 근무 모듈 표시, 연차기산일 관리 |
| 총괄 권한 | 별도 메뉴 없음 | 어드민 도메인 접근 권한의 최상위 |
| 권한 | 직책자 권한 · 서브어드민 권한 | 운영 권한 위임 (직책자 / 담당자) |

## 3. 기능 상세
### 3.1 총괄 권한
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-MOD-COM-01 | 관리자 총괄 등록 | 총괄로 등록된 사용자는 어드민 도메인에 접근할 수 있음 | 총괄은 모듈별로 별개 (예: 근무관리 총괄, 휴가관리 총괄) |
| A-MOD-COM-02 | 모듈 총괄 권한 | 해당 모듈의 어드민 기능 실행 및 전체 대상자 데이터 조회 가능 | 총괄이 아닌 사용자가 어드민 기능을 호출하면 접근 거부(403 Access Denied) |

### 3.2 권한 계층
| 단계 | 권한 | 부여 방식 | 범위 |
|---|---|---|---|
| 1 | 총괄 | 관리자 총괄 등록 (모듈별 1명 이상) | 어드민 전체 |
| 2 | 직책자 권한 | 직책 기반 자동 부여 (직책그룹 단위) | 직책그룹에 설정된 권한 |
| 3 | 서브어드민 권한 | 권한그룹에 담당자로 명시 지정 | 담당 범위 + 업무권한(근무 설정 관리 / 근무 실무 관리 / 휴가 설정 관리 / 휴가 실무 관리 / 과거 데이터 관리 — 메뉴 단위 상세 분류, [서브어드민 권한](../authority/custom.md) 4.1) |
| 4 | 일반 구성원 | — | 본인 데이터 (+ 참여한 워크플로우) |

권한 판단 순서: 총괄인가 → 직책자인가 → 서브어드민 담당자인가 → 일반 구성원.

### 3.3 사용자 화면에 미치는 영향
| 사용자 화면 | 필요한 권한 |
|---|---|
| 구성원 근무 / 구성원 휴가 | 직책자 권한 "구성원 근무 현황, 구성원 휴가 현황"이 있어야 타인 조회 가능 |
| 근무스케줄 | 직책자 권한 "근무스케줄 작성"이 있어야 역할 기준 탭과 수정 페이지 노출 |
| 모든 어드민 화면 | 총괄 + 모듈 권한 |

## 4. 정책 · 비즈니스 룰
1. **인사 발령 우선**: 인사-근무 연동 중에는 비활성 → 활성 전환이 인사 발령으로만 이루어집니다.
2. **인사 연동 시 조회 전용**: 연동 중에는 근무 모듈에서 조직·직책을 관리할 수 없습니다.
3. 인사 발령이 없는 직책은 근무 모듈에 연동되지 않습니다.
4. 근무 자체 관리 시 직책명은 중복 불가, 최대 20자입니다.
5. 구성원이 있는 직책, 직책자 권한 그룹에 포함된 직책은 삭제할 수 없습니다.
6. 조직·직책 조회에서 퇴직자는 노출되지 않습니다.
7. 총괄이 아니면 어드민 기능 호출 시 403 접근 거부입니다.
8. 서브어드민 권한그룹은 담당자가 없을 때만 삭제할 수 있습니다.
9. 활성 상태 구성원만 담당자로 추가할 수 있습니다.
10. 서브어드민 담당 범위는 회사별로 조직을 골라 지정합니다. 다중회사 클라이언트의 "회사 단위 전체조직만 선택" 제약은 2025-12-24 해제되었습니다.
11. 권한 종료일이 지난 담당자는 목록에서 흐리게 표시됩니다.
12. 직접 추가한 구성원은 "담당 구성원"과 "추가 구성원" 양쪽에 표시됩니다.
13. 제외 구성원을 복구할 때 담당 범위 안이면 담당 구성원으로 복귀, 범위 밖이면 단순 삭제됩니다.
14. "설정 관리" 업무권한은 설정 메뉴(근무/휴가 설정, 그룹 설정, 그룹 이력 관리)를, "실무 관리" 업무권한은 운영 메뉴(근무 데이터·신청 내역·마감·개인 스케줄 / 연차·연차 외 휴가 관리·연차 촉진)를 엽니다.

### 4.1 다른 모듈과의 연쇄 효과
| 동작 | 근무 모듈 영향 |
|---|---|
| 인사 발령 확정 | 근무 모듈 구성원 즉시 추가 / 비활성 |
| 인사 모듈 연동 해제 | 근무 모듈에서 직책을 자체 관리하는 모드로 전환 |
| 시스템 계정 비활성 | 근무 모듈 구성원도 비활성 |
| 시스템 계정 활성 (근무 연동 중) | 근무 모듈 비활성 유지 (인사 발령으로만 활성화) |
| 직책그룹 변경 | 해당 직책 보유자의 권한 즉시 변경 |
| 서브어드민 권한그룹 담당자 추가 | 해당 담당자에게 어드민 접근 권한 부여 |
| 권한 종료일 도래 | 담당자 목록에서 흐리게 표시 |
