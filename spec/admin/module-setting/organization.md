> **메뉴** 근무관리 › 모듈 설정 › 조직 설정
> **URL** `/attendance/module_setting/organization`
> **사용자** 어드민(근무 총괄)

## 1. 개요
인사 모듈과 연동된 조직 정보를 근무 모듈에서 조회하는 **조회 전용** 화면입니다. 조직은 인사 모듈에서만 정의하며, 근무 모듈에서는 생성·수정·삭제할 수 없습니다.

## 2. 화면 구성
| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 헤더 | [관리자 일괄 수정], [새 조직 추가], [조직 엑셀 다운로드] | [관리자 일괄 수정]·[새 조직 추가]는 항상 비활성, 툴팁 "인사관리 모듈에서 설정이 가능합니다." |
| 연동 안내 | 연동 중 안내 문구, 연동 구분, 마지막 연동 일자 | talenx 인사관리와 연동 중일 때만 노출 |
| 조직 트리 | 조직명, 조직장, 구성원 수, 상세보기(돋보기) | 조직장이 2명 이상이면 "OOO 등 N명", 마우스 오버 시 전체 이름(사번) |
| 조직 상세 정보 (다이얼로그) | 조직명, 조직장, 상위 조직, 구성원 표(이름 · 사번 · 활성 여부 · 조직) | 모든 항목 조회 전용. [조직 삭제]/[수정]/[확인] 비활성 |

## 3. 기능 상세
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|
| A-MOD-ORG-01 | 조직 정보 조회 | 인사 모듈과 연동된 조직을 트리로 노출 | 수정 불가 |
| A-MOD-ORG-02 | 조직 엑셀 다운로드 | "조직 데이터 엑셀 다운로드" 사유 입력 모달 → 다운로드. 컬럼: 번호 · 조직명 · 조직 경로 · 조직장 · 조직장 사번 · 구성원 수 | 사유 입력 필수 |
| A-MOD-ORG-03 | 조직 상세 조회 | 돋보기 클릭 → 조직 상세 정보 다이얼로그에서 조직장 / 구성원 조회 | 퇴직자는 조회되지 않음. 비활성 조직장은 "(비활성)", 겸직 조직장은 "(겸)" 표시 |

## 4. 정책 · 비즈니스 룰
1. 조직은 인사 모듈에서만 정의하며 근무 모듈에서는 조회 전용입니다. 조직 추가·수정·삭제 버튼은 노출되지만 항상 비활성입니다.
2. 조직 상세에서 퇴직자는 노출되지 않습니다.
3. 조직 엑셀 다운로드도 구성원 정보와 같이 다운로드 사유를 입력해야 합니다.

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 조직 정보 조회 실패 | "조직 정보를 불러오는데 실패했습니다." |
| 다운로드할 조직 데이터 없음 | "엑셀 다운로드 가능한 데이터가 없습니다." |
| 엑셀 다운로드 실패 | "조직 정보 다운로드에 실패했습니다." |
