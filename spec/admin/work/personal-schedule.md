## 1. 개요

근무그룹의 그룹스케줄과 별개로 구성원별로 지정된 **개인스케줄**(개인 근무 계획)을 어드민이 조회 · 등록 · 삭제하는 화면입니다 (안내 문구: "근무그룹의 기준 스케줄과 개인별로 변경된 근무 스케줄을 조회하고 수정합니다."). 개인스케줄은 근무계획 변경 신청 승인, 직책자의 스케줄 변경 확정, 대체근무 신청 승인, 그리고 이 화면의 엑셀 일괄 등록으로 만들어지며, 그룹스케줄보다 우선 적용됩니다.

**선택적 근로 스케줄** 탭에서는 선택적 근로시간제 대상자가 직접 수립한 근무 스케줄을 조회합니다.

> 용어: **근무 스케줄 = 근무 계획**(동의어), **근무 템플릿 = 근무 계획의 종류**.

## 4. 정책 · 비즈니스 룰

1. 개인스케줄은 4가지 출처(근무계획 변경 / 직책자 변경 / 대체근무 / 어드민 엑셀 등록)에서 만들어지며 이 화면에서 통합 관리합니다.
2. 근무그룹 소속이 아닌 구성원은 스케줄이 없으므로 조회되지 않고, 등록할 수도 없습니다.
3. 어드민은 **내일 이후 근무일**의 개인스케줄만 등록 · 삭제할 수 있습니다 (오늘 · 과거 불가).
4. 삭제는 **복구 불가 영구 삭제**입니다 (삭제 전 내용은 변경 이력으로 남음).
5. 해당 일자가 **근무 마감**되었거나, **근무계획 변경 신청** 또는 **대체근무 신청**이 진행 중이거나, 해당 구성원에 대한 권한이 없으면 그 건은 등록 · 삭제되지 않습니다. 나머지 건은 처리됩니다(부분 처리).
6. 선택적 근로제 근무그룹 소속 구성원은 엑셀 등록 대상이 아니며, 선택적 근로 스케줄 탭에서 본인이 수립한 스케줄을 조회만 할 수 있습니다.
6-1. 선택적 근로제 구성원도 근무 스케줄 탭 목록에 나옵니다. 그룹 스케줄은 표시되고 개인 스케줄 칸은 비어 있으며, 대체근무 등 신청서로 바뀐 날만 개인 스케줄이 표시됩니다 (기획 확인 2026-11-05).
7. 개인스케줄이 삭제되면 사용자 캘린더에서 사라지고 그룹스케줄이 적용됩니다 (개인스케줄 > 그룹스케줄 우선순위).
8. 서브어드민 권한의 **"개인 근무 관리"** 항목이 있어야 메뉴가 노출되며, 권한 보유 시 두 탭의 조회 · 엑셀 다운로드와 근무 스케줄 탭의 등록 · 삭제가 가능합니다. 권한이 없으면 메뉴 자체가 노출되지 않습니다.
9. 엑셀 다운로드는 사유 입력이 필수입니다(감사 로그).

| 엑셀 업로드 양식 오류 | "업로드 실패" — "{행}행: {항목}은 필수 입력 항목입니다." / "{행}행: 근무일 날짜 형식이 올바르지 않습니다." / "{행}행: 메모는 255자 이내로 작성합니다." |

| 업로드 처리 중 | "엑셀 파일을 백그라운드에서 처리 중입니다." / 재업로드 시 "이전 업로드가 진행 중입니다." |
| 업로드 전체 성공 | "스케줄 등록 완료" / "스케줄 등록을 완료했습니다." |

| 업로드 실패 사유 | "접근 권한이 없습니다." / "마감된 기간입니다." / "근무계획 변경 신청이 진행 중입니다." / "대체근무 신청이 진행 중입니다." / "사번은 필수 입력 항목입니다." / "근무일 날짜 형식이 올바르지 않습니다." / "유효하지 않은 스케줄입니다." / "메모는 255자 이내로 작성합니다." / "사용 가능한 스케줄이 아닙니다." / "미래 날짜만 업로드 할 수 있습니다." / "소속된 근무그룹이 없습니다." / "선택적 근로제 근무그룹 소속 인원은 업로드할 수 없습니다." / "시스템 오류가 발생했습니다." |
