> 예전 "휴가 지급 및 관리" 화면이 **연차 관리 / 연차 외 휴가 관리** 두 메뉴로 나뉜 것입니다(연차 촉진은 원래 별도 메뉴). 예전 메뉴 주소로 들어오면 이 화면으로 이동하며, 탭은 주소에 기억되어 새로고침해도 유지됩니다.

## 1. 개요
구성원의 연차를 생성 · 조정 · 정산하고, 연차 사용 기록을 조회 · 수동 등록하는 화면입니다. 연차는 구성원이 속한 휴가 그룹의 연차 제도와 연차 정산 기준에 따라 처리됩니다. 조회 필터·엑셀 다운로드 등 탭 공통 동작은 [휴가 공통 정책](./overview.md) § 3.1을 따릅니다.

## 4. 정책 · 비즈니스 룰
1. 연차 정산은 귀속연도 단위로 처리하며, 1년 미만 연차는 합산 처리합니다.
2. 다음 귀속연도가 정산된 경우 이전 귀속연도의 정산을 취소할 수 없습니다.
3. 정산된 연차, 근무 마감된 날짜의 연차는 요청·승인·취소할 수 없습니다.
4. 초과 사용은 연차 제도에서 허용한 경우에만 가능합니다(일반 연차: "연차 초과 사용", 1년 미만 연차: "1년미만연차 초과 사용" — 기본 허용 안함). 1년 미만 연차는 초과 사용을 허용해도 아직 발생하지 않은 달의 연차를 당겨 쓰지 않으므로, 앞당겨 쓰게 하려면 연차 조정에서 사용 시작일을 앞당깁니다. 어드민 강제 등록([초과 사용으로 등록])도 연차 제도의 "허용 안함"은 넘지 못합니다.
5. 연차 자동생성 시 생성 기준일에 휴가 그룹 소속이 없는 구성원이 있으면 생성이 실패합니다(권장 순서: 연차기산일 입력 → 근무 그룹 배정 → 휴가 그룹 배정 → 자동생성).
6. 연차 차감은 사용 종료일이 빠른 연차부터 이루어집니다.
7. 관리자 수동 등록 휴가는 결재 없이 등록되며, 사용자 화면에서 별도 확인 모달로 표시됩니다.
8. 보유현황의 "사용기간"은 생성 건 단위 요약이며, 기간별 사용 이력은 연차 사용 현황 탭에서 확인합니다.
9. 연차가 마감(정산 완료)된 구성원은 연차 자동 생성·연차 조정을 할 수 없습니다. 정산을 취소한 뒤 진행합니다.
10. 연차 자동 생성은 퇴직자를 제외하며, 연차를 새로 생성하면서 바뀐 사용기간 밖에 이미 사용 내역이 있는 구성원은 생성에서 제외됩니다.
11. 연차는 현재 근무율(출근율 80%·월 만근)과 무관하게 생성됩니다.
12. 정산 취소 시 다음 귀속연도의 잔여가 이월받은 일수만큼 남아 있지 않으면 정산을 취소할 수 없습니다. 잔여가 충분하면 정산 취소 연도에 이월분이 잔여로 돌아오고, 다음 귀속연도의 이월 일수에서는 이번 정산으로 넘어간 만큼만 회수합니다. 다음 귀속연도 연차가 이미 정산됐거나 두 건 이상이면 취소할 수 없습니다. (기획 확인 2026-11-05)
13. 연차 조정의 사용 시작일 변경은 1년 미만 연차 행에서만 가능합니다. 입사일·연차기산일과의 비교는 화면에서 검증하고, 서버는 종료일 이전·귀속연도 이전 불가만 검증합니다(의도된 설계, 기획 확인 2026-11-05).
14. 연차/연차 외 휴가 사용 현황 탭의 [등록 내역]은 개발이 보류된 기능으로, 버튼만 비활성 상태로 노출됩니다(기획 확인 2026-11-05).
