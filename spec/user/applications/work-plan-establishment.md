> **메뉴** 근무 신청 › 근무계획 수립
> **진입** 출퇴근 위젯 [근무신청] → "근무계획 수립 신청"
> **사용자** 선택적 근로제 근무그룹 소속 구성원(신청자) · 결재자

## 1. 개요
선택적 근로제 구성원이 **정산기간 전체**의 일자별 근무 시작·종료 시각을 직접 정해 승인받는 신청서입니다. 승인되면 그 정산기간의 개인 일자별 근무 스케줄이 확정되어 근무시간 계산의 기준이 되고, 아직 수립하지 않은 근무일은 내 근무 캘린더에 "미수립"으로 표시됩니다. 선택적 근로제 근무그룹에서는 근무계획 변경 신청을 쓸 수 없고, 이 신청서로 수립과 변경을 모두 합니다.

### 근무계획 변경과의 차이
| 구분 | 근무계획 변경 | 근무계획 수립 |
|---|---|---|
| 대상 | 선택적 근로제가 아닌 근무그룹 | 선택적 근로제 근무그룹만 |
| 신청 단위 | 원하는 기간 | 정산기간 전체 |
| 입력 | 근무일 템플릿 하나 선택 | 일자별 시작·종료 시각 직접 입력 (일괄 입력 가능) |
| 휴일/휴무일 | 변경 불가 | 근무그룹 설정이 "허용"이면 근무 시각 입력 가능 |
| 검증 | 변경 전후 동일 불가 등 | 정산기간 합계가 소정근로시간 이상·최대 근무시간 이하, 일자별 코어타임 포함 |
| 승인 결과 | 기간의 근무계획 변경 | 정산기간 전체 스케줄 확정(교체) |

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 유형 | 신청서 유형, 신청서 설명 | 설명은 접기/펼치기 |
| 정산 기간 | 정산기간 드롭다운 + 차단 사유 | 차단되면 아래 본문 없이 사유만 표시 |
| 요약 | "소정근로시간" / "계획한 시간" / "최대 근무시간" / "총 근무일 N일" | 계획한 시간에 "(N 미달)" / "(N 초과)" 표시 |
| 달력 | 정산기간 달력, "전체 선택"/"선택 해제", "N개 일괄 입력" | 범례 "미입력" / "입력됨" / "확인 필요" / "선택됨" |
| 전체 일정 | "M월 N주차" 아코디언, "전체 열기"/"전체 닫기", 일자별 시작·종료 시각 | 주차 합계 표시 |
| 하단 | 코멘트, 첨부, 결재선, [요청] | 코멘트/첨부 필수는 근무그룹 설정 |

## 4. 정책 · 비즈니스 룰
1. 근무제 유형이 **선택적 근로제**인 근무그룹 + 근무 신청서 관리 › 근무계획 수립 신청 **사용 여부 ON**일 때만 사용한다. (어드민 설정 화면에서도 선택적 근로제 그룹에서만 활성)
2. 신청 단위는 **정산기간 전체**이다. 정산기간 중 근무그룹이 바뀌면 그 근무그룹 소속기간에 해당하는 부분이 한 단위가 된다. 정산 단위가 월/주인 근무그룹만 지원한다.
3. 정산기간 계획 합계는 **소정근로시간 이상**, **최대 근무시간 이하**(제한이 있는 그룹만)여야 한다. 소정근로시간은 근무그룹 기준이 법정이면 법정 소정근로시간, 근무계획 기준이면 근무그룹 스케줄의 근무일 소정근로시간 합이다.
4. 코어타임이 있는 근무일은 입력한 근무시간이 코어타임 전체를 포함해야 한다.
5. 다음 정산기간은 신청할 수 없다 (우선순위 순): 같은 정산기간에 요청중인 근무계획 수립 신청 → 요청중인 대체근무 신청 → 마감된 일자 포함 → 확정된 근무 스케줄이 없는 일자 포함.
6. 최초 신청은 정산기간의 근무일을 모두 입력해야 한다. 휴일·휴무일 입력은 근무그룹 설정 "휴일/휴무일 근무 허용 여부"가 "허용"일 때만 가능하다. "허용 안함"인데 예전에 근무일로 수립된 휴일·휴무일을 다시 입력하지 않으면 원래 휴일·휴무일로 되돌린다.
7. 신청서를 연 뒤 어드민이 휴일/휴무일 허용 설정을 바꾸면 [요청] 시 신청을 막고 정산기간을 처음부터 다시 고르게 한다.
8. 승인 시 정산기간 전체 스케줄을 교체한다. 마감된 일자가 있으면 승인할 수 없다.
9. 근무계획 수립과 대체근무는 같은 정산기간에 하나가 요청중이면 다른 쪽을 신청할 수 없다.
10. 결재 완료 후 사용자 취소 불가. 반려·취소된 신청은 같은 정산기간 재신청을 막지 않는다.

- **지난 날짜 재수립**: 마감 전이면 지난 날짜도 수립·재수립할 수 있습니다. 계획보다 더 근무한 시간을 기본근무로 인정받으려면 해당 일자의 근무계획을 실제 근무시간에 맞게 다시 수립합니다 (고객 안내 기준, 2026-11-05 확인).

- **결재 완료 후 변경 (기획 확인 2026-11-05)**: 취소 신청서가 없으며 같은 정산기간을 다시 수립 신청해 바꿉니다.
- **작성 진입**: 출퇴근 위젯 [근무신청] 메뉴로만 작성합니다. 워크플로우 [문서 작성]에는 커스텀 신청서만 노출되므로 근무 신청서는 워크플로우에서 새로 작성할 수 없습니다.
- **어드민 조회 (기획 확인 2026-11-05)**: 수립된 계획은 개인 근무 스케줄 관리 › 선택적 근로 스케줄 탭에서만 보입니다. 근무 스케줄 탭에도 선택적 근로제 인원이 나오지만 개인 스케줄 칸은 공란이고, 대체근무처럼 신청서로 바뀐 날만 표시됩니다. 선택적 근로제 인원은 어드민 스케줄 등록·직책자 스케줄 변경·근무계획 변경 신청을 할 수 없습니다.
- **휴일/휴무일 허용 판단**: 선택한 정산기간 기준의 휴일·휴무일 근무 허용 설정을 따릅니다 (오늘 그룹 설정이 아님).

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 정산기간 미선택 | 드롭다운 "정산 기간을 선택하세요" |
| 정산기간 변경 (입력 있음) | 확인 "정산 기간 변경" — "정산 기간을 변경하면 입력한 근무시간이 모두 초기화됩니다. 계속 진행하시겠습니까?" |
| 요청중 수립 신청 있음 | "해당 정산 기간은 근무 계획 수립 승인 대기 중으로 신청이 불가합니다." |
| 요청중 대체근무 신청 있음 | "선택한 정산기간에 요청중인 대체근무 신청이 있습니다." |

| 확정 스케줄 없는 일자 포함 | "해당 정산기간에 확정된 근무 스케줄이 없는 일자가 포함되어 신청이 불가합니다." |

| 코어타임 미포함 | "코어타임(HH:mm~HH:mm)을 포함해야 합니다." |
| 계획 합계 < 소정근로시간 | 알림 "근무시간 미달 안내" — "계획한 시간이 소정근로시간보다 부족합니다. 일부 날짜의 근무시간을 조정 후 신청하시기 바랍니다." (소정근로시간 / 계획한 시간 / 부족한 시간) |
| 계획 합계 > 최대 근무시간 | 알림 "근무시간 초과 안내" — "계획한 시간이 최대 근무시간을 초과했습니다. 일부 날짜의 근무시간 조정 후 신청하시기 바랍니다." (최대 근무시간 / 계획한 시간 / 초과한 시간) |
| 원래 휴일/휴무일 입력 표시 | 툴팁 "점 표시가 있는 '입력됨' 라벨은 기존에 휴일/휴무일이었던 일자를 의미합니다." |
| 서버 거절 (화면 검증을 우회한 경우) | "최초 신청은 근무일 전체의 근무계획을 입력해야 합니다." / "휴일/휴무일에는 근무계획을 입력할 수 없습니다." / "근무일은 근무 시작/종료 시각을 입력해야 합니다." / "기준 스케줄이 없는 일자는 근무계획을 입력할 수 없습니다." / "계획근로시간 합계가 소정근로시간보다 작습니다." / "계획근로시간 합계가 최대근로시간을 초과했습니다." / "근무계획 수립 신청은 정산기간 전체 단위로만 신청할 수 있습니다." |
| 승인 시 마감 일자 포함 | "근무 마감된 일자가 있어 근무계획 수립 신청을 승인할 수 없습니다." |
| 코멘트 / 첨부 필수인데 미입력 | "코멘트를 입력합니다." / "첨부파일을 업로드합니다." |
