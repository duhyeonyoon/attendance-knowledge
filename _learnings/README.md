# _learnings/ — 누적 학습 노트

대화/작업 중 새로 알게 된 사실을 임시로 적어두는 폴더입니다.
일정 주기로 본문 (`product/`, `code/`, `domain/`) 으로 흡수하고 비웁니다.

## 사용 패턴

- **신규 발견**: `YYYY-MM-DD-<topic>.md` 형식으로 추가
- **검증 완료**: 본문 해당 위치로 이동, 여기서는 삭제
- **검증 실패**: 폐기

## 예시 파일명

- `2026-05-13-overtime-aggregation-logic.md`
- `2026-05-14-leave-promotion-edge-case.md`

`consolidate-memory` Skill을 활용해 주기적으로 정리하면 좋습니다.
