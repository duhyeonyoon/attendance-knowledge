## 2. 야간근무 (22시 ~ 06시)

QA 출처: L119, L134–142

- 법적 기준: **22:00 ~ 06:00**
- 근무그룹 설정: "승인 시에만 근무 가능" / "근무 불가"
- "근무 불가" 설정 시:
  - 출근 시점: 출근 불가 안내문
  - 퇴근 시점: 퇴근은 가능 (안내문 확인 후)
  - 출퇴근 신청 모달에서 22~06시 포함되면 밸리데이션
  - 사전 연장/야간 신청서, 사전 휴일 신청서, 근무내역 변경 신청서 모두 22~06시 포함 시 밸리데이션 또는 야간 불가 비근무 처리
- "승인시 근무 가능" 설정 시:
  - 승인 받은 내역 없으면 출/퇴근 안내문 표시 후 가능
  - 근무계획시간 외 모든 시간 = 연장근무 설정인 경우, **계획 출근시각 전의 조기출근(연장근무 출근)에는 안내문 미표시** (예: 9–18시 그룹의 7시 출근)

## 3. 연장근무

QA 출처: L122–133, L184

- 근무그룹 설정(연장근무 허용, 화면 라벨): "연장 가능" / "승인 시에만 연장 가능" / "연장 불가"(현재 라디오 비활성 — 선택 불가). 야간은 "야간 가능 / 승인 시에만 야간 가능 / 야간 불가", 휴일은 "근무 가능 / 승인 시에만 근무 가능 / 근무 불가" (2026-11-05 코드·e2e 확인)
  - ~~"자유 허용 / 승인 시에만 / 근무계획시간 외 모든 시간"~~ — 허용 옵션과 별도 항목인 **연장시간 관리 방식**(예: "근무 계획시간 외 모든 시간은 연장근무로 기록")을 섞은 표기였음
- 예상 퇴근시간 초과 시 위젯 문구 "예상 퇴근 시간이 지났습니다.":
  - "연장 가능" → 주황색 텍스트 (현재 연장시간대 진입 시. '근무계획시간 외 모든 시간 = 연장' 그룹은 계획 출근시각 이전 미표시)
  - "승인 시에만 연장 가능" → 빨간색 텍스트
  - "연장 불가" → 위젯 안내 없음, 퇴근 시 미승인 안내 다이얼로그
- 초과근무 시간 제한 설정 시 해당 시간 도달하면 출/퇴근 안내문
- 정산기간 합계 기준 그룹·최대 근무시간 초과 시 안내문 ("소정근무시간을 초과했습니다.")
- 최대 초과근무 미설정 시 연장 신청은 밸리데이션 없이 통과 (잔여 12h는 표시용) — `KB:product/user/applications/overtime.md`
- **(2026-11-05)** 사후 신청(1042) 승인도 사전과 동일하게 승인 구간과 실제 출퇴근 기록이 겹치는 부분만 인정. 출퇴근 내역 변경(1072) 승인은 정정 시간의 연장·야간을 승인으로 간주하지 않음 — `KB:product/user/applications/overtime-post.md`, `KB:product/user/applications/inout-record-change.md`
- **"연장 불가" 옵션은 개발 전**이라 모든 근무그룹에서 신규 선택 불가, 개발 계획 없음. 연장분 수당 미지급은 급여 계산식 설정으로 처리 (Slack #cx·#channeltalk 2026-10-08)
  - 예전에 "불가"로 저장된 그룹은 연장시간대 출근 시 서버가 차단(BLOCK)하지만 **화면은 거절 사유를 처리하지 않아 안내 없이 무반응** — 2026-01-26 #sq-time TODO로 남은 구현 누락 (`KB:product/user/home/checkin-widget.md`)

## 4. 휴일근무

QA 출처: L143–153

- 근무그룹 설정: "승인 시에만" / "휴일 근무 불가"
- "승인 시에만":
  - 승인 없이 출/퇴근 시 안내문 후 가능
  - 승인 있으면 정상 처리
- "휴일 근무 불가":
  - 출근 시점: 출근 불가 안내문
  - 그룹/스케줄 변경으로 출근 후 휴일 불가가 된 경우 → 퇴근 안내문 후 퇴근 가능
- **(2026-11-05)** 사후 신청(1122) 승인도 사전과 동일하게 승인 구간과 실제 출퇴근 기록이 겹치는 부분만 인정 (근무시간 포함여부 '승인시간만 포함'일 때). 출퇴근 내역 변경(1072) 승인은 정정 시간의 휴일 근무를 승인으로 간주하지 않음 — `KB:product/user/applications/holiday-work-post.md`, `KB:product/user/applications/inout-record-change.md`

## 5. 출퇴근 위치 (GPS / 근무지)

QA 출처: L72

- 등록 근무지 **외** 위치에서 출/퇴근 시 → "출/퇴근 요청" 모달
- 예외: 근무그룹 GPS 설정이 OFF 또는 등록된 출근지가 없으면 근무지 외 출퇴근 허용

- 출근 요청 승인 시: 칩 사라지고 출근 시간 확정

## 6. 출근 인정 시각

QA 출처: L75, L87

- 인정 시각 설정 가능
- 인정 시각 **이전** 출근 시: 출근시간 옆 info 문구, 근무시간 미인정
- 출퇴근 요청 모달에서 인정 시각 이전으로 변경 시 밸리데이션
- **출근시간 고정여부(`workStaTimeFix` F=정해진 시각 / S=자유롭게)와 무관하게 동일 동작** — 확정 근무시간 산정은 `validInTimeUseYn`/`validInTime`만 참조 (`be:WorkTimeCalcService:135-157, 2400-2425`)
- 타각 기록 자체는 실제 시각으로 남고, `[실제 출근 ~ 인정시각]` 구간이 `EARLY_IN`(조기출근 비근무)으로 분리됨
- ⚠️ **예상 퇴근시간에는 인정시각 보정이 없음** — 자유출근(S)은 실제 타각 기준이라 예상 퇴근시간만 앞당겨져 보임 (`be:WorkTimeCalcService#makeExpectOutTime:3163-3210`). 상세 → `_learnings/2026-08-03-validintime-vs-workstatimefix.md`

## 7. 출퇴근 시간 변경 밸리데이션

QA 출처: L83–93

- 현재 시간 이후로 출/퇴근 시간 변경 → 불가 (밸리데이션)
- 재출근 시 이전 퇴근 기록 전 출근 → 밸리데이션 (퇴근시간 확인)
- 출근 시간 이전으로 퇴근 → 밸리데이션
- 퇴근 신청 시 초과근무 시간 제한 초과 → 밸리데이션
- 연장/야간/휴일 = 승인시에만, 그러나 미승인 시간에 출퇴근 → 밸리데이션
- **근무 마감된 일자**: 요청/승인/취소요청/취소승인 모두 불가

## 9. 근무 마감 후 제약

QA 출처: L90, L731+

- 마감된 일자: 요청/승인, 승인완료 건 취소요청/취소승인 모두 불가
- 마감 상태 단위: 구성원 × 일자 / 실행·해제 단위: 근무그룹 × 기간 (이력). 개별 마감 기능은 코드값만 있고 UI·API 없음 (2026-11-05)
- 마감 해제: 마감 내역 탭 "일괄 해제" — 일괄 마감 이력 단위, 해제 이력 별도 생성
- 결재중 신청서가 있어도 마감은 진행됨 (신청서는 건드리지 않음)
- **마감된 일자의 결재중 신청서**: 결재함에 "승인필요"로 남지만 승인 시 "기한만료"로 거절, **반려만 가능**. 승인이 필요하면 마감 해제 → 승인 → 재마감으로 안내 (Slack #cx 2026-08-25, 2026-10-13)
  - 기획 초안(#ch-plan 2025-10-29)은 "요청중 신청서가 있으면 마감에서 제외"였으나 현재 구현은 제외 없이 일괄 마감 — 변경 결정 기록 없음 [확인 필요]

## 14. 휴가 초과 사용 (2026-11-05 정리)

- 초과 사용은 **연차 제도에서 허용한 경우만** 가능
  - 정상연차: 연차 제도 "연차 초과 사용" 옵션
  - 1년 미만 연차: 2026-09-17부터 "1년미만연차 초과 사용" 옵션 (기본 꺼짐, 켜면 제한 없음 / 최대 N시간) — hcgtheplus/optimiz-time#1642, talenx-admin#4375
  - 연차 외 휴가: 초과 사용 없음
- 어드민 수동 등록: 한도 초과 건은 "연차 부족"으로 분류 → [초과 사용으로 등록] 가능. 단 옵션이 꺼진 제도는 강제 등록 불가
- 자세히: `KB:product/admin/leave/overview.md`, `KB:product/admin/leave/annual-management.md`
- **휴가 일수 환산 원칙**: 일수 표시는 표준근로시간 기준으로 환산 (Slack #sq-time 2026-05-26). 사용자 신청 경로는 근무 템플릿 시간으로 환산하는 부분이 있어 어드민 직접 등록·정산 경로와 결과가 다를 수 있음 [확인 필요 — `KB:product/user/attendance/my-leave.md`]
