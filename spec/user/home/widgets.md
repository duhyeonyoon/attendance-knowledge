> **메뉴** 통합홈 › 처리할 문서 · 근무 대시보드(평균 근무시간 등) · 예정 휴가 · 구성원 휴가
> **사용자** 사용자(구성원)

## 1. 개요

사용자가 로그인 후 처음 보는 통합홈의 요약 위젯 모음입니다. 처리할 결재 문서, 본인 근무 지표, 예정 휴가, 구성원 휴가를 한눈에 보고 각 상세 화면으로 이동합니다. 출퇴근 위젯·근무 현황·근무 요약 정보는 별도 명세서에서 다룹니다.

## 2. 화면 구성

| 영역 / 탭 | 구성 요소 | 설명 |
|---|---|---|
| 처리할 문서 | 승인필요 / 읽지않음 탭, 문서 리스트, [더 보기] | 받은 문서가 있을 때만 위젯 노출 |
| 근무 대시보드 | 숫자 카드 8종 | 본인 근무 지표. 카드 클릭 시 근무정보 페이지 이동 |
| 예정 휴가 | 휴가 리스트, [휴가 신청] 버튼, [더 보기] | 본인의 예정 휴가 |
| 구성원 휴가 | 주간 휴가자 리스트, 날짜, [설정] | 설정한 조직/구성원의 휴가 현황 |
| 출퇴근 위젯 | — | [출퇴근 위젯](./checkin-widget.md) |
| 공통 | 모바일 우측 하단 맨 위로 버튼 | 모바일 스크롤 시 노출 |
| 헤더 | [대시보드 설정] 버튼 | 위젯 사용 여부·배치 설정 화면으로 이동 |

## 3. 기능 상세

### 3.1 공통 리스트 규칙

| ID | 기능 | 상세 동작 | 조건 · 예외 |

| U-HOME-WDG-01 | 리스트 표시 개수 | 문서·예정 휴가: 3개씩 + [더 보기] / 근무현황·구성원 휴가: 웹 스크롤, 모바일 5개씩 | — |
| U-HOME-WDG-02 | 모바일 아코디언 | 근무현황은 접힌 채, 구성원 휴가 현황은 펼친 채로 시작 | 모바일 한정 |
| U-HOME-WDG-03 | 맨 위로 이동 | 모바일 스크롤 시 우측 하단 버튼으로 최상단 이동 | 모바일 한정 |
| U-HOME-WDG-15 | 대시보드 설정 | 통합홈 [대시보드 설정] → 대시보드(탭)별로 위젯 사용 여부와 위치(웹 좌/우, 모바일 순서)를 정하고 [저장] → 통합홈으로 복귀 | 위젯을 하나도 선택하지 않으면 저장 불가 안내. "근무 현황 상세" 위젯은 근무시간 비공개 그룹이면 표시되지 않음. 개인 편집은 회사 방식이 '구성원 직접 설정'일 때 적용 (4절 6) |

## 4. 정책 · 비즈니스 룰

1. **승인필요 ≠ 읽지않음**: 두 탭은 배타적입니다.
2. 값이 0인 대시보드 카드는 클릭할 수 없습니다.
3. 관리자 등록 휴가(어드민 연차 수동등록)는 신청서가 아닌 별도 확인 모달로 열립니다.
4. 구성원 휴가 설정 대상은 본인 소속 회사 하위로 한정되고, 조직은 소속 구성원이 있는 조직만 표시됩니다 (2025.04.17 기준 임시 제약).
5. 근무/휴가 요청은 승인자의 구성원 근무 / 구성원 휴가 메뉴에서도 조회·승인할 수 있습니다.
6. **대시보드 구성은 회사 단위로 관리 방식이 정해집니다** (기획 확인 2026-11-05). 어드민의 홈 대시보드 설정에서 고객사 공통 기본 구성을 두고, 회사마다 다음 중 하나를 고릅니다.

   | 회사별 방식 | 구성원이 보는 통합홈 |
   |---|---|
   | 기본 설정 따름 | 고객사 공통 기본 구성 |
   | 어드민 일괄 설정 | 관리자가 정한 위젯 구성 (구성원 개인 편집 제한) |
   | 구성원 직접 설정 | 구성원이 [대시보드 설정]으로 개인별 편집 |

   사용하지 않는 메뉴(모듈)의 위젯은 표시되지 않습니다. 회사별 설정은 오너·시스템 관리자와 '홈 대시보드 설정' 권한을 받은 서브어드민(담당 회사만)이 바꿀 수 있습니다.

**위젯 간 연동 효과**

| 동작 | 영향 |
|---|---|
| 처리할 문서 승인/반려 | 작성자에게 알림 + 작성자의 내 근무 캘린더 갱신 |
| 예정 휴가 취소/승인 | 캘린더 즉시 반영 + 휴가 잔여 변동 |
| 근무 요약 정보 기간 변경 | 통합홈·내 근무 위젯 모두 갱신 |

## 5. 메시지 · 예외 처리

| 상황 | 화면 메시지 / 처리 |
|---|---|
| 받은 문서 없음 | 처리할 문서 위젯 숨김 |
| 요청 | 승인자에게 talenx 알림 |
| 승인/반려 | 작성자에게 talenx 알림 |
| 코멘트 | 작성자 + 승인자 (코멘트 작성자 제외) 알림. 프로필 › 계정설정 › 알림설정에서 OFF 가능 |
