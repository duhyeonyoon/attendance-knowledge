## A-1. 연차 제도 (Annual Leave Rule)

**페이지**: `/attendance/leave/base_setting/annual_leave_rule`

**필수값**: 연차 제도명("연차 제도 명을 작성합니다.") · **휴가 설명**("휴가 설명을 작성합니다." — 휴가 요청 시 구성원에게 공유됨) · 연차 부여 기준 · 연차 설정 · 연차 사용 시간대 (2026-11-02 검증, `_learnings/2026-11-02-leave-settings-full-inventory.md`)

**핵심 설정**:
- **연차 부여 기준**: 회계연도 기준 / 입사일 기준 / 부여 안함
  - "부여 안함" 설정 시 1년 미만 연차/첫 회계연도 연차/연차 설정 모두 숨김 (매년 0일 생성, 필요하면 어드민이 수동 조정)
- **1년 미만 연차(월차) 설정**: 최초 부여 기준 · 부여 방식 · 부여 개수 · 사용기한
  - 부여 방식 중 **'별도 기준'(`T`)은 비활성** (`ad:...annual_leave_rule_tab/detail/index.tsx:835`, 백엔드도 미구현 TODO)
  - **기타 설정 › "1년미만연차 초과 사용"** (2026-09-17 신설, `hcgtheplus/talenx-admin#4375` / `hcgtheplus/optimiz-time#1642`): 허용 안함(기본) / 허용 — 제한 없음 또는 최대 N시간. 미입력 시 "1년미만연차 초과사용 허용시간을 입력합니다.", 1 미만이면 "1년미만연차 초과사용 허용시간은 1 이상의 정수로 설정합니다." 한도는 달마다 리셋되지 않는 **사이클 총량**이며, 확정 시점(신청일/등록일)에 이미 도래한 생성분 기준으로 판정. 미도래분은 당겨쓰지 않음. **(2026-11-05 Slack 재확인)** 허용 여부·한도는 '연차를 실제로 쓰는 날짜'에 소속된 휴가그룹의 연차 제도를 따름(8월 사용분은 8월 당시 그룹 설정) — 릴리즈 안내 Slack #bizops-center 2026-09-22 (https://hcgtheplus.slack.com/archives/C0AC4BH6QLB/p1790065137896459?thread_ts=1789627172.244019&cid=C0AC4BH6QLB)
- **첫 회계연도 연차 설정** (회계연도 기준 선택 시): 모두 부여(15일) / 근속일할(15일 × 표준근로시간 × 근속 총 일수 / 365) / 근속월할(15일 × 표준근로시간 × 근속 개월수 / 12). 일할·월할이면 **최소 단위(30분~1일) + 올림/내림** 선택
- **(2026-11-05 Slack 확인) 부여 기준별 생성 규칙**
  - **생성 기준일**: 회계연도 기준 = 해당 연도 + 근무 설정의 회계연도 시작일 (예: 2028년 연차 → 2028.01.01) / 입사일 기준 = 해당 연도 + 입사(연차기산)월일 (예: 2026.03.01 입사자의 2028년 연차 → 2028.03.01). **그 기준일에 소속된 휴가그룹의 연차 제도**를 보고 생성 — Slack #channeltalk 2026-04-27 (https://hcgtheplus.slack.com/archives/C06ULEEM88M/p1777255120624029?thread_ts=1777252624.509129&cid=C06ULEEM88M). 그래서 회계연도 그룹으로 1/1 이후에 들어온 구성원은 그해 연차가 생성되지 않음 (Slack #cx 2026-08-11 https://hcgtheplus.slack.com/archives/C01AVJ2CJBW/p1786429967926669?thread_ts=1786429398.644369&cid=C01AVJ2CJBW)
  - **첫 해**: 입사일 기준이면 첫 연차 생성 시 근속연수 0년 행이 설정돼 있으면 1년 미만 연차와 함께 0년차 연차도 생성, 0년 행이 없으면 0년차 연차 행 자체를 만들지 않음(1년 미만 연차만) / 회계연도 기준이면 첫 회계연도 연차를 근속연수 0년 행의 일수로 계산, 0년 행이 없으면 법정 15일 기준으로 계산(일할·월할 적용) — Slack #sq-time 2025-12-15 (https://hcgtheplus.slack.com/archives/C04QC2RJJBU/p1765785467045259?thread_ts=1765763493.185579&cid=C04QC2RJJBU, 수정 반영 https://hcgtheplus.slack.com/archives/C04QC2RJJBU/p1765786913414959?thread_ts=1765763493.185579&cid=C04QC2RJJBU)
  - 회계연도 기준인데 "첫 회계연도만 입사일 기준으로 부여"하는 설정은 없음 (Slack #cx 2026-08-06)
- **연차 설정** (근속연수별 부여 일수) — 법적 표준 데이터 미리 입력됨, `법적표준 불러오기` 버튼으로 초기화 가능
  - 근속연수 입력 시 이전 행의 종료 연도 자동 변경
  - 이전 행보다 작게 입력하면 저장 불가 — "근속연수는 이전 근속연수인 {{years}}보다 커야합니다."
- **연차 초과 사용** (정상연차): 허용 안함 / 허용(제한 없음 또는 최대 N시간). 툴팁 "연차 초과사용을 허용하는 경우, 이번년도의 연차를 모두 소진한 이후에도 연차 휴가를 사용할 수 있습니다." / "초과사용한 휴가는 이번년도 잔여 연차에 마이너스로 표시되며, 다음년도 연차 부여 시 차감됩니다." 허용인데 시간 미입력 시 "연차 초과사용 허용시간을 입력합니다."
- **설정 결과 미리보기**: 입사일을 넣으면 연차유형(1년미만 연차/첫 회계연도 연차/정상연차)별 귀속연도·사용시작일·연차개수·사용종료일을 미리 보여줌
- **연차 사용 시간대**:
  - **자율**: 체크박스로 단위 선택 (종일 / 1~7시간 / 직접입력 — "[직접입력] 허용시 30분 단위로 휴가 사용이 가능합니다."). 모두 해제 시 "1개 이상의 연차 사용 단위를 설정합니다."
  - **고정**: 종일 + 추가 항목. 종일은 삭제 불가. 항목 정렬: 종일 > 차감시간 역순 > 시작시각 > 종료시각 > 항목명
    - 각 항목: 시작/종료 시각 + 차감시간
    - 시작=종료, 시작>종료 → "시작 시각과 종료 시각이 같습니다." / "종료 시각이 시작 시각 전입니다."
    - 차감시간 > (종료-시작) → "차감 시간을 시작 종료 시각으로 계산한 시간 보다 같거나 작게 설정합니다."
  - **자율+고정**: 둘 다 동일하게 동작

**룰 제약**:
- **내용 수정은 매핑 여부와 무관하게 전부 가능** — 수정 화면에 잠기는 필드 없음, 백엔드도 사용여부 N 변경만 차단 (`be:service/setting/rule/AnlCrtRuleSettingService.java:380`). 즉 휴가그룹에 매핑된 제도를 고치면 **그 제도를 쓰는 모든 휴가그룹에 즉시 영향** (2026-11-02 검증)
- 이미 휴가그룹에 할당된 제도: 사용여부 → "사용 안함" 변경 불가 ("휴가그룹에 적용된 연차 제도는 사용여부를 변경할 수 없습니다.")
- 이미 할당된 제도 삭제 불가 ("휴가그룹에 적용된 연차 제도는 삭제할 수 없습니다.")
- 수정 상태 [취소] → 조회 상태로 전환 (페이지 이동 X)
- 추가 상태 [취소] → 페이지 이동 알림 → 리스트로

## A-2. 연차 정산 기준 (Annual Leave Operation Rule)

**페이지**: `/attendance/leave/base_setting/annual_leave_operation_rule`

**조회/생성/수정/삭제** 표준 CRUD:

**설정 항목** (`LEAVE_SETTING.*` locale):

| 블록 | 선택지 |
|---|---|
| 의무 사용 여부 | 전체 의무 사용 / 일부 의무 사용(비율 % 또는 일수) / 의무 사용 안함 |
| 의무 사용 일수 기준 | 전년도 이월포함 / 전년도 이월 포함안함 |
| 의무 사용 일수 잔여 처리 | 소멸 / 소멸 안함 |
| 연차 보상 정책 | 전체 보상 / 일부 보상(비율 % 또는 일수) / 연차 보상 안함 |
| 연차 이월 정책 | 전체 이월 / 연차 이월 안함(소멸) |
| 연차 초과 사용분 정산 정책 | 전체 보상 / 전체 이월 / 전체 소멸 |
| 1년 미만 연차(월차) 정책 | 전체 보상 / 전체 이월 / 전체 소멸 |

- 비율 입력 시 반올림 단위는 **1일 / 1시간**만 노출 (일단위·시간단위 올림/내림). 일부 의무 사용 일수는 법적 한도 25일 이내 ("연차 법적 한도인 25일 이내로 입력합니다.")
- 생성 시: **연차 의무 사용 안함** 선택 → 의무 사용 일수 기준 / 잔여 처리 설정 불가 (툴팁 "전체 의무 사용, 일부 의무 사용의 경우에만 …")
- 생성 시: **연차 전체 보상** 선택 → 연차 이월 여부 설정 불가
- 수정 제약: 이미 저장된 정산 기준은 **이름/메모/사용여부만 수정 가능** (룰 자체는 변경 불가)
- 1년 미만 연차(월차) 정책은 1년 미만 연차의 잔여뿐 아니라 **부족분(초과 사용·하향 조정분)**도 같은 방식으로 청산 — 전체 보상이면 보상에서 차감(음수 가능), 전체 이월이면 차년도 부여에서 차감, 전체 소멸이면 청산 안 함 (2026-09-17 `hcgtheplus/optimiz-time#1642` §3). "연차 초과 사용분 정산 정책"은 정상연차 전용
- 현행 정산 기준은 v2 구조(2025-11 도입)이며, 예전 "연차 보상 및 적립 기준"(`TM_ANL_CM_RULE`)은 정산 엔진이 읽지 않는 죽은 코드 (`_learnings/2026-07-29-annual-leave-concept-map.md` §1)
- 삭제/사용여부 변경 제약: 휴가그룹에 매칭된 경우 차단 (연차 제도와 동일 패턴)

## A-3. 연차 외 휴가 제도 (Non-Annual Leave Rule)

**페이지**: `/attendance/leave/base_setting/non_annual_leave_rule`

**핵심 설정** (연차 제도와 유사하지만 추가 옵션):
- **연차 외 휴가 제도명** = **사용자용 / 어드민용 별도 설정** (어드민 화면에는 어드민용으로 노출)
- **필수값**: 휴가 제도명(어드민) · 휴가 제도명(사용자) · 휴가 설명 · 휴가 사용 단위 1개 이상
- **기본 설정**: 근무 인정 여부(인정 시 인정 근무시간에 휴가 시간 합산) · 유/무급
- **부여 방식**: 신청에 따라 사용 / 주기에 따라 반복 사용 / 수동 부여. 옵션 선택 시 추가 입력 항목 활성화 (연 최대 일수 또는 "연 단위 제한없음", 반복주기, 반복 부여 개수·단위)
  - 반복 주기 UI는 **1개월 / 1년만** 노출 (하루·일주일 코드 미노출). 부여 방식 '제한없음/연차차감' 코드도 미노출
- **수정 잠금** (2026-11-02 검증): 생성 후 수정 시 **근무 인정 여부 · 유/무급 · 부여 방식(및 연 최대/반복주기/반복 부여 개수·단위)** 는 비활성. 명칭·설명·기타 설정·사용 시간대는 수정 가능
- **기간 제한**: "제한" 선택 시 제한일자 정보 필수
- **휴일/휴무일 포함 여부**: 체크하면 근무계획상 휴일/휴무일에도 사용 가능
- **휴가 사용 시간대**: 연차 제도와 동일 (자율/고정/혼합)
  - **고정 > '종일' 체크박스 해제 시** 일반 항목처럼 항목명 수정 가능 (연차와 차이점)
  - **항목은 최소 1개 유지** (모두 삭제 불가)
- 연차 외 휴가 제도 목록 순서 = 구성원 화면 표시 순서 (새 항목은 하단에 추가)

> 연차 외 휴가는 **사용자에게 보이는 이름과 어드민이 보는 이름이 다를 수 있음** — 예: 사용자에게는 "특별 휴가"로, 어드민에게는 "직원 행사 보상휴가"로 명명 가능
