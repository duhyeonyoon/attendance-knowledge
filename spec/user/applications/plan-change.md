> **메뉴** 근무 신청 › 근무계획 변경
> **진입** 출퇴근 위젯 [근무신청] / 내 근무 캘린더 / 근무내역 변경 신청서에서 유형 변경
> **사용자** 구성원(신청자) · 결재자

## 1. 개요
구성원이 특정 기간의 근무계획(근무일 템플릿)을 바꾸기 위해 승인을 받는 신청서입니다. 승인되면 **개인스케줄**이 생성되어 그룹스케줄보다 우선 적용됩니다. 근무그룹 설정의 '근무 신청서 관리'에서 사용 여부와 신청 규칙을 정합니다.

## 2. 화면 구성
| 영역 | 구성 요소 | 설명 |
|---|---|---|
| 요청일 | 기간 캘린더 | 변경 대상 기간 외 일자는 비활성 |
| 기존 근무계획 | 기간별 기존 근무계획 | 휴일은 노출되지 않음. 기존 계획이 다르면 기간별로 나눠 표시 |
| 변경 결과 | 변경할 근무계획 | 근무일 템플릿만 선택 가능 |
| 하단 | 코멘트, 첨부, 결재선, [요청] | 코멘트/첨부 필수 여부는 어드민 설정 |

| U-APL-PLN-03 | 근무내역 변경서에서 전환 | 과거 근무내역 변경 신청서에서 유형을 근무계획 변경으로 변경 | |

### 3.2 신청
| ID | 기능 | 상세 동작 | 조건 · 예외 |
|---|---|---|---|

| U-APL-PLN-05 | 기간 유효성 표시 | 기간 유효성 위반이 여러 개여도 **가장 가까운 것 1개만** 노출 | 5. 메시지 참고 |

| U-APL-PLN-07 | 변경할 근무계획 선택 | 근무일 템플릿으로만 변경 가능 (휴일/휴무일은 기간에 포함돼도 실제 변경 불가) | |
| U-APL-PLN-08 | 신청 가능 기간 체크 | 어드민이 정한 신청 가능 기간 밖이면 경고 모달 후 신청서 닫힘 | |

## 4. 정책 · 비즈니스 룰
1. 근무그룹 설정 › 근무 신청서 관리 › 근무계획 변경 신청 **사용 여부 ON**일 때 사용 가능 (기본값 ON). 사용 중지면 "신청 불가 안내" / "신청서 사용이 중지되었습니다." 모달.
2. **개인스케줄 > 그룹스케줄** — 개인스케줄(사용자 근무스케줄 화면 또는 근무계획 변경으로 생성)이 있으면 그룹스케줄을 변경해도 해당 일자에 적용되지 않음.
3. 변경 가능 범위는 요청 시작일이 속한 근무그룹 기간까지.
4. 근무계획 변경 ↔ 대체근무는 상호 배타 (요청중 건이 있으면 다른 쪽 불가).
5. 어드민 설정 룰: 변경 대상 기간, 신청 가능 기간, 첨부/코멘트 필수 여부.
6. 마감된 일자는 요청/승인 불가.
7. **(2026-11-05)** 근무제 유형이 선택적 근로제인 근무그룹에서는 사용할 수 없습니다. 선택적 근로제 그룹은 [근무계획 수립 신청](./work-plan-establishment.md)으로 근무계획을 수립·변경합니다 (어드민 안내: "근무제 유형이 선택적 근로제인 근무그룹에서는 사용할 수 없습니다. 선택적 근로제 근무그룹은 근무계획 수립 신청서로 근무계획을 수립 및 변경합니다.").

- **결재 완료 후 되돌리기 (기획 확인 2026-11-05)**: 취소 신청서와 어드민 승인 취소 기능이 없습니다. 원래 템플릿으로 근무계획 변경을 다시 신청합니다. 미래 일자는 어드민 개인 근무 스케줄 관리에서 개인 스케줄 삭제도 가능합니다 (신청서는 남음).

## 5. 메시지 · 예외 처리
| 상황 | 화면 메시지 / 처리 |
|---|---|
| 기간에 미정 근무계획 있음 | "선택한 기간에 기존 근무계획이 정해져 있지 않은 기간이 존재합니다.(기간)" + "근무계획이 존재하는 기간으로 요청일을 변경해주세요." |
| 기간에 근무그룹 변경 있음 | "요청 시작일에 속한 근무그룹에 대해서만 근무계획을 변경할 수 있습니다.(~ 기간 종료)" |
| 기간에 요청된 근무계획 변경 있음 | "선택한 시간에 요청된 근무계획 변경 사항이 있습니다. 요청중인 기간의 근무계획은 변경할 수 없습니다.(기간)" |
| 기간에 요청된 대체근무 신청 있음 | "선택한 기간에 요청된 대체근무 신청이 있습니다. 요청중인 기간의 근무계획은 변경할 수 없습니다.(기간)" |
| 기간 전체가 휴일 | "선택한 요청일이 모두 휴일입니다. 근무 스케줄이 있는 근무일을 포함하여 선택해주세요.(휴일, 휴무일은 변경대상에서 제외됩니다)" |
| 변경 전후 근무계획이 동일 | "변경 이전과 이후가 동일합니다." |
| 변경 대상 기간 안내 | "(시작) ~ (종료)까지의 근무계획만 변경 가능합니다." (예: "전월 1일", "당월 말일") |
| 신청 가능 기간 외 | 경고 모달 "신청 가능한 기간이 아닙니다. (신청 기간: 매월 N일~M일)" + 신청서 닫힘 |
| 과거 근무계획 변경 | 안내 "과거 근무계획을 변경하면 변경된 계획을 기준으로 근무시간을 재산정합니다." |
| 코멘트 / 첨부 필수인데 미입력 | "코멘트를 입력합니다." / "첨부파일을 업로드합니다." |
| 마감된 일자 | "선택한 기간의 근무가 마감되어 근무계획 변경을 할 수 없습니다." (요청/승인 불가) |
